HTTPClient 网络客户端

组件 ID：foundation.http-client ｜ 任务清单 #94 ｜ 底层能力 foundation ｜ TMO 组件库 v1.4.0

定位：统一网络层——HTTP 客户端构建 + 环境（基址）配置 + 一期 Mock 通道；只负责「请求与解码」，业务规则放业务层。

1. 场景与边界（SCQA）

Situation

App 一期不接真后端，全部接口走 Mock；二期切换到真实后端仅需改基址。

Complication

若各页面自行 URLSession/OkHttp 发请求，会出现基址散落、序列化不一致、无法统一加拦截器（鉴权/日志）。

Question

需要一个集中构建客户端、集中声明环境基址、并提供一期离线 Mock 能力的网络层，且能被宿主替换为真实环境。

Answer

HTTPClient——iOS APIClientProtocol + MockAPIClient（Alamofire）+ APIEnvironment.current 可注入基址；Android KeepAccountsApi（Retrofit 接口）+ MockApiClient.create()（OkHttp + MockInterceptor 本地返回 JSON）。一期双端 Mock 均可离线成功。

2. 组件边界与划界

组件职责与 HTTPClient 划界
业务 API 接口记账/预算/资产等具体接口由宿主扩展 endpoint 与 DTO；中台包仅提供「客户端构建 + 环境 + 通用 Mock」
鉴权 / Token 刷新加 Authorization 头、401 刷新二期（在拦截器链中扩展）；一期不做
DTO 模型数据结构HealthDTO 等通用 DTO 由中台提供；业务 DTO 归宿主
日志 / 埋点请求日志二期

3. API 契约

iOS（Alamofire，已有 + 补齐 Mock 通道）

API签名说明
环境struct APIEnvironment { baseURL: URL; static let mock; static var current }current 默认 mock，宿主启动时覆盖为真实后端
协议protocol APIClientProtocol { func getHealth() async throws -> HealthDTO }便于替换实现与单测
客户端final class MockAPIClient: APIClientProtocol { static let shared; init(env:session:) }Alamofire Session 注入，getHealth() GET /health 解码
Mock 通道新增·补齐缺口MockURLProtocol（URLProtocol 子类 + register() 注入 URLSessionConfiguration）本地拦截 /health 返回 {"status":"ok","message":"keep-accounts mock"}；未知路径返回 {"status":"not_found",...}——与 Android MockInterceptor 行为一致

Android（OkHttp + Retrofit + kotlinx.serialization，已有）

API签名说明
接口interface KeepAccountsApi { @GET(ApiEndpoint.HEALTH) suspend fun health(): HealthDTO }Retrofit 接口
客户端class MockApiClient(val api: KeepAccountsApi) { companion object { fun create(): MockApiClient } }构建 OkHttp（挂 MockInterceptor）+ Retrofit（kotlinx 转换器）
Mock 拦截private class MockInterceptor(json)按 encodedPath 匹配：/health 返回 ok JSON；else 返回 not_found JSON；统一 code=200
基址ApiEndpoint.BASE_URL常量（宿主可为二期切换改造）

Events

事件说明
无挂起函数 / async 返回结果与错误

4. 设计规格

项规格依据
单一出口所有网络请求经统一客户端，禁止页面直接用原始 HTTP 栈可统一加拦截器与环境切换
环境可注入基址可被宿主覆盖（iOS APIEnvironment.current / Android 二期改造 BASE_URL 注入）一期 Mock、二期真后端零改业务
Mock 行为对齐/health → {"status":"ok","message":"keep-accounts mock"}；未知路径 → {"status":"not_found","message":"<path>"}；HTTP 状态码统一 200双端逐字符一致（Demo 可对照）
解码容错忽略未知字段（iOS 默认 / Android Json { ignoreUnknownKeys = true }）后端加字段不炸端
线程iOS async/await；Android suspend + Retrofit 自带 IO 调度不阻塞主线程
业务解耦中台包不含业务接口与业务 DTO可独立编译红线

5. Demo 排查 4 组

D1 健康检查     请求 GET /health → 显示 {"status":"ok","message":"keep-accounts mock"}
D2 环境配置     显示 baseURL 与当前环境（mock）；点击「切换环境」切换显示名
D3 未登记路径   请求 GET /unknown → 显示 {"status":"not_found","message":"unknown"}
D4 请求回执     显示 HTTP 200 + 耗时 xx ms + 响应体预览

Demo 全部走离线路由：Android 由 MockInterceptor 拦截，iOS 由 MockURLProtocol 拦截（注册到 Demo 会话配置），双端不产生真实网络请求，响应体逐字符一致。

7. 平台差异表

差异点iOSAndroid判据
HTTP 栈Alamofire SessionOkHttp + Retrofit表内放行（平台主流，语义一致）
序列化Codable + JSONDecoder（serializingDecodable）kotlinx.serialization + Retrofit 转换器表内放行（解码结果一致）
Mock 实现URLProtocol 拦截（本轮新增）Interceptor 拦截（已有）表内放行（各循平台拦截点；响应体逐字符一致）
环境配置APIEnvironment.current（struct，可运行期替换）ApiEndpoint.BASE_URL（常量，二期改造为可注入）表内放行（一期均指向 Mock）
并发模型async/awaitsuspend表内放行（同为非阻塞）
