CountDown 倒计时

组件 ID：ui.count-down ｜ 任务清单 #66 ｜ 信息展示区 ｜ TMO 组件库 v1.4.27

定位：纯展示型倒计时数字组件——输入目标结束时间戳（或剩余秒数），组件自驱每秒刷新显示格式化字符串（DD 天 HH:mm:ss / HH:mm:ss / mm:ss），结束时触发 onEnd 回调。不负责业务逻辑（跳转/提示由宿主在 onEnd 处理）。

1. 场景与边界（SCQA）

Situation 情景

App 中大量场景需要倒计时数字展示：秒杀活动倒计时、验证码重发倒计时、订单支付时限、活动开始/结束倒计时。

Complication 冲突

没有统一组件时=各业务页用 Handler/postDelayed 自写计时+拼字符串，暂停/继续、格式化、结束回调各实现一遍，时间漂移、页面切后台后计时错乱。

Question 问题

需要一个倒计时展示组件：支持绝对目标时间戳驱动（精度高、不受暂停影响），支持自定义格式串（HH:mm:ss / DD 天 HH:mm:ss / mm:ss），支持半受控暂停/继续，结束时回调宿主。

Answer 方案

CountDown——纯展示型内容组件，targetTime（绝对时间戳）优先、remaining（剩余秒数）便捷参数，每秒重算 remaining = targetTime - now（基于时间戳、无累积误差），format 字符串占位符替换（DD/HH/mm/ss），paused 半受控（暂停时停表、恢复时把暂停时长累加到 targetTime 保持剩余值连续），onEnd 结束回调。

6. 平台差异预告

差异点iOS（UIKit）Android（Compose）判据
计时驱动Timer.scheduledTimer(timeInterval:1, repeats:true, block)LaunchedEffect + delay(1000) 循环表内放行（各自平台惯用计时 API，语义一致=每秒基于时间戳重算）
暂停实现pause 时 invalidate Timer 存 pauseStart；resume 时 targetTime += now-pauseStart 重建 TimerLaunchedEffect keyed by paused：paused=true 时空循环不 advance；resume 时同公式累加 targetTime表内放行（算法同构，暂停期间剩余值连续）
渲染UILabel.text 替换 + textColor/fontText(text=, color=, fontSize=, fontWeight=)无差异（纯文本格式化）
等宽数字UIFont.monospacedDigitSystemFonttabular-nums（PlatformTextStyle）表内放行（同视觉效果=数字不抖动）

7. API 速览

Props

参数类型默认值说明
targetTimeLong（epoch 毫秒）0目标结束时间戳（绝对时间，优先级高于 remaining）。0 表示用 remaining
remainingLong（秒）0剩余秒数（targetTime 为 0 时使用，内部转 targetTime = now + remaining×1000）
formatString"HH:mm:ss"格式串，占位符：DD=天 / HH=时 / mm=分 / ss=秒，支持字面量（如"DD 天 HH:mm:ss"、"mm:ss"）
autoStartBooleantrue是否自动开始倒计时（false 时需外部把 paused 置 false 启动）
pausedBooleanfalse半受控暂停：true=暂停计时（停表保剩余值）；false=继续（targetTime 累加暂停时长）

Events

事件类型触发时机
onEnd() -> Unit剩余时间归零（remaining ≤ 0）时触发一次；业务结束动作（跳转/提示）由宿主在此处理

格式占位符

占位符含义示例（剩余 1 天 2 时 30 分 45 秒）
DD天（2 位，不足补 0）01
HH时（2 位，24 小时制）02
mm分（2 位）30
ss秒（2 位）45

常用组合：HH:mm:ss（1 小时内）/ DD 天 HH:mm:ss（跨天）/ mm:ss（分钟内）。
