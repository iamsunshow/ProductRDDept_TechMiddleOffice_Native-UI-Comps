NoticeBar 公告栏 · 设计规格（操作反馈区 #51 · 门禁 A）

组件 ID：ui.notice-bar ｜ 定位：顶部/内嵌公告/通知栏——双方向（horizontal 横向跑马灯/vertical 纵向轮播）+ 可关闭+左右自定义图标，对标 NutUI React NoticeBar + Vant NoticeBar。
组件库版本 设计阶段锁定基线 = v1.4.3（2026-09-08，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 顶部公告/通知循环播放（活动公告、系统消息）；② horizontal 横向跑马灯（单条文本自动滚动）；③ vertical 纵向多条轮播（list+垂直切换+停留时间）；④ 可关闭模式（closeable=true 右侧关闭按钮+onClose 回调）；⑤ 左右自定义图标（leftIcon/rightIcon slot）
不适用（N/A）① Toast 轻提示 → Toast（ui.toast）#59；② Notify 顶部通知 → Notify（ui.notify）#52（定位=短时全局浮层 vs NoticeBar=页面内嵌占位）；③ Dialog 弹窗 → Dialog（ui.dialog）#46；④ 全屏加载遮罩 → Loading（ui.loading）#50
五态适配默认态 ✅ 持续展示+滚动；禁用 N/A（NoticeBar 是瞬态信息展示，无"禁用"语义，不展示即移除）；其余态 N/A
与现有组件关系deps=[DesignTokens]（颜色/字号/间距 token，零硬编码）。与 Notify #52 划界：Notify=顶部全局短时浮层（自动消失，不占位），NoticeBar=页面内嵌占位栏（持续展示，需手动关闭或 scrollable 循环）；与 Toast #59 划界：Toast=全局轻提示（自动消失），NoticeBar=页面内嵌公告（持续）；与 Loading #50 划界：Loading=加载指示器（旋转图标），NoticeBar=公告信息（文本内容）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 一期形态：ACE 三选

选项后果评估
A：双方向（horizontal/vertical）+ 可关闭 + 左右图标 slot，页面内嵌占位栏✅ 覆盖 NutUI/Vant 主流公告栏场景；horizontal 单条跑马灯+vertical 多条轮播+closeable 关闭+leftIcon/rightIcon 自定义；页面内嵌=不浮层不自动消失推荐 A：双方向是 NutUI 标准，覆盖全场景
B：仅 horizontal 跑马灯（无 vertical 多条轮播）缺 vertical 多条消息轮播场景，与 NutUI direction=vertical 对不齐。淘汰：vertical 是基础场景
C：浮层模式（顶部弹出+自动消失）与 Notify #52 职责重叠，破坏单一职责。淘汰：归 Notify

P2 · 一期范围裁剪：ACE 三选

选项后果评估
A：horizontal+vertical+closeable+leftIcon/rightIcon+speed/delay/duration+Demo 4 组✅ 覆盖 NutUI 主流 props（direction/content/list/closeable/leftIcon/rightIcon/speed/delay/duration）；双方向+关闭+图标 slot 足够；二期再补 autoClose 倒计时圆环/action 操作按钮/tag 信息标/description 副文本推荐 A：范围收敛但覆盖完整
B：一期即支持 autoClose 倒计时圆环+action 按钮增加 UI 复杂度（圆环动画+按钮 slot），一期无强需求。淘汰：登记二期
C：仅 closeable 关闭（无 direction 滚动）缺滚动场景，与 NutUI scrollable 对不齐。淘汰：滚动是基础

P3 · iOS horizontal 滚动实现：ACE 三选

选项后果评估
A：CADisplayLink 驱动 UILabel frame.origin.x 匀速左移✅ 系统级定时器+frame 动画，精准可控；文本宽度算好后从右侧→左侧循环；结束回到起点无缝循环推荐 A：CADisplayLink 是 iOS 标准跑马灯方案
B：CAKeyframeAnimation 自动循环计算 keyframes 路径不如 frame 手动可控。淘汰：控制不如 frame
C：CATextLayer+transform不如 UILabel 简单。淘汰：UILabel 直观

P4 · Android horizontal 滚动实现：ACE 三选

选项后果评估
A：LaunchedEffect+animateScrollTo 横向滚动 BasicTextField/Text✅ Compose 标准 animateScroll 横向滚动，与 vertical LazyColumn 轮播同构；speed 配置 px/s推荐 A：animateScroll 是 Compose 标准方案
B：Handler+postDelayed 手动位移不利用 Compose 动画系统，多余。淘汰：animateScroll 标准
C：ViewCompat+_translationX不 Compose 原生，破坏一致性。淘汰：animateScroll 原生
