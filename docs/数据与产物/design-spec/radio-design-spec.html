Radio 单选 · 设计规格（数据录入组件 #35 · 任务清单 #35，subcategory=form · 门禁 A）

组件 ID：ui.radio ｜ 定位：通用排他单选标记（圆形单选点 + 可选 label）——单只 Radio（独立选中标记，行尾/宿主行内嵌用）与 RadioGroup（垂直排他单选列表，数据驱动，一选一）两种形态；单选点 20pt/20dp 圆形、选中外圈 primary + 中心实心点、label 后置；点按切换=onChange(value) 回调并回显；选中值半受控（value 外部可驱动回显）。对标 NutUI radio / Ant Radio 收敛为库内自有设计语言；与 Checkbox #25 明确区分：Radio=圆形排他一选一（点选即确定、点击已选行忽略）；Checkbox=方形复选可多选可取消。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-06，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 排他单选（性别、支付方式、默认账本、配送方式等"几选一"）；② RadioGroup 垂直列表逐项点选切换（表单/设置页主场景）；③ 编辑回显：宿主已持选中 value，RadioGroup 回显圆点并高亮；④ 行尾/单元格内单选标记（Cell 尾槽"本项为默认"圆点，宿主组合多行时用单只 Radio + 外部 value 驱动互斥）
不适用（N/A）① 复选多选（可多选/可取消/需集合结果）→ Checkbox #25（方形勾选）；② 二元即时开关（拨动式开/关、状态持久切换）→ Switch 类独立组件/既有开关；③ 下拉式页面选填（占空间大/选项多需承载层）→ Picker #33 / Menu #31 / 列表宿主；④ 页面主导航/分段高频切换 → Tabbar/Tabs/Segmented #74（页签类语义非表单排他）
五态适配默认态 ✅ 未选=白底圆外圈描边（边框 textSecondary 30%，同 Checkbox 惯例）+label 主文字；选中态 ✅ 圆外圈 primary 描边 + 中心实心 primary 圆点，label 保持主文字加粗；禁用态 ✅ 整项灰 40%（textSecondary 40%）不可点；选中+禁用=灰外圈灰中心点保留呈现（只读回显）；加载/失败 N/A（宿主自理）
与现有组件关系deps=[DesignTokens]；与 FormFieldRow #28 兼容=RadioGroup 作内容槽放入字段行（行高随组件撑开，配合 Form 校验宿主自理）；与 Cell（内容区）兼容=单只 Radio 可置于 Cell 内容/尾槽；与 Checkbox #25 状态惯例同构=半受控 value 外部驱动不触发 onChange；与 Menu #31 半受控惯例、InputNumber #30 外部驱动=同一状态惯例

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
单选点20pt/20dp 圆形，未选=白底、外圈描边 1.5pt/1.5dp 边框 textSecondary（alpha 0.3，同 Checkbox 未选描边惯例）；选中=外圈描边 primary + 中心实心圆点 8pt/8dp（primary）圆形=库内单选视觉（区别于 Checkbox 方形圆角 6 复选）
label后置、与单选点间距 8（spaceSm）、Md16 主文字、单行省略无 label=纯单选点（尺寸仍 20）
组行高/间距RadioGroup 垂直列表，行间距 4（spaceXs 组内紧凑）+行上下内 padding 10；整组内容宽=宿主容器宽列表项右缘不拉伸（单选点+label 左起、命中区=整行可点）
禁用态disabled=textSecondary 40% 灰（外圈/实心点/label 全灰）；disabled 项不可点无回调；value 指向 disabled 项=灰回显只读选中 disabled=灰点灰圈保留语义可读（与 Checkbox 已选禁用同则）
数据驱动RadioOption(value, label, disabled) → 选中 value 落库；RadioGroup(options, value?, onChange) 排他单选唯一选中与 CheckboxOption/CascaderOption/TabItem 数据驱动惯例同构

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件形态：ACE 三选

选项后果评估
A：独立通用单选组件双形态——单只 Radio（单选点+可选 label，行尾/宿主组合标记用）+ RadioGroup（options 数据驱动垂直排他列表）；圆形单选点 20 + 选中外圈 primary 中心实心点视觉✅ 场景覆盖完整：整组排他一选一与分散单选标记（宿主外部 value 驱动互斥）都落库级 API；圆形视觉与 Checkbox 方形严格区分、语义零混淆；垂直列表一期足够（表单主场景）；双端纯绘制+点击=轻量可靠推荐 A：单只+组双形态（对齐 Checkbox 先例）
B：仅做 RadioGroup 垂直列表（不做单只）分散单选标记（每行尾一枚、互斥由宿主排他）无组件可用，宿主被迫自绘圆点淘汰：单只是最小原子（对齐 Checkbox 先例）
C：复用/模拟系统单选（iOS 无系统 radio 控件、Android 套系统 RadioButton/Material 样式）iOS 无现成件=仍须自绘；Android 系统 radio 视觉/主题与库设计语言脱节、受 Material 主题变量约束=组件库自绘惯例违背淘汰：双端自绘圆点，库内自有设计语言

P2 · 数据模型：ACE 三选

选项后果评估
A：RadioOption(value, label, disabled) 数据驱动 + RadioGroup(options, value: String?, onChange)；单只=Radio(label?, checked: Bool?, onChange)✅ value 稳定落库、disabled 项内联可配；外部按 value 回显（编辑场景）；排他=唯一选中 value（String），与复选集 Set 区分清晰；与库内 option 数据驱动惯例同构推荐 A：数据驱动惯例
B：仅 label 字符串数组（无独立 value）选中结果落库歧义（同名文案/文案变体）；外部回显无法按 value 稳定匹配淘汰：同库惯例已弃（见 Menu P2 / Checkbox P2）
C：value 可含图片/富文本/副标题卡片结构整项自定义（图标+标题+副文案）卡片单选=二期形态，一期纯文字 label 足矣（宿主自定义行布局可自行组装）淘汰：登记二期

P3 · 状态控制：ACE 三选

选项后果评估
A：半受控——value（String?）可选传；nil=内部自持（初始=无选中=合法未选态，点选即选中该行并回调 onChange(value)；不自动回填首项=避免改变宿主表单语义）；外部赋值 value=同步刷新渲染（编辑回显/重置），不触发 onChange（同 InputNumber/Menu/Checkbox 惯例）；点击当前已选中行=幂等忽略（无变化不回调，同 Menu 已激活惯例）；单只 checked 同规则（nil 自持 false，点选置 true；取消只能外部驱动）✅ 表单提交=宿主拿 onChange 回传值；编辑回显=外部 value 驱动；未选态合法=配合必选校验宿主自理；库内状态惯例一致推荐 A：库内半受控惯例
B：纯受控（value 必传，每次点击宿主回写）简单受控无内部态；但宿主每次点按都要回写新值，未传即不可用（灵活性弱于 A）可接受但过度（A 的受控超集）
C：纯自管理（不暴露 value 外设）编辑回显/重置驱动无门（同 Menu P3-C 结论）淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：圆形单选点+label 后置+Radio/RadioGroup 双形态+disabled（项级/组级/已选禁用灰点保留）+半受控 value+demo 四段（单只/组排他/禁用/受控外部驱动）✅ 单选核心闭环（排他切换/禁用/外部回显/回调）逐项可验；无动画无嵌套=验收路径清晰推荐 A：核心闭环可验收
B：一期含整项卡片单选（图标+标题+副文案自定义行）自定义行=内容槽复杂度+双端 demo 对仗成本高，非单选基础需求淘汰：登记二期
C：一期含横向/换行排列/圆点动画/点击已选中取消（toggle 式）横向排列=新布局方向；radio 传统语义不可 toggle 取消（与 Checkbox 混淆）；动画范围膨胀淘汰：登记二期/不做

05 · 平台差异表（表内放行，表外必须双端统一）

维度iOSAndroid放行原因
圆点绘制CALayer/CAShapeLayer 圆描边+内圆填充（20pt/8pt）Canvas drawCircle 外圈描边+中心实心（20dp/8dp）平台绘制机制不同、视觉一致（表内放行，同 Checkbox 勾绘先例）
点击按压反馈touchDown 压暗瞬态（无系统 ripple）clickable 系统 ripple / 组行无涟漪（agreement 无涟漪先例）系统级原生差异（同全库先例，表内放行）
命中区整行 UIControl/UITapGestureRecognizer，label 一并可点Row.clickable 整行可点两端命中区一致=整行（表内放行机制差异）
状态回写命令式：外部赋值 value → 显式刷新子单选点视图（demo onChange 宿主回写 value 属性）声明式：value State/参数变化自动重组命令式/声明式机制不同、宿主回写后视觉一致（库内惯例，表内放行）
文字省略/折行UILabel truncateTailText maxLines=1 ellipsis两端单行省略一致指向（表内放行）
无障碍VoiceOver：单选点 isAccessibilityElement+label+value 选中态（selected 语义）TalkBack：语义/selected 状态系统无障碍层各读屏实现不同（表内放行）
尺寸单位 / 命名pt；RadioOption struct + RadioView/RadioGroupView（独立 Radio.swift）dp；data class RadioOption + @Composable Radio/RadioGroup（Radio.kt）Token 同值不同单位；命名差异见门禁 B（表内放行）

06 · API 草案（双端一致契约，门禁 B 据此登记 api.json）

端API

value: String?（当前选中值；nil=内部自持且初始未选=合法态）；onChange(value: String)（有效点选触发：点未选行=切中并回调；点当前已选中行=幂等忽略；disabled 无回调；外部赋值 value 不触发 onChange）；单只=Radio(label?, checked: Bool?, onChange(Bool))（点选置 true，取消只能外部驱动 false）
