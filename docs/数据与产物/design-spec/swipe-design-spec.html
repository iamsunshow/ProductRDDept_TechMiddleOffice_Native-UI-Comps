Swipe 滑动

组件 ID：ui.swipe ｜ 任务清单 #58 ｜ 操作反馈区第十四件 ｜ TMO 组件库 v1.4.14

定位：列表项横向滑动露出操作按钮——左右滑动显示删除/标记/置顶等操作，点击操作触发回调并自动收起。

1. 场景与边界（SCQA）

Situation 情景

列表项需要对单条数据执行快捷操作（删除、标记、归档等），操作项 1~3 个，不适合长按（手势隐蔽）也不适合整页 ActionSheet（遮挡过多上下文）。

Complication 冲突

无统一组件时=各业务自拼 UISwipeActionsConfiguration(iOS)/ItemTouchHelper(Android)，视觉不统一、无双向滑动、无自定义操作颜色。

Question 问题

需要一个列表项内嵌的横向滑动容器，支持左右双向操作、自定义操作按钮（文本/颜色/回调），滑动露出操作点击后自动收起。

Answer 方案

SwipeItem——横向滑动容器，包裹主内容 + 左右操作按钮列表，纯展示+回调（不内置业务逻辑）。

5. 关键决策 PREP/ACE（P1–P4，AI 代评待用户总审）

P1 · 组件形态：ACE 三选

选项后果评估
A：SwipeItem 包裹器（横向滑动容器+主内容+左右操作列表）✅ 列表项即插即用，包裹内容+操作，双向支持，与 NutUI SwipeAction/Vant SwipeAction 一致。推荐 A：开箱即用+双向+自定义操作
B：只做单向右滑简单但缺少左滑场景（标记/置顶）。淘汰：双向是标配
C：宿主自拼手势灵活但重复造轮子。淘汰

P2 · 滑动实现方案：ACE 三选

选项后果评估
A：手动偏移+动画——UIPanGestureRecognizer/detectHorizontalDragGestures 计算偏移，松手根据阈值决定展开/收起，UIView.animate/animatable Offset 动画✅ 双端同构，阈值可控（50% 操作宽度展开），松手自动回弹，与 Vant SwipeAction 一致。推荐 A：双端一致+阈值可控
B：UIScrollView 横向滚动iOS 原生但 Android 无对等，且滚动惯性难控。淘汰：跨端不一致
C：系统 SwipeActions（iOS UITableView trailingSwipeActions）iOS 13+ 原生但 Android 无对等，且仅限 UITableView/UICollectionView 场景。淘汰：场景受限+跨端不一致

P3 · iOS 实现路径：ACE 三选

选项后果评估
A：UIView + UIPanGestureRecognizer + 手动 frame/transform 偏移✅ UIKit 原生，手势计算偏移，松手 UIView.animate 动画展开/收起；操作按钮做底层 subview 露出。推荐 A：UIKit 原生，手势可控
B：UIScrollView 横向原生但惯性难控，Android 无对等。淘汰
C：UIContextualAction（系统）仅 UITableView 场景，组件库通用性差。淘汰

P4 · Android 实现路径：ACE 三选

选项后果评估
A：Box + pointerInput(detectHorizontalDragGestures) + offset 动画✅ Compose 原生，手势计算偏移，松手 animateFloatAsState 动画展开/收起；操作按钮 Box 底层露出。推荐 A：Compose 原生，手势可控
B：LazyColumn ItemTouchHelper仅 RecyclerView 场景，且 Swipe 是横向不是拖拽。淘汰
C：HorizontalScrollView原生但惯性难控。淘汰

8. anti_goals 反目标（二期不做）

  • 自定义操作按钮内容（图标/自定义视图）——一期纯文本覆盖 80%
  • 滑动距离阈值可配（一期固定 50% 操作宽度展开）
  • 嵌套 Swipe（Swipe 内 Swipe）——复杂场景用页面导航
  • 滑动方向自由（上下滑）——Swipe 仅横向
  • Lottie 滑动动画
