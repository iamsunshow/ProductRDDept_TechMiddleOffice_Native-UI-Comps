Popover 气泡弹出框

组件 ID：ui.popover ｜ 任务清单 #53 ｜ 操作反馈区第八件 ｜ TMO 组件库 v1.4.4

定位：点击触发元素后弹出的小气泡浮层，带箭头指向锚点，内嵌自定义内容（菜单/提示/表单等），点击外部自动收起。

1. 场景与边界（SCQA）

Situation 情景

用户在工具栏/列表项/卡片中点击某元素后，需要展示一小块补充内容（提示说明、快捷操作菜单、迷你表单），内容量小、不需要全屏遮罩、不需要居中确认对话。

Complication 冲突

没有统一组件时=各业务页自拼 UIPopoverPresentationController(iOS)/PopupWindow(Android)，视觉不统一、无箭头指向、无 placement 方向、无 closeOnClickOutside。

Question 问题

需要一个锚点弹出气泡浮层，支持 placement 六向（top/bottom/left/right/start/end）、箭头指向锚点、closeOnClickOutside、自定义内容槽，双端视觉一致。

Answer 方案

Popover——锚点定位气泡浮层，受控 visible + content 内容槽 + placement 方向 + 箭头 + closeOnClickOutside（不内置业务内容，纯容器承载宿主内容）。

2. 组件边界与划界

组件职责与 Popover 划界
Dialog #46居中确认对话（标题+内容+按钮）Dialog=居中遮罩确认，Popover=锚点小气泡无遮罩
ActionSheet #44底部动作面板（操作列表）ActionSheet=底部全屏遮罩动作，Popover=锚点小气泡
Popup #54通用弹出层（居中/底部/顶部）Popup=通用容器带遮罩，Popover=锚点小气泡无遮罩
Tooltip纯文本提示（悬停/长按）Tooltip=只读文本提示，Popover=可嵌入任意内容（菜单/表单）
Overlay #6遮罩层基础类Overlay=底层遮罩，Popover=不使用遮罩（仅 closeOnClickOutside 透明层）

3. API 契约

Props

参数类型默认值说明
visibleBoolean必传是否展示（受控）
contentComposable / UIView必传气泡内嵌内容槽（宿主自定义）
placementPopoverPlacementtop弹出方向：top/bottom/left/right/start/end
anchorRect / Anchor必传锚点位置（触发元素的 frame，用于定位气泡+箭头方向）
closeOnClickOutsideBooleantrue点击气泡外部是否自动收起（触发 onClose）
offsetOffset0气泡相对锚点的额外偏移（微调用）
onClose(() -> Unit)?null气泡收起回调（closeOnClickOutside 触发或外部 visible=false）

PopoverPlacement 枚举

值说明
top气泡在锚点上方，箭头朝下
bottom气泡在锚点下方，箭头朝上
left气泡在锚点左侧，箭头朝右
right气泡在锚点右侧，箭头朝左
start气泡在锚点 RTL 起始侧（LTR=左）
end气泡在锚点 RTL 结束侧（LTR=右）

Events

事件回调签名触发时机
onClose() -> Unit点击外部（closeOnClickOutside=true）或外部 visible=false 设为 false 时

4. 设计规格

4.1 布局结构

区域规格Token
气泡容器白底圆角 8dp，阴影 0 4 12 rgba(0,0,0,0.15)bgCard / radiusSm / elevation
内边距水平 12 垂直 8（内容槽外部留白）spaceMd / spaceSm
箭头8×8 旋转 45° 实心方块，颜色同气泡底色bgCard
箭头位置沿锚点方向居中（top/bottom=水平居中，left/right=垂直居中）—
外部透明层全屏透明，捕获点击（closeOnClickOutside=true 时）—
内容槽宿主自定义（菜单项/提示文本/迷你表单）—

4.2 交互规格

交互行为
展开气泡淡入+缩放 0.95→1.0（150ms easeOut）
收起-外部点击closeOnClickOutside=true 时点击透明层 → 气泡淡出 → onClose() 回调
收起-外部控制外部 visible=false → 气泡淡出（不触发 onClose，由外部自行处理）
placement 自动翻转若指定方向空间不足（靠近屏幕边缘），自动翻转到对侧方向

编号决策点选项选定理由

B. 居中弹层（带遮罩）
C. 底部弹出层		 A 锚点小气泡覆盖工具栏提示/快捷菜单场景，与 Dialog 居中确认/ActionSheet 底部动作/Popup 通用容器划界

B. 内部自持 visible

B. 预设菜单项数据驱动

7. 平台差异表

差异点iOS（UIKit）Android（Compose）判据
弹出机制keyWindow.addSubview + frame 定位Popup（Compose 1.6+）表内放行（系统级弹层机制差异）
箭头绘制CAShapeLayer 自绘 8×8 旋转方块Canvas drawRect 8×8 旋转方块表内放行（双端同构自绘）
外部点击捕获全屏透明 UIView + UITapGestureRecognizerPopup dismissOnClickOutside表内放行（手势系统差异）
placement 自动翻转UIScreen.bounds 空间检测LocalView bounds 空间检测表内放行（坐标系差异）
动画UIView.animate 0.15stween 150ms表内放行（动画 API 差异，时长一致）

8. 反目标（anti_goals）

不做原因
遮罩层（半透明黑底）Popover=轻量气泡提示，无需遮罩；需遮罩用 Dialog #46 或 Popup #54
预设菜单项数据驱动通用容器=内容槽最灵活；预设菜单用 Menu #31 或 ActionSheet #44
长按触发二期增量，一期点击触发覆盖 80% 场景
嵌套 Popover（Popover 内 Popover）复杂场景用多级页面导航或 Cascader #24
自定义动画曲线一期统一 150ms easeOut，曲线参数=二期增量
任意 angle 角度定位六向枚举覆盖 95% 场景，任意角度过度设计
