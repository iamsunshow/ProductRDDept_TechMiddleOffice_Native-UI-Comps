BarChart 条形图 · 设计规格（业务展示组件 · 任务清单 #97 · 业务展示补全 · 门禁 A）

组件 ID：ui.bar-chart（双端均缺，全新立项）｜ 定位：横向条形图——业务展示通用条形图组件（横向布局，Y 轴为类别、X 轴为数值），支持单/多类别 + 数据值 + 颜色阈值切换 + 数值标签；与 LineChart #96（折线）严格划界；iOS Charts (DGCharts) HorizontalBarChartView / Material BarChart 收敛为库内自有设计语言（Canvas drawRoundRect 自绘 + 圆角 4dp + 阈值三态色 + 数值标签 sizeSm Semibold）。
组件库版本 设计阶段锁定基线 = v2.0.8（2026-09-15，未过 C2/D 不升版）
业务回填 KeepAccounts 记账 AssetTypeBarChart 双端均需替换（评估文档 §5 行 73，2026-09-16 真实状态核对 = 双端都缺，§3.7 行 382 已登记 v2.0 todo）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 业务报表分布展示（记账分类支出比例条形）；② 资产类型分布（记账 AssetTypeBarChart）；③ 排行榜（Top10 销售额）；④ 类别比较（多类别同一数值维度）；⑤ 任何横向比较型分布
不适用（N/A）① 折线图（时序趋势）→ LineChart #96；② 饼图/环形分布 → PieChart（业务二期）；③ 单一数值 → Price #72；④ 比例表达 → Progress #74 / ProgressCircle #83；⑤ 堆叠柱状（多系列堆叠）→ 业务二期；⑥ 纵向柱状图 → 业务二期（本期仅横向，竖向登记二期）
五态适配默认态=白底（bgCard）+ 主色条（primary）+ 数据值 sizeSm Semibold textPrimary；颜色三态=primary（默认）/warning（≥80% 阈值）/error（≥100% 阈值）；加载=骨架条占位（保留布局不画填充）；空态=空数据文案「暂无数据」+ 文案 sizeSm textSecondary；成功/失败 N/A
与现有组件关系deps=[DesignTokens]；收编现状=iOS 无独立 BarChart（业务自绘或依赖 DGCharts/Charts 第三方库 BarChartView）；Android 无独立 BarChart（业务 AssetTypeBarChart 自建 Canvas drawRoundRect 拼装），本规格将业务横向条形图模式提升为库内统一独立组件（双端从零 Canvas 自绘不引入第三方库，与 LineChart #96 同策略）；与 LineChart #96（折线）严格划界（线 vs 条）；与 Progress #74（横条进度）/ProgressCircle #83（圆环）划界（条形图多类别 vs 进度单条/圆环）

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
行高每条 24dp（label 区域 64dp 宽 + 轨道 16dp 高 + 数值标签 48dp 宽 + 间隔 10dp）条目等高 24dp；与 iOS Charts HorizontalBarChartView rowHeight=24pt 同构（业务同高度 24）
轨道宽轨道 bgGrayLight=F3F4F6 灰底铺满 + 填充色按数据未填充部分统一灰底，填充部分按阈值颜色（primary/warning/error）
条高16dp（轨道内填充）圆角 4dp strokeCap=Round；与 iOS Charts 16pt 同构
填充颜色primary=16A34A（默认）+ warning=F59E0B（≥80% 阈值）+ error=DC2626（≥100% 阈值）阈值可由宿主传 warnThreshold=0.8 / dangerThreshold=1.0 覆盖；色彩按 value/maxValue 比例自动切换
标签类别标签 64dp 宽 sizeXs=12 textSecondary 右对齐；数值标签 48dp 宽 sizeSm=14 Semibold textPrimary 左对齐宿主可传 labels[String] 覆盖默认数字索引；value 文本必显示
圆角条填充 4dp 圆角 strokeCap=Round（与 ProgressCircle 同）与 Progress #74 圆角对齐=视觉一致
动画0.3s ease-out 过渡（从 0 长度动画到目标长度）数据变化时平滑过渡；与 ProgressCircle 0.3s 一致
与 LineChart 划界BarChart=横向条形图（类别在 Y 数值在 X）；LineChart=折线（时序）数据模型不同（BarChart 类别+数值对 vs LineChart values 数组）；可共存

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件定位：ACE 三选

选项后果评估
A：横向条形图独立组件（双端从零 Canvas 自绘）——单/多类别条形 + 数值标签 + 阈值三态颜色 + 0.3s 过渡✅ 与业务现状（记账 AssetTypeBarChart）1:1 收敛；双端统一独立组件；与 LineChart #96 同策略（Canvas 自绘不引第三方库）推荐 A：业务收敛独立
B：复用 LineChart #96 + 加条形模式LineChart 折线职责扩张；折线（时序）与条形（类别）数据模型不同；API 难统一淘汰：职责分裂
C：children 插槽（宿主自组 Row + 填充 + 标签）组件退化为"数据列表"，失去组件语义淘汰：登记二期

P2 · 数据/API 模型：ACE 三选

选项后果评估
A：声明式数据驱动——BarChart(items: [BarItem], warnThreshold: Float = 0.8, dangerThreshold: Float = 1.0)；BarItem{label: String, value: Float}；maxValue 自动 = max(items.value)✅ 与 LineChart #96 / ProgressCircle #83 数据驱动 API 同构；items 数组清晰；maxValue 自动计算宿主可覆盖；阈值与 ProgressCircle 命名同推荐 A：与库内 API 同构
B：双 API（单条 Bar + 多条 BarGroup）组件职责重叠淘汰：单 API 覆盖
C：children 插槽失去组件语义淘汰

P3 · 横向 vs 纵向：ACE 三选

选项后果评估
A：一期仅横向（业务 AssetTypeBarChart 当前形态）——Y 轴类别 X 轴数值；竖向柱状图登记二期✅ 与业务现状 1:1 收敛；横向最适合类别比较（标签可读性高）；竖向留给业务二期推荐 A：一期仅横向
B：一期双向（横向+纵向）超出 AssetTypeBarChart 业务范围；组件复杂度翻倍淘汰：登记二期
C：一期纵向与业务现状不匹配；用户体验差（标签可读性低）淘汰

P4 · 一期范围：ACE 三选

选项后果评估
A：一期=数据驱动横向条形图+数值标签+阈值三态+0.3s 过渡+Demo 四段（D1 基础 5 类别/D2 阈值切换 60%/85%/110%/D3 7 类别 Top 排行/D4 0.3s 过渡）✅ 覆盖业务记账 AssetTypeBarChart 现状；双端 1:1 收敛；验收可达推荐 A：一期收敛
B：一期+堆叠柱状（多系列堆叠）超出 AssetTypeBarChart 业务范围；登记二期淘汰：登记二期
C：一期=空壳+业务全自管无组件价值淘汰

05 · 平台差异表（表内放行）

差异点iOSAndroid放行原因
绘制方式UIView draw(_:) UIBezierPath roundedRect + UIColor.setFillCompose Canvas drawRoundRect(topLeft,size,cornerRadius,style=Fill)系统级原生 API 差异
动画UIView.animate withDuration 0.3s curveEaseOut + layer.opacity/layer transformanimateFloatAsState(targetValue=animatedValue, animationSpec=tween(300, easing=FastOutSlowInEasing))平台动画框架差异
行布局UIStackView spacing=10 + width 锚定Column verticalArrangement spacedBy(10.dp) + fillMaxWidth布局系统差异
标签字体UIFont.system(size:12, weight:.regular) textSecondary rightText(sizeXs=12, color=textSecondary) + textAlign=TextAlign.End类型系统差异
数值字体UIFont.system(size:14, weight:.semibold)Text(sizeSm=14, fontWeight=FontWeight.SemiBold)类型系统差异

特别说明：iOS 业务现状依赖第三方库 Charts/DGCharts BarChartView，本规格=双端从零 Canvas 自绘不引入第三方库，与 LineChart #96 同策略（评估文档 §5 修正段已澄清 iOS 是 Vendor/Charts 第三方库非库侧实现）。
