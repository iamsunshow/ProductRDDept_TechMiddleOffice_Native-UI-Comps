Collapse 折叠面板

组件 ID：ui.collapse ｜ 信息展示区组件 #65 ｜ TMO 组件库 v1.4.27

定位：可折叠/展开的内容区域——点击标题展开或收起内容，用于将较长内容分组收纳，节省页面纵向空间。

1. 场景与边界（SCQA）

Situation 情景

App 中常出现大段说明、协议、帮助、多组设置项等长内容，平铺会让页面极长、用户难以快速定位重点。

Complication 冲突

各业务页自绘标题行+隐藏内容+手写展开逻辑，箭头方向不一致、手风琴互斥规则各自实现、禁用态缺失，双端表现漂移。

Question 问题

需要一个折叠面板组件，支持多项同时展开、手风琴互斥（只展一项）、禁用项、外部受控驱动展开态，双端 1:1 视觉一致。

Answer 方案

Collapse——数据驱动的内容折叠组件，items 数组定义每项（title + content + key + disabled），activeKeys 控制展开项 key 列表（受控/自管理可切换），accordion 开手风琴互斥，右侧 chevron 箭头展开时旋转，支持 onChange 回调。

2. 组件边界与划界

组件职责与 Collapse 划界
Tabs #78页签横向切换Tabs=横向页签切换不同面板（同时只显一页）；Collapse=纵向折叠展开/收起（可多项同展）
Cell #66列表行展示Cell=静态列表行（无展开态）；Collapse=有展开/收起二态，标题行下方动态显隐内容
NoticeBar #51公告栏横向滚动NoticeBar=单行横向滚动公告；Collapse=纵向分组折叠
Empty #1空状态占位Empty=无数据占位；Collapse 内容区可嵌 Empty 作为折叠项内容

7. API 速览

Collapse Props

参数类型默认值说明
itemsList<CollapseItem>[]折叠项数据数组
activeKeysList<String>?null展开项 key 列表；null=内部自管理状态，非 null=受控
onChange((List<String>) -> Unit)?null展开态变化回调（返回最新 activeKeys）
accordionBooleanfalse手风琴模式：true 时只允许一项展开，展新项自动收旧项

CollapseItem

字段类型默认值说明
keyString—项唯一标识（对应 activeKeys 中的值）
titleString—标题行文案
content内容视图/Composable—展开后内容（iOS=UIView，Android=@Composable lambda）
disabledBooleanfalse禁用：标题置灰、不可点击展开
