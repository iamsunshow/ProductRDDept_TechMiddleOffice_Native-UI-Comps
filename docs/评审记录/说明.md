# 评审记录（门禁 A 设计评审单归档）

本目录统一存放全部组件「门禁 A 设计评审」的评审单，与 `数据与产物/`（api.json/design-token/design-spec 等数据产物）分离，独立成区便于查阅。

- **文件命名**：`review-<组件标识>-A.md`，一份对应一个组件的一次门禁 A 评审。
- **配套规格**：同一评审的设计规格 H5 见 `../数据与产物/design-spec/<组件标识>-design-spec.html`（规格 + 评审单 = 门禁 A 双档，通过即 📐 立项）。
- **评审维度**：评审单逐项打 A1 组件边界 / A2 Token 零硬编码 / A3 决策投票表 P1–P4 / A4 Demo 排查 / A5 实现现状 / A6 平台差异表 / A7 anti_goals，全 A 方通过。
- **当前收录**：33 份（2026-09-07 归档）。
- **外部引用**：组件进度.md（docs 根）以 `评审记录/review-xxx-A.md` 指向本目录；api.json（数据与产物下）以 `../评审记录/review-xxx-A.md` 指向本目录。

> 2026-09-07：自 `数据与产物/评审记录/` 迁至 `docs/评审记录/`，与数据产物目录分离。
