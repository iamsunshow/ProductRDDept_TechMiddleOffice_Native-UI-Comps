Dialog 对话框

组件 ID：ui.dialog ｜ 任务清单 #46 ｜ 操作反馈区第三件 ｜ TMO 组件库 v1.4.0

定位：居中弹出的模态对话框——标题 + 正文 + 操作按钮，用于确认/警示/告知。

1. 场景与边界（SCQA）

Situation

需要用户确认重要操作（删除/退出/同意协议）或展示重要信息。

Complication

iOS 无统一 Dialog 组件（Android 已有 AppDialog），双端视觉/API 不对齐。

Question

iOS 补全 Dialog，对齐 Android 现有 AppDialog API。

Answer

DialogView.swift 对齐 AppDialog：title/content(或自定义content)/actions(三样式)/buttonLayout(Vertical通栏|Horizontal并排)/onDismiss。

2. 组件边界与划界

组件职责与 Dialog 划界
ActionSheet #44底部动作面板（多选一动作）Dialog=居中确认对话（是/否），ActionSheet=底部动作列表
Toast #59轻提示短暂浮层Toast=自动消失无按钮，Dialog=需用户点按钮关闭
Popup #54通用弹出层容器Popup=通用容器，Dialog=专用居中对话框

3. API 契约（对齐 Android AppDialog）

参数类型默认值说明
titleString?null标题（null=不显示标题区）
contentString?null正文文本（与自定义内容二选一）
contentContentComposable/UIView?null自定义正文内容（优先于 content）
actionsList<DialogAction>必传按钮列表
buttonLayoutVertical | HorizontalVerticalVertical=通栏全宽自上而下；Horizontal=左右并排（最多2项）
onDismiss(() -> Unit)?null点击遮罩关闭回调（null=不响应点遮罩）

DialogAction

字段类型默认值说明
textString必传按钮文案
onClick() -> Unit必传点击回调
stylePrimary | Default | DestructiveDefaultPrimary=主色填充；Default=浅灰背景；Destructive=红色文字

6. 决策投票表

编号决策点选定理由
P1对齐方式A. iOS 对齐 Android 现有 AppDialog APIAndroid 已沉淀 AppDialog（CommonComponents.kt L419），iOS 补全对齐，避免双端 API 分裂
P2按钮布局A. Vertical 通栏(默认) + Horizontal 并排与 Android AppDialog 一致，覆盖通栏确认和并排取消/确定两场景
P3按钮样式A. Primary/Default/Destructive 三样式与 Android DialogAction.style 一致；Default=浅灰、Primary=主色、Destructive=红字
P4自定义内容A. 支持 contentContent 自定义正文与 Android contentContent 一致，支持富文本/协议链接等复杂正文
