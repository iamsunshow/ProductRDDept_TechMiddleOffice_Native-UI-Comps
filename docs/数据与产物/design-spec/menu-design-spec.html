Menu 菜单 · 设计规格（数据录入组件 #? · 任务清单 #31，subcategory=form · 门禁 A）

组件 ID：ui.menu ｜ 定位：嵌入式下拉单选菜单（内联展开、无遮罩无浮层）——顶部一条横向菜单栏（≤4 列等分；列文案=当前选中值）＋ 展开态在菜单栏正下方内联展开一个选项单选列表（随组件高度增长，宿主纵向容器自然推挤下方内容）；点开项再点=收起，点其它项=切换展开；选中选项=回调并收起；列级 activeKey 与选中值半受控外部驱动。对标 NutUI Menu 收敛为库内自有设计语言（筛选条+下拉展开+选中回显）；一期无遮罩/悬浮浮层（Popup #54 未实现），不做多级子菜单与联动筛选。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-06，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 页面筛选条：一行菜单项（排序方式/时间范围/账单类型/状态）点开即选、选中值回显到菜单栏标题；② 紧凑多条件单选（2~4 列并排）；③ 编辑回显：宿主已持各列选中值，Menu 回显并高亮；④ 卡片/列表页顶部筛选等宿主纵向内容流首部（下方内容在展开时被推挤=嵌入式语义）
不适用（N/A）① 悬浮遮罩式下拉（盖于内容之上、点外部收起）→ 二期（随 Popup #54 / 浮层机制）；② 多级子菜单/级联筛选 → Cascader #24 / 二期；③ 单列表格/分组的常驻选择列表 → Picker #33 / 其他；④ 底部弹层单列选择 → OptionPicker 系（Modal sheet 已存在）；⑤ 左侧目录轨 → SideBar #18
五态适配默认态 ✅ 菜单栏各列=标题+当前值（次色小字）+▾；未选中=列标题默认占位；展开态 ✅ 激活列文案主色加粗、▾ 上翻、面板展开于栏下；选中态 ✅ 面板内选中行主色加粗；禁用态 ✅ 列级 disabled=整列灰不可展开、选项级 disabled=面板行灰 40% 不可点；加载/失败 N/A
与现有组件关系deps=[DesignTokens]；与 Cascader #24 划界=Cascader=多层级联逐层下钻、Menu=单层每列平铺单选；与 Picker #33 划界=Picker=单列值选择（内容常驻/弹层），Menu=菜单条驱动的下拉单选、选中回显到菜单栏；与 Popup #54=Menu 一期不依赖 Popup（内联展开），二期悬浮版再对齐

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
菜单栏高 44pt/44dp；列内文字 Md=16（标题主色；激活主色加粗）；当前值小字 Sm=12 次色（紧贴标题右、单行省略 ≤列 52%）整件高=44（收起）；列等分（≤4 列，超出=横滑）；点列=切换该列展开
展开面板行高 44pt/44dp；面板 max 高 220pt/220dp（=5 行）超出内部滚动；面板=栏下紧贴白底、行间 hairline展开态组件高=44+面板实际高（≤220）；收起高度恢复 44（宿主纵向布局随动=嵌入式核心）
▾ 指示列末箭头符 12 次色（激活列主色、上翻 180°=展开态）文本箭头（全库图标字符惯例）
选中/禁用色选中=primary 加粗 + 面板行左侧/无勾选（以颜色文字区分，同 Cascader 高亮惯例）；禁用=textTertiary 40%激活列=主色；其余列=默认主文字
数据驱动MenuColumn(key,title,options)（≤4 列）→ 每列展开=该列 options 单选；MenuOption(value,text,disabled)options 任一列可点展开（activeKey 半受控，见 P3）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件定位：ACE 三选

选项后果评估
A：嵌入式下拉单选菜单——菜单栏（≤4 列）+ 展开态在组件内部纵向下展面板（组件高=44+面板高，宿主纵向容器推挤下方）；无遮罩/无悬浮浮层；重复点当前展开列=收起✅ 收敛可验收：内容组件语义（同 Address/Cascader 无弹层先例）；双端实现纯布局+滚动=轻量可靠；宿主纵向内容流场景（页首筛选条/表单内）天然成立；选中回显菜单栏=核心闭环可 demo推荐 A：无浮层收敛（悬浮版二期）
B：悬浮式下拉（面板浮于页面内容之上 + 遮罩点外部收起）Popup #54 未实现；iOS 需 window/overlay 自建浮层、Android Popup 双端机制不齐（iOS 无自绘浮层先例）；遮罩+点击外部命中与层级管理面大淘汰：登记二期（随浮层机制立项）
C：弹层版复用 Modal（present 页面式 sheet）与既有 OptionPicker/日期选择 Modal 形态重复（底部全宽 sheet），非"菜单条下拉"语义；失去菜单栏回显特征淘汰：形态不符

P2 · 数据模型：ACE 三选

选项后果评估
A：MenuColumn(key, title, options) 列数组 + MenuOption(value, text, disabled) ——列 key=稳定 id、title=占位标题（未选中时显示）、options=该列单选池；外部按列 key 取选中 value 回显 title 位✅ 多列并排（筛选条多条件）结构化表达；title 与 options 分离=列常态可显示当前选中值；value 稳定落库；与 CascaderOption/TabItem 数据驱动惯例同构推荐 A：数据驱动惯例
B：扁平字符串数组（仅文案无 key/value）无法回显匹配（文案重复歧义）；列与列之间无法稳定索引外部驱动淘汰：缺稳定 value（同库惯例已弃）
C：由 Cascader 树（两列级联）充当多列Menu 多为平铺互斥列（排序/时间无级联关系）；级联树语义错位淘汰：模型不符

P3 · 状态控制：ACE 三选

选项后果评估
A：半受控——内部自管理展开列（activeColumnKey）+ 各列选中值（selected[key] map，默认每列 options 首启用项）；宿主可外部传 selectedValues 驱动回显（按列 key 匹配 option value 高亮+标题替换）；选中选项=onChange(columnKey, optionValue)；展开切换幂等（点当前展开列=收起）✅ 编辑回显/外部重置成立；展开态内部持有（宿主不用管开合）；与库内半受控惯例一致；map 以列 key 索引=多列各自独立推荐 A：库内惯例
B：纯受控（展开列与各选中值全由宿主 state 驱动）宿主需维护展开态+每列值两组状态并逐事件回填；开合交互与表单强耦合、重复状态可接受但过度
C：纯自管理仅通知最终值编辑回显/外部"重置筛选"驱动无门（多列场景尤甚）淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：嵌入式单选 Menu——≤4 列菜单栏 + 展开内联面板（选中高亮+disabled+max 220 内部滚动+点当前列收起）+ 选中回显菜单栏 + 半受控 selectedValues + demo 四段（单列基础/多列联动展开/长列表滚动含禁用/受控外部驱动）✅ 覆盖"筛选条单选下拉"核心闭环；展开列切换/收起/回显/禁用/滚动 demo 可逐验；无浮层无遮罩=验收路径清晰推荐 A：验收路径清晰
B：一期即含 遮罩悬浮浮层 + 多级子菜单浮层机制未立项（P1-B 问题）；多级=级联语义错位淘汰：登记二期
C：一期即做 联动筛选（列间级联+结果计数面板）筛选联动=业务逻辑（宿主职责）；复杂状态面一期不可控淘汰：宿主业务自理

05 · 平台差异表（表内放行，表外必须双端统一）

维度iOSAndroid放行原因
点击按压反馈UIButton touchDown 压暗瞬态clickable 系统 ripple系统级原生差异（同全库先例，表内放行）
等分/横滑UIStackView fillEqually / UIScrollViewRow weight / horizontalScroll系统布局机制不同、结果一致（表内放行）
面板滚动UIScrollView/UITableViewLazyColumn/verticalScroll平台滚动容器实现不同（表内放行）
高度推挤intrinsicContentSize 随展开态变化 + AutoLayout 链自动推挤Column 高度状态驱动下方节点位置命令式/声明式高度联动机制不同、宿主列内结果一致（表内放行）
文字省略UILabel truncateTailText ellipsis两端省略行为一致指向（表内放行）
尺寸单位 / 命名pt；MenuColumn/MenuOption struct + MenuViewdp；data class MenuColumn/MenuOption + @Composable MenuToken 同值不同单位；命名差异见门禁 B（表内放行）

端API
