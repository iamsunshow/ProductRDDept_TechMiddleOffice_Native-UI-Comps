Lottie 动画

组件 ID：ui.lottie ｜ 信息展示区组件 #70 ｜ TMO 组件库 v1.4.29

定位：渲染 Lottie/Bodymovin JSON 动画的容器组件——输入动画源（source）、是否自动播放（autoplay）、是否循环（loop）、播放速度（speed）、自定义尺寸（size），提供 play/pause/stop 播放控制接口与 onComplete 回调，用于加载状态、引导动画、品牌动效等场景。

1. 场景与边界（SCQA）

Situation 情景

App 中常需播放设计师从 After Effects 导出的 Lottie 动画（启动页引导、空状态插画动效、加载动画、点赞/收藏微交互等），这些矢量动画体积小、不失真，远优于 GIF/序列帧。

Complication 冲突

各业务页自行接入 lottie 库、各自封装播放控制与尺寸适配，源数据格式不一（本地 JSON / 远程 URL）、autoplay/loop 默认值不统一、播放/暂停/停止接口缺失，双端表现漂移且样板代码重复。

Question 问题

需要一个统一的 Lottie 动画组件，支持动画源接入、自动播放、循环、播放速度、自定义尺寸，提供 play/pause/stop 控制接口与播放完成回调，双端 1:1 视觉与 API 一致。

Answer 方案

Lottie——声明式动画容器组件，source 指定动画源（一期占位=动画名称，Lottie 库渲染=二期），autoplay 控制自动播放（默认 true），loop 控制循环（默认 true），speed 控制播放速度（默认 1.0），size 控制自定义尺寸，提供 play()/pause()/stop() 控制接口与 onComplete 回调。

7. API 速览

Lottie Props

参数类型默认值说明
sourceString""动画源标识（一期=动画名称占位，二期=Lottie JSON 文件名/路径）
loopBooleantrue是否循环播放
autoplayBooleantrue是否自动播放（挂载后立即播放）
speedFloat1.0播放速度（1.0=正常，0.5=慢速，2.0=快速）
sizeCGSize / Dp 尺寸自适应自定义动画尺寸（宽高），D4 自定义尺寸场景
onComplete(() -> Void)?null播放完成回调（仅 loop=false 时触发；循环模式不触发）

控制方法

方法说明
play()从当前位置继续播放（暂停后恢复）
pause()暂停在当前帧，不复位
stop()停止并复位到首帧
