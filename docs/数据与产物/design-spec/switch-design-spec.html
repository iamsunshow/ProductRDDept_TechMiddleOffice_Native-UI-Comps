Switch 开关 · 设计规格（数据录入组件 #41 · 任务清单 #41，subcategory=form · 门禁 A）

组件 ID：ui.switch ｜ 定位：通用二元即时开关（拨动式 on/off 状态切换）——轨道 + 滑块自绘、点按翻转开/关并回调，可嵌 FormFieldRow #28 / Cell 尾槽作行尾开关；无内置 label（label 文案=宿主行首）；checked 半受控（nil 内部自持 / 外部赋值驱动回显不触发 onChange）。对标 NutUI switch / Ant Design Switch 收敛为库内自有设计语言；与 Checkbox #25 / Radio #35 明确区分：Switch=二元即时持久开关（点按翻转开闭）；Checkbox=方形复选可多选可取消（表单勾选确认）；Radio=圆形排他几选一（点选即确定）。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-06，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 二元即时状态开关（通知提醒开关、仅 Wi-Fi 下载、自动同步、深色模式等"即时开/关、状态持久"设置项）；② 行尾开关=FormFieldRow #28 / Cell 尾槽嵌用（label 文案走宿主行首，开关只出开闭核）；③ 表单布尔提交（接受条款=开 才可提交=由宿主校验）；④ 编辑回显：宿主已持 checked，外部 value 驱动开/关回显
不适用（N/A）① 几选一排他（性别/支付方式离散单选）→ Radio #35；② 复选集合/多选勾选（可多选可取消需集合结果）→ Checkbox #25；③ 连续区间/数值调节 → Range #36 / InputNumber #30；④ 下拉选填（选项多需承载层）→ Picker #33 / Menu #31；⑤ 分段高频切换页签 → Tabbar / Tabs / Segmented #74；⑥ 开关带 label 文案自持=宿主行首职责（Switch 核组件不内置行组件）
五态适配默认态 ✅ off=灰轨道（textSecondary 30% 底）+ 白色滑块居左；选中态 ✅ on=primary 轨道 + 白色滑块居右（点按翻转）；禁用态 ✅ 整件 40% 灰不可点无回调（on+禁用=灰 primary 轨道灰滑块保留开态只读）；加载/失败 N/A（宿主自理）
与现有组件关系deps=[DesignTokens]；与 FormFieldRow #28 兼容=Switch 作 trailing 尾槽（label/校验走行，高度随行内嵌）；与 Cell 内容区/trailing 兼容；与 Checkbox #25 / Radio #35 / Rate #37 半受控状态惯例同构=外部赋值驱动不触发 onChange；与 iOS 系统 UISwitch / Android Material Switch 划界=库内自绘不套系统控件

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
轨道48pt/48dp 宽 × 28pt/28dp 高，radiusFull 圆角；on=primary 填充、off=textSecondary（alpha 0.3）浅灰填充48 宽=交互行基准注释锚定（同 Input #29 / FormFieldRow min 48 语义），28 高=20 滑块 + 上下内衬各 4（spaceXs）
滑块 thumb白色 20pt/20dp 圆形，轨内上下左右内衬 4（spaceXs）；off=左对齐，on=右对齐（行程 20 = 48 − 2×4 − 20）20=对齐 CheckboxGlyph / RadioGlyph 20 惯例；滑块白色=轨道高对比可见（浅灰/primary 底均清晰）
切换动效滑块位移 + 轨道变色 0.18s（同 FixedNav 展开/收起 0.18s 动效时长惯例）双端 0.18s 线性/缓动=跟手短反馈；动画仅位移动态非布局抖动
禁用态disabled=整件 alpha 0.4（轨道/滑块/已有开态灰呈现），不可点无回调on+disabled=灰 primary 轨道灰滑块保留=只读回显语义（同 Checkbox 已选禁用）
命中区整枚开关（轨道框）可点=点按翻转；行内嵌时宿主行可自行加宽命中区核组件命中=轨道自身，放大命中=宿主组合（Cell/FormFieldRow 可点区）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件形态：ACE 三选

选项后果评估
A：独立通用二元开关核组件 Switch（轨道+滑块自绘，无内置 label），宿主按需嵌 FormFieldRow/Cell 行尾；开/关=checked Bool 布尔、onChange 回调✅ 最小原子可复用（任何"即时开/关"场景一套 API）；label 归宿主=不重复造行组件、与 FormFieldRow/Cell 组合天然契合（同 Picker #33 工具栏/CalendarCard 嵌入先例"组件只做内容块"）；双端自绘=视觉 100% 可控推荐 A：纯开/关核组件
B：Switch 自带 label 行组件（行组件含文案+开关+整行命中）label/布局/校验全内聚=一组件成行；但与 FormFieldRow #28 / Cell 职责重叠（行结构宿主已有），组件库重复造行=组合心智负担淘汰：行结构归宿主（同 Checkbox/Radio 仅出核组件的定位）
C：复用系统开关（iOS UISwitch / Android Material Switch）包壳iOS UISwitch 尺寸/轨道色/thumb 系统定制弱、与库 token 语言脱节；Android Material Switch 受 Material 主题/状态变量约束、视觉不一致=组件库自绘惯例违背淘汰：双端自绘轨道+滑块

P2 · 数据模型：ACE 三选

选项后果评估
A：checked: Boolean?（当前开/关；nil=内部自持初始 off）+ onChange(Boolean) 回调✅ 二元态布尔=原生布尔直落库（true/false 无映射歧义）；nil=自持、外部赋值=驱动回显=库内半受控惯例一致推荐 A：Bool 半受控
B：value: String（"on"/"off" 或自定义激活值）开关语义=纯布尔，字符串映射徒增落库转换、外部回显解析成本淘汰：二元状态 String 无增益
C：checked 三态（on/off/null 中间半选态）中间态=半选/未知语义（复选嵌套场景），非开关二元语义=Checkbox indeterminate 范畴淘汰：登记二期/不属开关职责

P3 · 状态控制：ACE 三选

选项后果评估
A：半受控——checked（Bool?）可选传；nil=内部自持初始 off（点按翻转并回调 onChange(新值)）；外部赋值 checked=同步刷新渲染（编辑回显/重置）不触发 onChange（同 InputNumber/Menu/Checkbox/Radio 惯例）；点按=翻转（on→off 与 off→on 均回调）；disabled=不可点无回调✅ 宿主无状态=自持开/关；编辑回显=外部驱动；两种路径语义清晰=库内状态惯例完全一致推荐 A：库内半受控惯例
B：纯受控（checked 必传，每次点按宿主回写）简单受控无内部态；但宿主必须每次回写，未传即不可用（灵活性弱于 A）可接受但过度（A 的超集）
C：纯自管理（不暴露 checked 外设）编辑回显/重置驱动无门（同 Menu P3-C / Radio P3-C 结论）淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：轨道+滑块核组件+开/关动画 0.18s+checked 半受控+disabled（含 on 灰保留）+onChange+demo 四段（基础开/关回显·行尾嵌 FormFieldRow/Cell·disabled 锁定·受控外部驱动）✅ 开关核心闭环（翻转/动画/禁用/外部回显/回调）逐项可验；无自定义颜色/尺寸膨胀=验收路径清晰推荐 A：核心闭环可验收
B：一期含 loading 状态/延迟提交开关（async onChange 提交中转圈）异步提交流=宿主提交链路职责（同按钮 disabled/loading=宿主），开关核不做请求状态机淘汰：宿主自理
C：一期含 activeColor/轨道背景自定义色、thumb 尺寸/轨道尺寸参数、滑动拖拽手势配色/尺寸参数化=定制面扩大（Checkbox/Radio 亦未做颜色参数）；拖拽滑动手势=双端手势几何对仗成本+一期点按即翻转已满足主场景淘汰：登记二期（尺寸/配色参数、拖拽）

05 · 平台差异表（表内放行，表外必须双端统一）

维度iOSAndroid放行原因
轨道/滑块绘制UIView layer（轨道圆角背景色+滑块白色圆角子视图，on/off 改颜色/位置）Compose Box（clip RoundedCornerShape(999)+背景色+滑块 offset x 位移）平台绘制机制不同、视觉一致（表内放行，同全库先例）
切换动画UIView.animate(duration:0.18) 改滑块 frame/约束 + 轨道背景色animateDpAsState/animateColorAsState（tween 180ms）驱动 offset/颜色两端动画时长一致 0.18s、实现 API 不同（表内放行）
点击命中UIControl touchUpInside / UITapGestureRecognizer 整枚可点Box clickable 无涟漪（同库开关无涟漪惯例）两端命中一致=整枚、机制差异（表内放行）
状态回写命令式：外部赋值 checked → 显式刷新滑块位置/轨道色（demo onChange 宿主回写）声明式：checked 参数变化自动重组命令式/声明式机制不同、宿主回写后视觉一致（库内惯例，表内放行）
尺寸单位 / 命名pt；SwitchView（独立 Switch.swift）dp；@Composable Switch（Switch.kt）Token 同值不同单位；命名差异见门禁 B（表内放行）
无障碍VoiceOver：isAccessibilityElement+label+value（开/关语义 UIAccessibilityTrait）TalkBack：语义/checked 状态系统无障碍层各读屏实现不同（表内放行）

06 · API 草案（双端一致契约，门禁 B 据此登记 api.json）

端API

Android@Composable fun Switch(checked: Boolean?, onCheckedChange: (Boolean) -> Unit, disabled: Boolean = false, modifier)
