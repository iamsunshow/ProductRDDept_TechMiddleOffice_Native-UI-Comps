Range 区间选择 · 设计规格

组件 ID：ui.range 数据录入区 #36 subcategory=form 全新立项（双端从零，无近似收编） 设计稿 2026-09-06 门禁 A

01 · SCQA 组件定位与边界

适用场景（S）

表单/筛选/图表常需「区间值」录入与过滤：① 数值区间筛选=价格、金额、里程、时长、热量等两端定界（报表金额 0–5000、跑量 5–20km）；② 数值区间录入=身高体重区间、设备尺寸范围等（比双 InputNumber 更直观、拖动手感连续）；③ 图表明细过滤条=两端定界后宿主旁路显示边界值与单位（同 #33 Picker/#25 Checkbox 半受控+宿主自布先例，组件壳不含 label/单位行）。

目标与冲突（C）

需求=「拖出/拖窄一个区间」的直觉；冲突=双独立 InputNumber 无联动会互越界、不连续、双端各写一套质量漂移；单值 Slider 表达不了区间；系统控件（UISlider/SeekBar）均单钮且视觉脱离库内设计语言。

问题（Q）

库内是否新增通用「Range 双钮区间滑块」内容组件？

答案（A）

定位 是。新增 ui.range=横向双滑块区间选择内容组件：一条共用轨道+左右两枚滑块（start/end 闭区间，start≤end 恒成立，可相等=零宽单点），拖动任一端连续调整、点轨道空段=最近端吸附跳位；数值 Double 承载、宿主格式化单位展示；半受控 value + min/max/step + disabled；无壳（同 #25/#35 划界=壳/单位/校验归 FormFieldRow #28 或宿主）。

五态适配

默认态 ✅ 轨道未激活段=textSecondary 30% 灰、start~end 激活段 primary；两钮=白底圆形 20 + primary 描边 1.5，按钮悬停无态；拖动态 ✅ 拖动中钮吸附 step 粒度、激活段随钮实时刷新、值实时回调（钮视觉不变，拖动=命中态无额外描边）；禁用态 ✅ disabled=整条 textSecondary 40% 灰、钮不可拖/轨道不可点、无回调；边缘态 ✅ start=end=零宽单点（激活段宽度 0）合法；值域外（宿主改 min/max 致越界）=自动 clamp 到边界并回显不触发 onChange；start=min 或 end=max 钮贴边合法；加载/失败 N/A（内容组件无内部状态，宿主自理）。

划界与依赖

依赖=DesignTokens（AppColor/AppFont/AppSpace）。与同区组件划界：InputNumber #30=步进点按改单值、无区间联动（Range=连续拖动双端区间）；RadioGroup #35 / Menu #31=离散枚举档位少量互斥（Range=连续或大档位数值区间）；Switch #41=二元开关；Rate #37=整数评价 0–5 星点（离散且非区间）；date-range 日历区间=日期非数值不走滑轨；未来 Slider 单钮单值组件若立项与 Range 划界（Range=区间语义专用）。业务方（记账报表金额区间等）复用本组件，宿主自理单位/刻度文案。

03 · 关键决策（P1–P4 投票表）

P1 组件形态（区间 vs 单值 vs 系统控件）

选项方案后果结论
A双钮区间 Range：单轨道+start/end 两钮、激活段高亮、点轨道吸附最近端（对标 Vant Range/NutUI Range 语义收敛为库内设计语言）完整表达区间；实现=钮拖动手势+几何换算，成本可控A 推荐 ✅
B仅单钮 Slider（连续单值）无法表达区间两端；单值场景可用但需求缺口仍在淘汰（登记 Slider=若未来需要单立项）
C系统控件 UISlider/SeekBar + 双实例伪装双实例无联动钳制、视觉脱离库内设计语言、双端体验分裂淘汰

P2 数值模型（数值类型与值域参数）

选项方案后果结论
ADouble 全域：RangeValue(start,end)+min/max/step 均 Double；step>0 且 ≤(max−min)（超界=参数注释断言）整数/小数/价格金额通用，宿主展示格式化，无泛型复杂度A 推荐 ✅
BLong/Int 整数专用小数区间（如步长 0.5）不可表达=必须另立件淘汰
C泛型 <T: Comparable>实现与数值换算显著复杂化，收益低淘汰

P3 状态与事件（半受控/回调/禁用/钳制）

选项方案后果结论
A半受控：value RangeValue? 可选（nil=内部自持且初始区间 [min,max]=「全选=不过滤」语义）；外部赋值（含 clamp 后）仅同步回显不触发 onChange；点/拖=onChange 连续回调（每次 step 对齐后），宿主回写；start≤end 钳制恒成立（不可越过对方=另一钮做硬挡板）、可相等零宽；min/max 动态改→越界端自动 clamp；disabled 组级与 #25/#35 半受控惯例一致；表单/筛选双场景通吃A 推荐 ✅
B纯受控必传 value+无内部态宿主每次 pointer 事件自管理全部状态=API 繁重淘汰
C纯自管理无外部驱动无回显能力，宿主无法受控回卷淘汰

P4 一期裁剪与 Demo 四段

选项方案后果结论
A一期=横向区间双钮+step 吸附+点轨道吸附最近端+disabled+半受控+min/max 动态 clamp+demo 四段：D1 基础区间（min0 max100 step1 [25,75] 拖动实时回显两端值）｜D2 离散步进（step 5）+点轨道跳钮（点空段最近端吸附演示）｜D3 值域与禁用（动态改 min=60 越界自动 clamp+禁用开关+外部重置）｜D4 受控外部 value 驱动（预设外部赋值同步点亮，不触发 onChange）主路径+关键边界全覆盖；无刻度无气泡=视觉干净依赖宿主文案A 推荐 ✅
B一期含刻度 mark/数值气泡 tooltip离散档位视觉+绘制与命中显著膨胀=一期不必要二期候选
C一期加 onDragStart/onDragEnd/节流事件宿主可自节流；事件面扩大的收益低于成本淘汰（宿主自理）
