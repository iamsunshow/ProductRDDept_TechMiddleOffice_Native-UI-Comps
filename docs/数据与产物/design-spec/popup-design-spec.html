Popup 弹出层

组件 ID：ui.popup ｜ 任务清单 #54 ｜ 操作反馈区第九件 ｜ TMO 组件库 v1.4.4

定位：通用弹出层容器——居中/底部/顶部弹出，带遮罩，承载任意自定义内容（表单/卡片/广告/自定义确认等），可关闭。

1. 场景与边界（SCQA）

Situation 情景

业务需要弹出一段自定义内容（登录表单/广告卡片/活动弹窗/自定义确认面板），内容结构不固定，ActionSheet（操作列表）/Dialog（标题+按钮）无法承载。

Complication 冲突

没有统一组件时=各业务页自拼 UIViewController(iOS)/Dialog(Android)，视觉不统一、无 position 切换、无 closeable、无 closeOnClickOverlay。

Question 问题

需要一个通用弹出层容器，支持 position 居中/底部/顶部、closeable 关闭按钮、closeOnClickOverlay 遮罩点击收起、content 内容槽，双端视觉一致。

Answer 方案

Popup——通用弹出层容器，受控 visible + content 内容槽 + position 三向 + closeable + closeOnClickOverlay + 遮罩 + 动画（不内置预设内容，纯容器承载宿主内容）。

3. API 契约

Props

参数类型默认值说明
visibleBoolean必传是否展示（受控）
contentComposable / UIView必传弹层内嵌内容槽（宿主自定义）
positionPopupPositioncenter弹出位置：center/bottom/top
closeableBooleanfalse是否显示右上角关闭按钮
closeOnClickOverlayBooleantrue点击遮罩是否收起（触发 onClose）

onClose(() -> Unit)?null弹层收起回调（closeable/closeOnClickOverlay/外部 visible=false）

4. 设计规格

4.1 布局结构

区域规格Token
遮罩全屏 black 45% 透明overlay scrim
弹层容器白底，圆角按 position 变化bgCard / radiusLg
内边距content 槽外不加 padding（宿主自管）—
关闭按钮右上角 24×24 圆形灰底白叉，closeable=true 时显示gray6 / radiusFull
底部安全区position=bottom 时 safeArea bottom paddingSafeArea #7

4.2 交互规格

交互行为
展开遮罩淡入 200ms + 弹层按 position 动画（center=淡入缩放，bottom=底部滑入，top=顶部滑入）
收起-关闭按钮closeable=true 时点击关闭按钮 → 弹层退出动画 + 遮罩淡出 → onClose()
收起-遮罩点击closeOnClickOverlay=true 时点击遮罩 → 弹层退出 + 遮罩淡出 → onClose()
收起-外部控制外部 visible=false → 弹层退出（不触发 onClose）

8. 反目标（anti_goals）

不做原因
预设确认对话结构（标题+内容+按钮）用 Dialog #46
预设操作列表用 ActionSheet #44
无遮罩小气泡用 Popover #53
拖拽收起（下拉手势）二期增量，一期 closeable+遮罩点击够用
嵌套 Popup（Popup 内 Popup）复杂场景用多级页面导航
自定义动画曲线一期统一 center=200ms/bottom+top=250ms，曲线参数=二期
