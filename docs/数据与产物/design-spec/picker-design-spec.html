Picker 选择器 · 设计规格（数据录入组件 · 任务清单 #33，subcategory=input · 门禁 A）

组件 ID：ui.picker ｜ 定位：单列滚轮选择器内容视图（数据驱动 options → 滚轮列选 → 顶部工具栏取消/标题/确定确认回调）——组件=「工具栏（44）+ 单列滚轮可视区（220=5 行×44）」的完整选择内容块，无遮罩无自绘浮层，宿主自行承载（页面卡片内嵌 / 系统 sheet 弹层承载均成立）；受控 value 决定初始滚停与外部回滚定位，用户滚动后点「确定」回调 onChange(value)、点「取消」不回调；选项级 disabled 灰显且滚掠不可停靠。对标 NutUI Picker 收敛为库内自有设计语言（单列 + 工具栏 + 滚轮吸附）；iOS 收编自 OptionPickerSheetViewController（pageSheet 320pt 单列滚轮 + 顶栏取消/确定）组件化重构，Android 从零实现；滚动吸附/阻尼行为表内放行。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-06，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 弹层单选枚举：宿主用系统 sheet/页面弹层承载本组件内容块，用户滚轮选值 → 确定回调（对齐既有记账「OptionPicker 单列滚轮弹层」用法）；② 卡片内嵌直接选择：页面表单卡片中嵌入 220pt 滚轮，滚动 + 确定确认；③ 连续/长枚举单选：频率/天数/额度/省份等 12+ 项的纵向滚动选择（行高 44 点按精度高于横向多选项）；④ 编辑回显：宿主已持 value，组件初始滚停该项并外部可回滚定位
不适用（N/A）① 级联/多级联动列选 → Cascader #24 / 二期多列；② 菜单条驱动下拉单选（平铺面板）→ Menu #31；③ 日期/年月日专用选择 → date-picker #26 / date-picker-month #27（未来可复用 #34 基础滚轮，不属本件）；④ 基础多列滚轮视图（无工具栏、滚动即回调）→ picker-view #34（二期基础件）；⑤ 文本输入/搜索 → Input #29；⑥ 记账分类五列网格（强业务 BookkeepingCategory）→ business.category-picker 收编件不动
五态适配默认态 ✅ 工具栏（取消/标题/确定）+ 单列滚轮，value 对应行居中等高亮（primary 加粗）；滚动态 ✅ 行纵向滑动、顶部/底部渐隐，停靠行=临时选中；选中态 ✅ 确定后 onChange 回调 value、行保持高亮；禁用态 ✅ 选项级 disabled=行灰 40% 且滚掠不可停靠；组件级 disabled=滚轮整体灰不可滚；加载/失败 N/A（无网络语义）
与现有组件关系deps=[DesignTokens]；iOS 收编 OptionPickerSheetViewController（modal .pageSheet detent 320pt、UINavigationBar 取消/确定、UIPickerView 单列、onConfirm(Int index)）→ 组件化：OptionPickerOption{value,text,disabled} 数据驱动 + 回调改传 value；宿主演示沿用系统 sheet 呈现法（弹层机制=宿主职责，不依赖 Popup #54）；与 #34 picker-view 划界=picker-view=无工具栏纯多列滚轮基础件（滚动即回调 onChangeIndex，供 Picker/DatePicker 复用，二期立项），Picker=带确认语义的完整单列选择器（确认前不提交、取消可撤销）

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
工具栏高 44pt/44dp 白底 bgCard；取消=左 14（sizeSm）textSecondary；标题=中 16（sizeMd）textPrimary 加粗 600、可省略；确定=右 16（sizeMd）primary 加粗 600；底部 hairline 与滚轮区分隔取消=关闭不回调；确定=onChange 回调（可隐藏确定=纯取消关闭？一期固定显示）；标题默认「请选择」宿主可传 title
滚轮可视区高 220pt/220dp=5 行×44（固定，宿主无需传）；行高 44pt/44dp；行内文字 Md=16 textPrimary 居中；选中行 primary 加粗 600iOS 用 UIPickerView 设置 rowHeight=44 + 原生渐隐/分隔线；Android 自绘 LazyColumn 滚轮=上/下 1pt hairline 夹选中带 + 顶底 70dp 线性渐隐（同右侧 mock）
选中带选中行上下分隔 hairline 细线（iOS 系统内置灰线样式 vs Android 自绘 0.5/1px 线，表内放行）视觉=中部第 3 行为当前候选（5 行中的中心带）
禁用/状态色选项 disabled=textTertiary（40% 灰）；组件 disabled=整体 alpha 40% + 不可滚disabled 行滚掠不可停靠：拖动/惯性结束后校正吸附到最近可用行（两平台实现见平台差异表）
数据驱动options: [PickerOption{value,text,disabled}] → 单列映射行；value=受控选中值行文案=text；行值=value；text 超宽单行省略居中（max 90% 列宽）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件定位：ACE 三选

选项后果评估
A：嵌入内容式「单列滚轮选择器块」——工具栏(取消/标题/确定)+单列滚轮(220)完整内容组件，无遮罩无自绘浮层，宿主自行承载（页面卡片内嵌 / 系统 sheet 弹层承载）；确定=onChange、取消=不回调；受控 value✅ 收敛可验收：继承 iOS OptionPicker 既有用法（宿主系统 sheet）语义不回归；内容组件与全库无弹层先例一致（Address/Cascader/Menu/NumberKeyboard 同构）；单列范围=验收路径清晰；确认/取消语义=编辑撤销天然成立推荐 A：内容块+宿主承载收敛
B：自带底部弹出浮层完整 Picker（含遮罩+背景+容器+动画）Popup #54 未实现；双端浮层机制不齐（iOS 可用原生 sheet 但组件自绘遮罩=重造 Overlay）；遮罩/点外部/动画面大淘汰：登记二期（随浮层机制立项，宿主弹层已可用）
C：淘汰登记、只留 picker-view #34 纯滚轮基础件通用确认语义（取消/确定/标题）+禁用滚掠校正+受控回滚定位将无处安放（#34 定位=无确认的裸滚轮）；业务「弹层选一项确认」高频场景仍需宿主拼工具条=重复代码淘汰：#33 独立价值成立

P2 · 数据模型：ACE 三选

选项后果评估
A：options: [PickerOption{value, text, disabled?}] + value（受控）——value=稳定落库值、text=滚轮行文案、disabled=禁停靠灰显行✅ 与 api.json ui.picker 现有契约一致（props options{label,value}[] + value:string + onChange(value)）；value 稳定、双端 demo 回显匹配无歧义；禁用行可在滚轮内可视化推荐 A：延续 api.json 契约
B：仅纯文案数组 [String]（iOS 收编现状）文案重复歧义；外部驱动 value 无法稳定匹配；disabled 行无法表达淘汰：升级为 value/text 数据驱动（同库惯例）
C：泛型值（T 任意类型）双端桥接序列化/相等性歧义；库内惯例 value 均为 string（Cascader/Menu/TabItem）淘汰：value 统一 string

P3 · 状态控制：ACE 三选

选项后果评估
A：受控 value（外部持有）+ 滚动临时选中（内部可视态）——初始 value 滚停定位；滚动过程内部临时态（可视高亮跟随滚轮）；点确定=onChange(value) 提交、点取消=丢弃临时态不回调；外部 value 变更→滚轮回滚定位（不触发 onChange）✅ 与 api.json「value 必填 + onChange 确认」契约一致；确认前不提交=编辑安全；外部回滚定位=编辑回显成立；组件内部仅临时可视态=状态面小推荐 A：受控+确认提交
B：半受控（value 可缺省内部自持、外部可选驱动）缺省自持=「滚动即改值」语义需另定（无外部同步源）；取消/确定存在两套内部值同步回路=易错可接受但确认语义下冗余
C：纯自管理仅通知最终值编辑回显/外部重置 value 无门；与 api.json 契约（value 必填受控）冲突淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：一期=单列滚轮选择器：工具栏（取消/标题/确定）+ 受控 value + 选项 disabled（灰显滚掠不可停靠）+ 组件级 disabled + 行高 44 滚轮 220 + demo 四段（单列基础确认/取消回显、长列表+禁用掠行、受控外部回滚定位、宿主 sheet 弹层用法）✅ 覆盖「单选枚举确认」核心闭环；四段把滚动/确认/禁用/受控/弹层宿主路径逐验；iOS UIPickerView 直接封装+Android 自绘滚轮工作量收敛；与 #34 picker-view 划界清晰（多列/滚动即回调二期）推荐 A：验收路径清晰
B：一期即含多列/联动列选联动=Cascader 已覆盖；多列滚轮=#34 基础件范畴；单列未闭环前扩列面失控淘汰：登记二期（随 #34 picker-view 基础件）
C：一期即做搜索/虚拟长列表/循环滚轮枚举单选一般 ≤ 200 项（LazyColumn/UITableView 均原生支持）；搜索=Input 组合职责；循环滚轮双端惯性机制不对齐淘汰：登记二期或 N/A

05 · 平台差异表（表内放行，表外必须双端统一）

维度iOSAndroid放行原因
滚轮本体UIPickerView 原生（rowHeight=44、原生渐隐/阻尼）自绘 LazyColumn 滚轮（上/下 hairline 夹选中带 + 顶底线性渐隐）滚轮=系统差异最大的控件，视觉五态（选中带/渐隐/行高 44）双端对齐、内层实现表内放行
滚动阻尼/惯性UIScrollView 原生 decelerationsnapFlingBehavior 最近行吸附系统滚动物理差异（表内放行），停靠行语义双端一致（第 3 行=候选）
disabled 掠行校正willEndDragging 时吸附最近可用行；选中行变更即临时态fling/拖动停止后 snap 到最近可用行触发时机平台实现不同、结果一致=不可停靠禁用行（表内放行）
工具栏承载原生 UINavigationBar item 风格（iOS 收编既有形态）Row 自绘（左次色/右 primary 文本钮）平台导航栏规范差异、布局结果一致（表内放行）
弹层承载宿主 .pageSheet modal（收编原用法）宿主 Dialog/sheet 承载内容组件=内容块无遮罩，弹层机制宿主自理（表内放行）
尺寸单位 / 命名pt；struct PickerOption + PickerView（UIKit）dp；data class PickerOption + @Composable PickerToken 同值不同单位；命名差异见门禁 B（表内放行）

06 · 接口契约草案（门禁 B 定稿）

类别名称类型必填说明
参数 propsoptionsPickerOption[]是单列选项池；PickerOption{value:string, text:string, disabled?:boolean}
valuestring是（受控）当前选中值；决定初始滚停与外部回滚定位；非法/disabled 值回落首个可用行展示
disabledboolean否组件级禁用=滚轮整体 40% 灰不可滚
title / cancelText / confirmTextstring否工具栏文案，默认 请选择 / 取消 / 确定
事件 eventsonChange(value: string) => void—点「确定」提交当前可视行 value；点「取消」不回调
（取消）——取消=组件无事件、临时态丢弃、滚轮回滚 value 行；关闭动作宿主自理
数据模型PickerOptionstruct / data class—value（稳定值）、text（行文案）、disabled（禁停靠灰显）

07 · 验收清单（门禁 A → 双端实现 → C1.5 demo 实机）

  • 视觉：工具栏 44 + 滚轮 220 = 整件 264pt/dp；选中带=第 3 行候选语义；行高 44；选中行 primary 加粗、普通 textPrimary、禁用 textTertiary 40%；顶底渐隐双端目视一致
  • 交互：滚轮惯性滚动停靠整行；disabled 行灰显且掠行不可停靠（自动吸附最近可用行）；确定=onChange 提交可视行；取消=回滚 value 行
  • 受控：外部 value 变更滚轮 scrollTo 定位（不触发 onChange）；初始 value 定位
  • 禁用：组件级 disabled 滚轮不可滚整体 40%
  • Demo：D1 基础确认/取消、D2 长列表+禁用掠行、D3 外部回滚定位、D4 宿主 sheet 承载用法——双端 1:1 可逐验
  • 工程：无新依赖（UI 系统自带）；iOS UIPickerView 封装 + Android 自绘滚轮；demo 注册占位接线
