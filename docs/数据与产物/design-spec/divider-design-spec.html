Divider 分割线 · 设计规格（布局组件 #1，subcategory=layout · 门禁 A）

组件 ID：ui.divider ｜ 定位：区隔内容分割线，对标 NutUI Divider / Ant Design Divider。
组件库版本 设计阶段锁定基线 = v1.4.0

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 列表/表单区域间的水平分隔；② 内容分区带文本标注（如"—— 或 ——"）；③ 行内垂直分隔（如菜单项之间）；④ 虚线分隔（历史/时间线风格）
不适用（N/A）① Cell 组件内置的底部 1px 分隔线（已内建于 Cell.showsDivider）；② 卡片边框/分隔 → 用 Card border；③ 间距留白 → 用 Space（ui.space）
五态适配Divider 为"纯展示"组件，无交互。默认态 ✅ = 分隔线正常展示。点击/禁用/加载/成功/失败 全部 N/A（分隔线无状态切换需求）
与现有组件关系deps=[] 无硬依赖。内部引用 DesignTokens（AppColor/AppSpace/AppFont）零硬编码。Android 现有 HorizontalDivider 内联用法（CommonComponents/ProfileListGroup）可替换为独立 Divider 组件。

02 · 尺寸/颜色 Token 规格（零硬编码）

要素Token数值说明
线条颜色AppColor.border#E5E7EB与 Cell 分隔线一致，跟随主题
线条粗细（hairline）像素级 1px / 0.5dpiOS: 1/scale pt，Android: 0.5dphairline 模式（默认），与 Cell 分隔线一致
线条粗细（非 hairline）1dp / 1pt普通粗细非 hairline 模式
文本字号AppFont.sizeXs12带文本分割线时的文字大小
文本颜色AppColor.textSecondary#6B7280次要文字色
文本与线条间距AppSpace.sm8文本左右两侧到线条的间距
上下外边距AppSpace.sm8分割线上下留白

03 · 关键决策 PREP / ACE（4 条，编号 P1–P4，待用户门禁 A 表决）

P1 · hairline 默认值：ACE 三选

选项后果评估
A：hairline 默认 true（0.5px 细线）✅ 与 Cell 分隔线视觉一致，双端均使用像素级细线。推荐 A：与现有组件风格统一
B：hairline 默认 false（1px/dp 普通线）更粗更显眼，可能更适合某些设计稿。淘汰：与 Cell 不一致
C：不暴露 hairline prop，固定细线简化 API 但失去灵活性。淘汰：NutUI 有此 prop，保留灵活性

P2 · 虚线（dashed）支持：ACE 三选

选项后果评估
A：支持 dashed prop（默认 false）✅ 与 NutUI 对齐，iOS CAShapeLayer dashPattern / Android PathEffect 实现。推荐 A：NutUI 标准能力，实现成本低
B：不支持虚线简化但缺失能力。淘汰：NutUI 有此能力
C：支持 dashed + 自定义 dash 间距过度设计。淘汰：MVP 不需要

P3 · 文本位置（contentPosition）：ACE 三选

选项后果评估
A：支持 left/center/right 三个位置✅ 与 NutUI 完全对齐。推荐 A：NutUI 标准能力
B：仅支持 center简化但不够灵活。淘汰：限制使用场景
C：支持位置 + 自定义间距过度设计。淘汰：MVP 不需要

P4 · 垂直方向（direction）：ACE 三选

选项后果评估
A：支持 horizontal + vertical✅ 与 NutUI 完全对齐。vertical 用于行内分隔。推荐 A：NutUI 标准能力
B：仅支持 horizontal简化但缺失垂直分隔能力。淘汰：NutUI 有 vertical
C：支持方向 + 自定义角度过度设计。淘汰：不需要
