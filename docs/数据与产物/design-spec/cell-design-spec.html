01用途与场景

Cell 是列表页的最小行单元，用于承载"一项设置 / 一条记录"的入口或信息展示。
  • 典型场景：设置页每行（如「账号与安全 >」）、个人中心信息行（头像/昵称）、明细页静态信息行（交易时间 / 单号）。
  • 组合关系：可承载 Icon / Avatar / Badge 于左侧；右侧承载 Switch / Tag / 自定义控件（由业务组合）。
  • 反模式（anti-goals）：不做整页容器（用 List）、不做流水数据行（用 ListItem）、不做宫格入口矩阵（用 Grid）。

    05交互细节

  • 点击：可点击 Cell 整体可点，按下态 gray.4；带箭头默认暗示可点击。
  • 事件：onClick（点击回调，参数为 cell 索引/数据）；onLongPress 可选（iOS 长按；Android 不承诺，标注差异）。
  • 层级：Cell 本身无弹窗层级；右侧 Popup 类控件由业务弹层承载。
