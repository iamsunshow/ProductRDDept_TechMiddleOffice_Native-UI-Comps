# 双端平台差异白名单（platform-diff）

> 允许的系统级原生差异登记表。**白名单之外的视觉/行为差异一律禁止**。
> 配套：`docs/设计规范.md` 第四节；验收门禁 A 检查项（`docs/验收流程/验收标准.md`）。

## 白名单

| 项 | iOS | Android | 备注 |
|----|-----|---------|------|
| 手势 | UIGesture | GestureDetector | 系统行为 |
| hover | 无 | 有 | Android 支持 hover 态 |
| 键盘 | 系统键盘 | IME | 系统行为 |
| 控件默认样式 | UIKit | Material | 需覆盖对齐 |
| 按压反馈（Cell） | UILongPress/Highlight | Ripple 水波纹 | 平台原生差异；Cell 按下态统一覆盖为背景 `gray.4`，水波纹不扩散至 Cell 外（登记自 cell-design-spec.html 06 节） |
| 长按事件（Cell） | 支持 `onLongPress` 回调 | 不承诺（契约声明，Android 侧不暴露） | 能力差异（登记自 cell-design-spec.html 06 节 + api.json `ui.cell` events） |
| 图标参数类型（Cell） | `iconSymbol: String?`（SF Symbol 名） | `icon: Painter?`（资源映射层传入） | 平台资源体系差异（SF Symbols vs Vector Drawable），契约字段名 `icon` 双端一致 |
| 点击事件签名（Cell） | `onTap(_ item, _ index)` | `onClick: (() -> Unit)?`（数据+索引由调用方闭包绑定） | 平台惯例差异（Compose `() -> Unit`），事件名 `onClick` 双端一致 |

## 登记规则

1. 出现双端差异 → 先评估是否**系统级原生差异**：
   - 是 → 登记到本表（注明原因）。
   - 否 → 双端必须统一，禁止差异化。
2. 未登记即差异化 → 视为违规，验收门禁 A 打回。
3. 已有条目如需修改 → 走组件治理变更（`docs/治理规范.md`），不能私自改。
