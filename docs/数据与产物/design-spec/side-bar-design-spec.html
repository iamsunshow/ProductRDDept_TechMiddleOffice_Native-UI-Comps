SideBar 侧边导航 · 设计规格（导航组件 #5 · 任务清单 #18，subcategory=navigation · 门禁 A）

组件 ID：ui.side-bar ｜ 定位：页面内容区左侧的竖排目录导航轨（垂直单选导航）——左侧固定窄轨列出分组标题，点选激活并高亮，右侧内容区联动切换/滚动定位由宿主接 onChange 自理；对标 NutUI React SideBar（value 受控 + SideBar.Item + onChange）收敛为库内自有设计语言（目录轨 + 选中持久态）。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-04，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 商品分类/账单分组/城市目录等"左侧目录轨 + 右侧内容联动"的页面形态——左侧窄轨列出分组标题，选中项常驻高亮，点选触发 onChange 由宿主切换右侧内容或滚动定位（设置分组列表、月份/账单类别、字符索引目录等）；② 分组项数量较多时 rail 自身可滚动，选中项自动滚入可视；③ 单轨单选，选中态持久清晰
不适用（N/A）① 页面/业务楼层锚点跳转 + 随内容滚动自动跟随 → Elevator（ui.elevator，#14）（本组件不监听滚动、不做锚点跟随）；② 底部主导航 Tab → Tabbar（ui.tabbar，#19）；③ 顶部横向页签/选项卡 → Tabs（ui.tabs，#20）；④ 页面顶部导航/标题 → NavBar（ui.nav-bar，#17）；⑤ 多入口悬浮面板导航 → FixedNav（ui.fixed-nav，#15）
五态适配默认态 ✅ rail 灰底 + 项文字常规；激活态 ✅ 选中项白底胶囊 + 主色加粗（常驻持久）；禁用态 ✅ 单项 disabled 置灰不可点；点击（按压）反馈随平台（见 §05）；加载/成功/失败 N/A（单选导航类无加载态，业务态由宿主反馈承载）
与现有组件关系deps=[DesignTokens]；与 Elevator 划界：SideBar=目录轨单选、选中态持久、内容联动宿主自理（无锚点跟随）；Elevator=楼层锚点跳转 + 随滚动跟随。激活视觉=导航项同族基线（主色文字 + 白底/浅主色底胶囊，同 Tabs/FixedNav 激活态先例）；"右侧内容联动"由宿主完成（组件=纯导航轨，不自带右内容区）

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
导航轨宽度默认 96pt/96dp（宿主可覆盖，建议区间 80–128）窄轨=语义锚定；数值组件级 token 化并注释锚定（非魔法值），宿主可随布局用 frame/modifier.width 覆盖
项行行高 48pt/48dp，纵向 padding sm（8）；行间距默认 0（无分隔线）行内容垂直居中；文本字号 Sm（14）；横向由激活胶囊内衬控制（见下）
激活胶囊行内左右 margin = xs（4）→ 胶囊宽=轨宽−8；圆角 full；底=卡片白；文字=主色 + 加粗激活态=白胶囊浮在灰轨上，主色加粗文字（同导航项激活先例）；左侧不另加竖条（胶囊已足够区分）
禁用态同 default 布局 + 文字透明度 40% + 不可点disabled 项点击不触发 onChange（同 Cell/FixedNav 禁用先例）
长标题单行 + 行尾省略（truncate）一期不换行/两行（登记二期）；双端系统省略行为放行（见 §05）
滚动项数超出可视区→轨内纵向滚动；受控选中/点击选中时自动滚入可视一期无滚动指示器皮肤定制（系统级，表内放行）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件定位：ACE 三选

选项后果评估
A：纯左侧竖排导航轨（rail）——items 目录项单选、选中持久高亮、rail 内可滚动、点选回传 onChange；右侧内容联动（切换/滚动定位）由宿主自理✅ 语义=目录导航（分类页/分组目录）；单职责组件双端 1:1 清晰；与 Elevator（锚点跟随）、Tabs（顶部页签）、FixedNav（悬浮多入口）全部划界；联动灵活（宿主可切换/滚动/外部驱动）推荐 A：收敛可验收
B：导航轨 + 右内容滚动联动一体封装（组件内做左右两栏 + 锚点滚动定位）右侧内容结构宿主各不相同（列表/卡片/自定义视图），内嵌联动双端重（滚动距离/分栏测量）难 1:1，且与 Elevator 锚点语义重叠淘汰：联动登记二期候选
C：直接复用 Tabs 竖排变体（旋转 90°）顶部页签语义/尺寸/激活视觉不适用于左轨目录；单行横排变竖排需重写交互与滚动淘汰：语义错位

P2 · 数据模型：ACE 三选

选项后果评估
A：options 数据驱动——SideBarItem(title, value, disabled=false)，items 数组传入；onChange 回传被点/切换的 value✅ 与 Cell/FixedNav 等库内"列表数据驱动 + value 标识"一致；value 稳定可映射右内容/滚动段 id；双端契约简单推荐 A：数据驱动惯例
B：children 声明式（iOS 子视图 / Android content slot 逐项）项样式/复用/禁用/滚动需组件内 diff，双端实现差异大；目录轨固定样式场景无插槽诉求淘汰：二期自定义插槽再评估
C：仅标题字符串数组（无 value/disabled）无法用稳定 key 做外部驱动/内容映射；禁用态缺失淘汰：表达能力不足

P3 · 选中态控制：ACE 三选

选项后果评估
A：半受控——默认首项激活自管理；宿主可传 value 外部驱动（同步高亮+滚入可视）；点击已激活项不重复回调；点击禁用项无动作✅ 宿主既能自取右侧内容切换，也能由右侧滚动反向驱动轨高亮（demo D3/D4 可验）；回调幂等（不重复 onChange）便于计数验收推荐 A：灵活且行为确定
B：纯受控——value 必传，所有变更宿主回填强约束对简单目录页过重；首项/默认态语义丢给宿主可接受但过度
C：纯自管理 + 仅通知点击无法由右侧滚动反向驱动轨高亮（内容联动场景硬缺口）淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：纯导航轨——数据驱动 items + 半受控选中 + 禁用项 + 轨内滚动 + 选中滚入可视 + 单行省略 + demo 四段（基础两栏/禁用长标题/长列表联动/受控复位）✅ 覆盖目录导航核心闭环；联动能力经 D3（宿主滚动定位 + 反向驱动高亮）与 D4（外部 value 驱动）直接验证推荐 A：验收路径清晰
B：一期即内置右侧内容滚动锚定联动（两栏一体）见 P1-B 后果；需测量/滚动双端大量差异，非组件核心淘汰：登记二期候选
C：支持自定义行内容插槽/徽标/分组头目录轨场景多为固定文案；插槽双端实现差异大淘汰：登记二期（自定义插槽/徽标）

05 · 平台差异表（表内放行，表外必须双端统一）

维度iOSAndroid放行原因
点击按压反馈UIButton touchDown 高亮/压暗瞬态（点按选中感）clickable 系统 ripple（Material 默认点击反馈）系统级原生差异：按压反馈体系不同（表内放行，同 Grid/列表先例）
轨内滚动实现UIScrollView + 内容栈（或内部容器），系统弹性回弹LazyColumn（懒加载复用），overscroll 默认系统级原生差异：滚动容器机制不同（表内放行）
文字省略截断UILabel 单行 truncateTailText overflow=Ellipsis（maxLines=1）两端系统文本省略行为一致指向（表内放行，同 Grid/全库先例）
尺寸数值单位ptdpToken 同一数值不同单位（表内放行，同全库先例）
轨宽可覆盖入口frame 宽度约束 / AutoLayout widthmodifier.width / railWidth 参数同一覆盖能力两端入口不同（表内放行，语义一致）

06 · API 草案（双端一致契约，门禁 B 据此登记 api.json）

端API
共用SideBarItem：title: String（单行省略）+ value: String（稳定标识，映射右内容/滚动段）+ disabled: Boolean = false
iOSfinal class SideBarView: UIView
init(items: [SideBarItem], selectedValue: String? = nil, onChange: ((String) -> Void)? = nil)
默认 selectedValue=nil → 首项激活；var items / var selectedValue（didSet 刷新高亮 + 滚入可视）；组件=纯导航轨（轨宽默认 96，宿主可宽度约束覆盖）；内容联动完全宿主自理
Androiddata class SideBarItem(title: String, value: String, disabled: Boolean = false)
@Composable fun SideBar(items: List<SideBarItem>, selectedValue: String? = null, onChange: (String) -> Unit, modifier: Modifier = Modifier)
默认 selectedValue=nil → 首项激活；内部 LazyColumn 轨内滚动；行 clickable 语义 + ripple（表内放行）；宽由 modifier 定（宿主传 96.dp 缺省样轨宽）
