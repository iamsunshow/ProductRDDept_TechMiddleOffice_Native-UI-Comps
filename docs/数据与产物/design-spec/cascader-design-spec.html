Cascader 级联选择 · 设计规格（数据录入组件 #3 · 任务清单 #24，subcategory=form · 门禁 A）

组件 ID：ui.cascader ｜ 定位：任意层级树形数据的通用级联选择视图（内嵌内容组件，不含弹层）——宿主传入多级嵌套 options（品类/组织/多级分类等任意树），组件以"顶部层级路径 tab + 当前层列表"逐级联动，用户选到叶子（无 children）即完成，回传选中路径（各级 value + text 拼接）；弹层/遮罩/确认由宿主自理（Popup #54 未实现）。对标 Vant Cascader（options 嵌套树 + 顶部 tabs 级联 + 选中回传 {value, selectedOptions}）收敛为库内自有设计语言（任意深度树 + tabs 级联 + 叶子完成）。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-05，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 多级树形单选：品类树（支出/收入多级分类）、组织架构、商品类目等任意层数（2~N）数据；② 与"地区/地址"无关的任意层级选择——从一组树状选项中选一个叶子并带上完整路径；③ 编辑回显：宿主已有选中路径（values），组件同步展开到对应层并高亮
不适用（N/A）① 省市区地域专用选择 → Address（ui.address，#21）（固定 省→市→区 三级语义 + 结构化 AddressResult 直接落地址字段；本组件=任意树、返回值仅 path）；② 单选一层选项/下拉 → Picker（#33）/ Menu（#31）；③ 左侧目录轨+右侧内容联动 → SideBar（#18）/ Elevator（#14）；④ 弹层/遮罩容器 → 宿主自理（Popup #54 未实现）
五态适配默认态 ✅ 当前层列表行默认次色文字；选中态 ✅ 顶部路径 tab + 列表已选项主色加粗；禁用态 ✅ 节点级 disabled 置灰 40% 不可点；完成态=到达叶子（无 children）即 onChange；加载/失败 N/A（树数据异步加载=宿主职责，组件=纯渲染已给数据）
与现有组件关系deps=[DesignTokens]；与 Address 划界=Address 固定地域三级语义返回结构化地址；Cascader 任意树深（2~N）返回路径值。树数据驱动=value 稳定标识（同全库"列表数据驱动"惯例）；视图内列表=原生滚动（不依赖 VirtualList #81）

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
路径 tab 栏高 44pt/44dp，文字 Sm=14（激活主色 Semibold + 底部 2pt/2dp 主色指示线=当前层 tab 整宽，同 Tabs #20）；tab 数量=已选层数+1（≥1=根层"请选择"占位可点展开根）点击非激活 tab=回退到对应层重选；路径 tab 横向放不下时=左侧起单行省略+可横向滚动（深层路径场景 demo 用 5 层验证）；tab 文案=所选节点 text
列表区行高 44pt/44dp（=Address/Elevator 同基线）；字号 Md=16（默认 textSecondary、选中 primary Semibold）行=节点 text + 有 children 时右侧">"指示符（次色）；叶子无箭头；行整宽可点；disabled 节点=灰 40% 不可点无箭头高亮
容器/高度组件不固定整体高度：tab 44 + 列表高度宿主约束（建议 ≤360 滚动）弹层内高度=弹层内容；内嵌卡片=宿主约束；列表原生滚动
激活/默认色激活=AppColor.primary；默认=AppColor.textSecondary；tab 指示线=primary树形选择为功能组件，不做 activeColor 覆盖（二期按需）
路径回显宿主传 result（CascaderResult values[]）→ 组件按 values 逐层匹配展开到末层并高亮选中半受控语义（见 P3）；values 匹配不到=忽略回显仅回根层（同 Address 容错策略）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件定位：ACE 三选

选项后果评估
A：通用树形级联选择视图（内嵌内容组件）——宿主传任意深度嵌套 options，组件 顶部路径 tab + 当前层列表 逐级联动，叶子完成回传路径；弹层宿主自理✅ 品类/组织/任意树通用（层数数据驱动 2~N）；不依赖未实现的 Popup；与 Address 分工清晰（地域专用 vs 任意树）；宿主弹层/内嵌两种形态都支持推荐 A：收敛可验收
B：内置弹层+搜索+多选+懒加载子级一体的"通用级联选择器"弹层=Popup 职责（#54 未实现）；搜索=需对整树扁平化+过滤展示态；懒加载=异步层级协议双端差异大；多选=另一语义淘汰：登记二期（多选/搜索/懒加载逐项单独立项）
C：退化为"逐级下拉"（每层一个 Picker 按需弹出）多列并排原生 picker（iOS UIPickerView 多 component / Android 无等价）双端差极大；树深未知时组件无法定列数；非级联 tabs 交互淘汰：跨端不平权

P2 · 数据模型：ACE 三选

选项后果评估
A：CascaderOption(value, text, children?, disabled?) 嵌套树传入 + 结果 CascaderResult(values[], texts[], text=texts 路径拼接)✅ 任意深度由 children 递归自然表达；value 稳定（落库/回显键）；texts 供展示/回显；text 供一次性展示；与 RegionOption/AddressResult 同构但语义通用（不绑定地域）推荐 A：数据驱动惯例
B：扁平列表 + parentId 关联表组件需自己建索引树；宿主数据通常是接口返回的嵌套 JSON，改扁平=宿主侧多一次转换且易错淘汰：宿主给嵌套即渲染（转换成本宿主承担不值）
C：仅展示字符串路径（无 value 仅 text 数组）无法做稳定回显匹配（text 重复节点会歧义）；落库只能用文案不可改淘汰：缺 value 无法满足编辑场景

P3 · 选中态控制：ACE 三选

选项后果评估
A：半受控结果——内部维护当前层级与已选路径；宿主可传 result 外部回显（按 values 展开到末层+高亮）；用户选到叶子=onChange(result)；点已选层 tab 回退重选✅ 编辑预填/外部重置/路径驱动都成立；过程中间态（选到第 2 层未完成）由组件内部持有，宿主只接最终结果；与库内半受控语义一致推荐 A：灵活且行为确定
B：纯受控——每进一层都回调宿主回填当前路径树深不定、中间态回填繁琐；宿主需维护"当前层 state"与组件同步，重复状态易漂移可接受但过度
C：纯自管理仅叶子通知编辑回显/外部清空无门；"先选第 1 层再外部跳到第 3 层"无法驱动淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：通用树级联——嵌套 options + 顶部路径 tab（回退）+ 当前层列表（选中高亮+叶子无箭头）+ 节点禁用 + 叶子 onChange(result) + 外部 result 回显 + demo 四段（基础三级品类/深浅树混合含禁用/深层路径滚动回退/受控驱动）✅ 覆盖"任意树单选叶子"核心闭环；2 层浅树到 5 层深树=children 深度自然（demo D2/D3 可验）；禁用=节点级置灰（demo D2 可验）；半受控回显（demo D4 可验）推荐 A：验收路径清晰
B：一期即含 搜索过滤 + 懒加载子级 + 多选搜索=整树扁平过滤双端算法一致但状态面大；懒加载=宿主异步协议；多选=独立选择模型；三者叠加一期不可控淘汰：登记二期（逐项单独立项）
C：一期即做"整页全屏级联步骤向导"（每层一屏下一步）层级多时每层一屏跳转=导航容器职责（与 PageView 耦合）；非轻量表单选择语义淘汰：宿主可用 Navigation/PageView 自组

05 · 平台差异表（表内放行，表外必须双端统一）

维度iOSAndroid放行原因
点击按压反馈UIButton touchDown 高亮/压暗瞬态clickable 系统 ripple（Material 默认点击反馈）系统级原生差异：按压反馈体系不同（表内放行，同全库先例）
tab 等分/横滑UIStackView / UIScrollView 横滑Row weight / horizontalScroll系统级布局机制不同、结果一致（表内放行）
列表滚动UIScrollView/UITableView 原生滚动LazyColumn/verticalScroll 原生滚动平台滚动容器实现不同、行为一致（表内放行）
文本省略截断UILabel 单行 truncateTailText overflow=Ellipsis（maxLines=1）两端系统文本省略行为一致指向（表内放行）
尺寸数值单位ptdpToken 同一数值不同单位（表内放行，同全库先例）
数据模型命名struct CascaderOption / CascaderResult / CascaderViewdata class CascaderOption / CascaderResult / @Composable Cascader契约同构（表内放行，命名差异见门禁 B）

06 · API 草案（双端一致契约，门禁 B 据此登记 api.json）

端API

iOSfinal class CascaderView: UIView

result=nil → 根层起步；传 result → 按 values 逐层展开高亮（未匹配仅回根层）；var options / var result（didSet 重载联动）；tab 高 44、列表高宿主约束、无弹层
Androiddata class CascaderOption(val value: String, val text: String, val children: List<CascaderOption>? = null, val disabled: Boolean = false)、data class CascaderResult(val values: List<String>, val texts: List<String>, val text: String)
@Composable fun Cascader(options: List<CascaderOption>, result: CascaderResult? = null, onChange: (CascaderResult) -> Unit, modifier: Modifier = Modifier)
