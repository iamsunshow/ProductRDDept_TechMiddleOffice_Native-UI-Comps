Carousel 轮播 · 设计规格（信息展示区 · 门禁 A）

组件 ID：ui.carousel ｜ 定位：图片/内容轮播容器——支持自动播放、循环、指示器与手动滑动，用于 Banner 广告位、活动推荐、商品图集等横向翻页展示。对标 Ant Design Mobile Swiper / Vant Swipe / NutUI Carousel。提供 items 内容数组、autoPlay 自动播放、loop 循环、showIndicators 指示器、currentIndex 受控等能力。

01 · 组件用途 & 不适用边界（SCQA）

维度说明
Situation 情景首页/活动页/商品详情等场景需在同一广告位横向展示多张图片或内容卡片，单屏仅展示一项，用户通过左右滑动或自动播放切换，空间利用率高、信息密度集中
Complication 冲突无统一组件时=各业务自拼 UIScrollView(UIScrollView+isPagingEnabled)/HorizontalScrollView，自动播放定时器、循环首尾衔接、指示器联动、受控索引等能力各自重复造轮子，视觉与手势不一致、循环闪烁、自动播放与手动滑动互相打架
Question 问题需要一个横向分页轮播容器，支持自动播放（可配间隔/开关）、循环（首尾衔接）、指示器（可配颜色/开关）、手动滑动、受控当前索引与切换回调，双端手势一致
Answer 方案Carousel——横向分页轮播容器，纯展示+回调（不内置业务逻辑），items 数组驱动内容，autoPlay/loop/showIndicators 等开关控制行为，currentIndex 受控 + onChange 回调同步外部状态
适用场景① 首页 Banner 广告轮播（多张活动图自动播放）；② 商品/图集横向浏览（手动滑动为主）；③ 活动推荐位（自动播放+点击跳转）；④ 引导页/新手引导翻页（loop=false 收尾停止）；⑤ 自定义内容轮播（items 可放任意视图/卡片）
不适用（N/A）① 列表项侧滑操作 → Swipe（ui.swipe）；② 纵向拖拽排序 → Drag（ui.drag）；③ 单张图片展示/预览放大 → Image（ui.image）/ ImagePreview（ui.image-preview）；④ 标签页横向切换 → Tabs（ui.tabs）（Tabs=页签内容切换，Carousel=图片内容轮播）；⑤ 全屏画廊/相册滑动 → 二期 ImagePreview 承载
五态适配默认态 ✅ 展示当前幻灯片+指示器；自动播放态 ✅ autoPlay=true 每 duration ms 自动切换下一张；循环态 ✅ loop=true 末张→首张无缝衔接；手动滑动态 ✅ 手势左右滑动翻页（松手吸附到最近页）；禁用态 N/A 无禁用态（轮播被动展示，可用 autoPlay=false 静止）
与现有组件关系deps=[DesignTokens]（颜色/间距/圆角 token，零硬编码）。与 Swipe #58 划界：Swipe=列表项侧滑露操作按钮，Carousel=整屏内容横向翻页轮播；与 Tabs 划界：Tabs=页签标题+内容切换（内容可异构），Carousel=等宽图片/卡片内容轮播（内容同构）；与 Image 划界：Image=单张图片展示，Carousel=多张内容横向轮播容器（内部可嵌 Image）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

PREP · 组件形态总览（结论先行）

维度说明
Point 结论采用单容器 Carousel（items 数组驱动 + autoPlay/loop/showIndicators/currentIndex 开关 + onChange 回调），不做 Carousel+CarouselItem 子组件拆分，开箱即用且与 Vant Swipe / NutUI Carousel 一致
Reason 理由① 轮播内容同构（等宽图片/卡片），用 items 数组比插槽更简洁；② 双端分页容器都是"数据驱动 + 横向翻页"模型，数组 API 与原生 Paging 模型天然契合；③ 竞品（Vant/NutUI/AntD Mobile Swiper）均采用 items/swiperItems 数组驱动，开发者心智模型一致
Example 案例Vant Swipe 接收 swiperList 数组渲染等宽项；NutUI Carousel 接收 list 数组；AntD Mobile Swiper 接收 children 数组或 items
Point 结论单 Carousel 容器 + items 数组驱动，受控 currentIndex + 非受控自动播放双模式，下方 P1–P4 为形态/循环/双端实现的 ACE 细节

P1 · 组件形态：ACE 三选

选项后果评估
A：单容器 Carousel——items 数组驱动内容 + autoPlay/loop/showIndicators/currentIndex/onChange 开关回调，无子组件✅ 开箱即用（传入 items 即自动渲染分页），API 简洁，与 Vant Swipe/NutUI Carousel 一致；受控/非受控双模式（currentIndex 受控切换 / autoPlay 内部自驱）。推荐 A：开箱即用+数组驱动+双端一致
B：Carousel + CarouselItem 子组件插槽灵活可放异构内容，但需用户手动循环渲染 CarouselItem，使用成本高，且轮播内容通常同构。淘汰：使用成本高，一期 items 数组覆盖
C：纯手势容器（无数据驱动，宿主自拼内容）灵活但自动播放/循环/指示器需宿主自建，重复造轮子。淘汰

P2 · 循环（loop）方案：ACE 三选

选项后果评估
A：首尾克隆法——在首部插入末张克隆、尾部插入首张克隆，滑动越界时无感重置 currentIndex 到真实位置✅ 双端同构（iOS/Android 均可克隆 cell/item），末张→首张 / 首张→末张无缝衔接，无空白闪烁，与 Vant Swipe loop / NutUI Carousel loop 一致。推荐 A：无缝衔接+双端一致
B：到达末张后索引重置回 0（带动画）实现简单但末张→首张会反向"倒带"滑动，视觉突兀。淘汰：视觉突兀
C：不实现循环（loop=false 默认行为）末张后停止，需手动滑回。loop=false 时采用此行为（一期支持开关）。loop=false 时采用

P3 · iOS 实现路径：ACE 三选

选项后果评估
A：UICollectionView + isPagingEnabled=true + 横向布局（UICollectionViewFlowLayout scrollDirection=.horizontal）✅ UIKit 原生分页滚动，cell 复用机制内存友好；isPagingEnabled 自动吸附到页边界；配合 Timer 实现 autoPlay（scrollToItem），克隆 cell 实现 loop；指示器用 UIView 叠加 bottom 容器。推荐 A：UIKit 原生分页+cell 复用+吸附
B：UIScrollView + isPagingEnabled + 手动 contentSize可实现但无 cell 复用，items 多时内存占用高；需手动布局子视图。淘汰：无复用，items 多时低效
C：UIPageViewController原生分页但每页一个 ViewController 过重，且循环/自动播放需大量自定义，与 cell 复用模型不符。淘汰：过重，模型不符

P4 · Android 实现路径：ACE 三选

选项后果评估
A：HorizontalPager（Compose Foundation androidx.compose.foundation.pager）+ state 驱动✅ Compose 原生分页，PagerState 驱动 currentPage/scrollOffset，内置吸附+手势；LaunchedEffect + delay 实现 autoPlay（pagerState.scrollToPage）；克隆 item 实现 loop；指示器 Box 叠加 bottom Row。推荐 A：Compose 原生分页+state 驱动+吸附
B：ViewPager2（View 体系）原生分页但属 View 体系，与组件库 Compose 优先策略不符，需 AndroidView 桥接，集成成本高。淘汰：View 体系，集成成本高
C：LazyRow + 手动吸附逻辑可实现但吸附/分页需手写滚动逻辑，易出 bug。淘汰：吸附需自写，易错

04 · API 契约（与 api.json 对齐）

Carousel Props

类型名称必填默认值说明
propitems是—Array<CarouselItem>，轮播内容数组（每项含图片/自定义内容），至少 1 项
propautoPlay否trueBoolean，是否自动播放（每 duration ms 切换下一张）
propduration否3000Number，自动播放间隔毫秒（autoPlay=true 时生效，建议 ≥1000）
proploop否trueBoolean，是否循环（末张→首张无缝衔接，loop=false 时末张后停止）
propshowIndicators否trueBoolean，是否显示底部指示器
propindicatorColor否primary(#16A34A)String，当前指示器高亮色（支持任意 hex/DesignTokens 颜色名）
propcurrentIndex否0Number，受控当前索引（外部传入则受控，切换需配合 onChange 更新）
propheight否200Number/String，轮播容器高度（dp/pt）
eventonChange否—(index: number) => void，当前页切换回调（自动播放/手动滑动/受控切换均触发）

CarouselItem 数据结构

字段类型必填说明
keystring/number否项唯一标识（用于 cell 复用/diff，缺省用数组索引）
imagestring（url）否图片地址（与 content 二选一，image 优先渲染为铺满图片）
contentSlot/自定义视图否自定义内容（图片以外的卡片/视图，image 为空时生效）
onTap() => void否点击当前幻灯片回调

07 · anti_goals 反目标（二期不做）

  • 3D 翻页/卡片层叠效果（一期统一平面横向滑动）
  • 指示器自定义形状（数字/进度条/自定义视图）——一期纯圆点覆盖 80%
  • 纵向轮播（Carousel 仅横向）
  • 自动播放手势冲突暂停的高级策略（一期统一"滑动时暂停定时器，松手恢复"）
  • 懒加载/虚拟化超长列表（items 通常 ≤10，无虚拟化需求）
  • Lottie 翻页转场动画
