# 回归测试台账（错误防复发清单=唯一权威）

> 依据：《产研部-唯一权威手册》第二章第四节「错误反馈回归闭环」+ 本仓 AGENTS.md 红线「修复必带回归收口」。
> 定位：本台账=所有历史/新增错误的全量登记与「问题→防复发落点」映射=C1 单测补建与回归补测的逐批需求清单。
> 建档：2026-09-07（以子仓 git 历史 fix 提交为准，全量从旧到新整理）。后续每发现/修复一条错误=必须当场在本台账补行=不补=视为未完成。
>
> 防复发落点分四类：
> - L1=Android Robolectric 单测（`cd android && ./gradlew :components:testDebugUnitTest` 真绿才入库；测试文件按组件落在 android/components/src/test）
> - L2=编译门禁（安卓 gradlew assembleDebug 退出码0 / iOS 用户 Xcode 构建零报错）+ 第四章永久禁令
> - L3=双端 Demo 场景一致性门禁（scripts/check_demo_parity.py）
> - L4=人工实机回归清单（iOS 渲染/手势/动效类，自动化不可达=依赖 demo 实机复验）
>
> 全量 fix 提交原始清单生成命令：`git log --oneline --grep="fix"`（本台账按组件/主题聚合建档，逐条明细以此命令复核）。
