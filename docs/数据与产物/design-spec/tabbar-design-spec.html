Tabbar 标签栏 · 设计规格（导航组件 #6 · 任务清单 #19，subcategory=navigation · 门禁 A）

组件 ID：ui.tabbar ｜ 定位：页面底部的横向多入口主导航栏（底部标签栏）——常驻页面底部一行等分标签项（icon + 文字），点击切换激活并持久高亮，回传 onChange(value)；页面内容/路由切换由宿主接回调自理；对标 iOS UITabBar / Material BottomNavigation / NutUI React Tabbar（value 受控 + TabbarItem title/icon + onSwitch）收敛为库内自有设计语言（等分标签项 + 选中持久态 + 可选角标）。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-04，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 应用"首页级主导航"：页面底部常驻 2–5 个一级功能入口（首页/账单/统计/我的 等），点击在页面间切换、当前标签持久高亮；② 单个 Tab 可带数字角标（如消息未读数）提示业务态；③ 需自定义激活文案颜色的品牌化底部导航；④ 底部导航条上叠内容区（内容滚动上推/吸底由宿主布局自理）
不适用（N/A）① 顶部页签/页内内容切换 → Tabs（ui.tabs，#20）（本组件在页面底部，语义=一级页面切换，非页内内容切换）；② 页面顶部导航/标题 → NavBar（ui.nav-bar，#17）；③ 左侧目录导航轨 → SideBar（ui.side-bar，#18）；④ 悬浮面板多入口导航 → FixedNav（ui.fixed-nav，#15）；⑤ 悬浮单功能动作钮 → HoverButton（ui.hover-button，#16）/ BackTop（ui.back-top，#13）
五态适配默认态 ✅ 全项文字/图标次色灰；激活态 ✅ 当前项 icon + 文字主色加粗（常驻持久）；禁用态 ✅ 单项 disabled 置灰不可点；点击（按压）反馈随平台（见 §05）；加载/成功/失败 N/A（底部导航无加载态，业务态由宿主反馈承载）
与现有组件关系deps=[DesignTokens]；与 Tabs 划界：Tabbar=页面级一级导航（页面底部整条、icon+文字、跨页切换）；Tabs=页面内内容切换（顶部页签/横向滚动）。激活视觉=导航项同族基线（主色文字 + 图标，同 Tabs/SideBar 激活态先例，不做胶囊浮底）；"页面内容切换/路由"由宿主完成（组件=纯标签条，不自带页面容器与转场）

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
栏高默认 56pt/56dp（宿主可覆盖，建议 ≥48）行业基线=iOS UITabBar 49pt（不含安全区）/ Material 底部导航 56dp；库内取值 56 对齐导航组件行高惯例；组件=栏内容视图，不含系统底部安全区 inset——由宿主叠 SafeArea/底部约束处理（同 FixedNav/HoverButton "位置宿主锚定"先例）
项宽等分（items 数均分栏宽）2–5 项自适配；iOS=UIStackView fillEqually / Android=Row + weight(1f)（表内放行）
icon 位字符 22pt/22dp（=AppFont.sizeXl），icon–文字间距 xs（4）icon 一期=文本字符/emoji（同 FixedNav "⌂/⤓/✎" 先例，不走 Icon 组件资源映射=登记二期）；激活随文字变主色（文本字形可染色；emoji 彩色项不随主色=文档明示）
文字字号 Xs（12pt/12dp）；激活=主色 + Bold，默认=次色灰 Regular；单行省略icon 无/纯文字项=文字垂直居中整项（无 icon 占位）；长标题单行行尾省略（双端系统行为放行）
激活/默认色可选 activeColor 覆盖（默认=AppColor.primary）；默认态=AppColor.textSecondary品牌自定义激活色场景（如底部导航跟深色主题/品牌红）：宿主传色值覆盖，默认不传即主色；非激活色固定次色不开放（克制）
角标 badge高 16pt/dp 圆角 full，bg=primary 白字，字号 12（=AppFont.sizeXs）；右上角悬浮（icon 右上）可选数字（Int?，0/缺省=不显示，同 FixedNav num 先例）；红点 dot 形态=登记二期；角标跟随禁用项同 40% 透明度
禁用态同 default 布局 + 文字/icon 透明度 40% + 不可点disabled 项点击不触发 onChange（同 Cell/SideBar 禁用先例）
栏分隔栏顶 hairline（iOS 1/scale pt vs Android 0.5dp 表内放行，同 Grid 先例）；栏底=白底（bgCard）无圆角（整条贴底语义）顶部细线区分内容区与标签条；圆角由宿主容器裁剪（demo 卡片圆角示意，非组件自带）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件定位：ACE 三选

选项后果评估
A：纯底部标签导航条——items 数据驱动等分（2–5 项）、icon+文字、选中持久高亮、角标可选、点选回传 onChange；页面内容切换/路由转场由宿主自理✅ 语义=页面底部一级导航（对齐 iOS UITabBar/Material BottomNavigation 的"栏"本体）；单职责组件双端 1:1 清晰；与 Tabs/SideBar/NavBar/FixedNav 全部划界；宿主可用 onChange 切页面/控制器，亦可受控外部驱动推荐 A：收敛可验收
B：底部标签条 + 内置页面容器/路由懒加载一体（多页切换 + 保状态栈）页面栈/保活/转场双端差异巨大（UINavigationController vs Fragment/Compose Nav），非 UI 组件职责，验收周期失控淘汰：页面路由宿主自理（登记二期候选）
C：直接收编 iOS UITabBarController / Android BottomNavigationView 系统容器系统容器与库内 design token/设计语言不兼容（系统 tab 尺寸/配色/材质不可定制到库内基线），且 Android 系统组件跨端契约难统一淘汰：系统容器收编已由 NavBar/Tabs 收编先例覆盖业务近似场景

P2 · 数据模型：ACE 三选

选项后果评估
A：options 数据驱动——TabBarItem(title, value, icon?, badge?, disabled=false)，items 数组传入；onChange 回传被点 value✅ 与 FixedNav/SideBar 等"列表数据驱动 + value 标识"一致；value 稳定可映射页面路由 id；icon/badge 可缺省（纯文字/无角标 tab）；双端契约简单推荐 A：数据驱动惯例
B：children 声明式（iOS 子视图 / Android content slot 逐项）底部导航为固定样式等分 tab，无自定义插槽诉求；children 使等分/激活统一态维护复杂淘汰：二期自定义插槽再评估
C：仅标题字符串数组（无 value/icon/badge）无法带图标与角标（底部导航核心视觉）；无法用稳定 value 做页面路由映射淘汰：表达能力不足

P3 · 选中态控制：ACE 三选

选项后果评估
A：半受控——默认首启用项激活自管理；宿主可传 selectedValue 外部驱动（同步高亮）；点击已激活项不重复回调；禁用项无动作✅ 宿主既能"点选即切页"，也能受控驱动（登录态/外部事件跳转 tab 同步高亮，demo D4 可验）；回调幂等便于计数验收；与 SideBar/Tabs 选中语义一致推荐 A：灵活且行为确定
B：纯受控——value 必传，所有变更宿主回填对常驻底导过重；首项/默认态语义丢给宿主；底部导航普遍场景无强制受控必要可接受但过度
C：纯自管理 + 仅通知点击无法由外部（登录后跳首页/深链）驱动 tab 激活，宿主需要自己 hack淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：纯标签条——items 数据驱动（title/value/icon?/badge?/disabled）+ 等分 + 半受控选中 + 角标数字 + 禁用 + 单行省略 + 可选 activeColor + demo 四段（基础/角标禁用/纯文字与省略/受控驱动）✅ 覆盖底部导航核心闭环（一级页面切换 + 激活持久 + 业务角标）；D3/D4 分别验证纯文字项布局与外部 value 驱动语义推荐 A：验收路径清晰
B：一期内置系统级"中间凸起大按钮/自定义插槽/多级菜单"记一笔等中间凸起按钮属业务自定义形态，与等分底导语义冲突；插槽双端实现差异大淘汰：登记二期（凸起按钮=宿主叠层/自定义插槽）
C：一期即支持动画切换（滑动淡入/翻转）与红点 dot、安全区自动避让动画与转场属页面容器职责（P1-B 淘汰项）；dot 红点与数字角标并存需双态组件复杂度上升淘汰：dot/动画/安全区自避让登记二期（安全区一期宿主叠 SafeArea 处理）

06 · API 草案（双端一致契约，门禁 B 据此登记 api.json）

端API
共用TabBarItem：title: String（单行省略）+ value: String（稳定标识，映射页面路由）+ icon: String?（文本字符/emoji，可选）+ badge: Int?（数字角标，0/缺省不显示）+ disabled: Boolean = false
iOSfinal class TabbarView: UIView
init(items: [TabBarItem], selectedValue: String? = nil, activeColor: UIColor? = nil, onChange: ((String) -> Void)? = nil)
默认 selectedValue=nil → 首启用项激活；var items / var selectedValue / var activeColor（didSet 刷新激活态）；栏高默认 56，宿主可高度约束覆盖；icon 文本字形随激活色染色（emoji 彩色项除外=文档明示）；组件=纯标签条，底部安全区由宿主叠 SafeArea/底部约束
Androiddata class TabBarItem(title: String, value: String, icon: String? = null, badge: Int? = null, disabled: Boolean = false)
@Composable fun Tabbar(items: List<TabBarItem>, selectedValue: String? = null, activeColor: Color? = null, onChange: (String) -> Unit, modifier: Modifier = Modifier)
默认 selectedValue=null → 首启用项激活；内部 Row 等分（weight=1f）；行 clickable + ripple（表内放行）；高度由 modifier 定（宿主传 56.dp 缺省样）；底部安全区宿主用 SafeArea 避让
