Storage 本地存储

组件 ID：foundation.storage ｜ 任务清单 #93 ｜ 底层能力 foundation ｜ TMO 组件库 v1.4.0

定位：本地优先持久化骨架——只管理数据库生命周期（建库 / 迁移 / 清空），表结构与迁移逻辑由宿主注入，中台包不依赖任何业务表。

1. 场景与边界（SCQA）

Situation

记账 App 采用本地优先策略：账单、分类、预算等数据先落本地 SQLite，离线可用；注销账号时需一次清空全部业务表。

Complication

若中台包直接建业务表，会与业务 schema 强耦合（每次加字段都要改中台包），且双端 schema 漂移无法审计。

Question

需要一个只负责「数据库文件位置 + 迁移执行 + 清空」的骨架，业务 schema 由宿主声明并注入。

Answer

Storage——iOS 为 AppDatabase（GRDB DatabaseQueue + 宿主注入 DatabaseSchemaProvider）；Android 为 AppDatabase（SQLiteOpenHelper + 宿主注入 AppDatabaseSchema）。

2. 组件边界与划界

组件职责与 Storage 划界
业务表结构 / 迁移建表、加字段、数据迁移由宿主注入（iOS migrator / Android migrations）；Storage 只负责执行
ConfigProvider #3 / 宿主偏好存储轻量键值配置KV 配置（主题、开关）归 UserDefaults/SharedPreferences，不走本组件；Storage 只承载结构化数据
网络缓存层请求缓存 / 离线队列二期；一期不做
加密 / 字段级脱敏敏感字段加密一期不做；由宿主在业务表内自行加密（见敏感信息规范）

4. 设计规格

项规格依据
零业务依赖骨架不 import 任何业务表类型中台包可独立编译红线（同 Router）
存储位置iOS 应用支持目录 / 业务子目录；Android context.filesDir / 业务子目录不被系统缓存清理（区别于 Caches）
清空语义只 DELETE FROM（删行），不 DROP TABLE注销后复用同一库结构，免重复迁移
幂等prepare 重复调用安全（已有库则直接打开 + 补跑缺失迁移）宿主生命周期不确定
失败策略未注入 schema / 未 prepare 即访问 → 明确抛错（iOS）或返回 null（Android）暴露误用，不静默降级

5. Demo 排查 4 组

D1 建库 + 写入   prepare(schema) → INSERT INTO demo_note(text) VALUES('第一条') → 回显「已写入：第一条」
D2 读取         SELECT * FROM demo_note → 列出全部记录（行数 + 内容）
D3 删除单条      DELETE FROM demo_note WHERE id=? → 回显「已删除 id=1，剩余 N 条」
D4 全部清空      eraseAll() → 回显「已清空，剩余 0 条」

Demo 使用一个内置 demo_note 表（宿主角色的最小 schema 示例），演示「宿主注入 schema → 骨架建库迁移 → 业务读写 → 注销清空」全链路。

7. 平台差异表

差异点iOSAndroid判据
SQLite 封装GRDB（DatabaseQueue + DatabaseMigrator）原生 SQLiteOpenHelper + SQLiteDatabase表内放行（底层同为 SQLite，行为一致）
迁移表达DatabaseMigrator（命名迁移，自动记录已执行版本）version 整数 + migrations 列表（onUpgrade 内按 old/new 补跑）表内放行（语义一致：按版本补跑缺失迁移）
接入方式AppDatabase.schemaProvider = X（全局静态）AppDatabase.prepare(context, X)（显式传参）表内放行（Android 需 Context，无法纯静态）
存储目录applicationSupportDirectory/{dir}context.filesDir/{dir}表内放行（同为应用私有持久目录）
线程模型GRDB 队列串行化，无需调用方管理调用方自行切 IO 线程表内放行（组件不引入协程作用域，避免主线程阻塞）

8. 反目标

不做原因
字段级加密 / 密钥管理一期不做；宿主按敏感信息规范自处理
网络缓存 / 离线同步队列二期
ORM 实体映射 / 代码生成一期不做（Room/GRDB Record 由宿主选型）
数据库迁移可视化工具非一期交付目标
