ActionSheet 动作面板

组件 ID：ui.action-sheet ｜ 任务清单 #44 ｜ 操作反馈区首件 ｜ TMO 组件库 v1.4.0

定位：底部弹出的动作选择面板——点击触发按钮后从底部滑出，展示一组操作选项供用户点选，选中后自动收起。

1. 场景与边界（SCQA）

Situation 情景

用户在列表/详情页需要对某条数据执行操作（分享、删除、编辑、复制等），操作项 2~6 个离散动作，不适合下拉菜单（移动端不友好）也不适合弹窗（遮挡过多上下文）。

Complication 冲突

没有统一组件时=各业务页自拼 UIAlertController(iOS)/AlertDialog(Android)，视觉不统一、无 title/description、无 disabled 态、无 destructive 红色区分。

Question 问题

需要一个底部弹出的动作选择面板，支持 title、操作列表（含 disabled/destructive）、取消按钮，双端视觉一致。

Answer 方案

ActionSheet——底部 ModalBottomSheet 风格，圆角顶部+遮罩+操作列表+取消按钮，纯展示+回调（不内置业务逻辑）。

2. 组件边界与划界

组件职责与 ActionSheet 划界
Dialog #46居中弹窗（标题+内容+按钮）Dialog=确认对话（是/否），ActionSheet=多选一动作
Picker #33滚轮选择器（数据驱动）Picker=数据列表滚动选值，ActionSheet=动作按钮点选
Menu #31内嵌下拉菜单（列展开）Menu=页内嵌入展开，ActionSheet=底部弹出遮罩
Overlay #6遮罩层基础类Overlay=底层遮罩能力，ActionSheet=使用遮罩的业务组件
Popup #54通用弹出层（未实现）Popup=通用容器，ActionSheet=专用底部动作面板

3. API 契约

Props

参数类型默认值说明
visibleBoolean必传是否展示（受控）
titleString?null面板标题（顶部居中灰字，无则不显示标题行）
descriptionString?null标题下方描述文案（可选，无则不显示）
actionsList<ActionSheetItem>必传操作项列表
cancelTextString"取消"取消按钮文案
onSelect((Int) -> Unit)?null选中操作项回调（回传 index，null=不回调仅收起）
onCancel(() -> Unit)?null取消/遮罩点击回调
disabledBooleanfalse整体禁用（所有操作项灰显不可点，取消按钮仍可点收起）

ActionSheetItem 数据类

字段类型默认值说明
textString必传操作项文案
destructiveBooleanfalse是否危险动作（红色文案）
disabledBooleanfalse该操作项禁用（灰显不可点）

Events

事件回调签名触发时机
onSelect(index: Int) -> Unit点击某操作项（非禁用），面板自动收起后回调
onCancel() -> Unit点击取消按钮或遮罩区域，面板自动收起后回调

4.2 交互规格

交互行为
展开遮罩淡入 200ms + 面板从底部滑入 250ms ease-out
收起-选中点击操作项 → 面板滑出 + 遮罩淡出 → onSelect(index) 回调
收起-取消点击取消/遮罩 → 面板滑出 + 遮罩淡出 → onCancel() 回调
禁用项点击不触发回调，不收起
整体禁用所有操作项灰显不可点，取消按钮仍可点收起

编号决策点选项选定理由
P1组件定位 A. 底部动作面板（操作列表+取消）
B. 居中对话框（标题+内容+按钮）
C. 顶部下拉横滑面板		 A 移动端操作选择惯例=底部弹出（ thumb 可达），与 Dialog #46 居中确认场景划界

B. 每个操作项独立 onClick

7. 平台差异表

差异点iOS（UIKit）Android（Compose）判据

遮罩点击UITapGestureRecognizerscrim clickable表内放行（手势系统差异）

8. 反目标（anti_goals）

不做原因
图标操作项二期增量，一期纯文本覆盖 80% 场景
自定义操作项内容（嵌入组件）宿主如需复杂内容用 Dialog #46 或 Popup #54
多选确认ActionSheet=选一动作即收起，多选=Checkbox #25 + Dialog 确认
滑动收起（下拉手势）二期增量，一期点击遮罩/取消按钮收起已够用
嵌套子菜单复杂场景用 Cascader #24 或多级页面导航
