ResultPage 结果反馈

组件 ID：ui.result-page ｜ 任务清单 #56 ｜ 操作反馈区第十件 ｜ TMO 组件库 v1.4.4

定位：页面级/区域级操作结果反馈——成功/失败/警告/信息四态图标+标题+描述+操作按钮，整页或区域占位展示。

1. 场景与边界（SCQA）

Situation 情景

用户完成关键操作（提交订单/支付/审批/提交表单）后，需要一个整页或区域级的结果反馈，告知操作结果（成功/失败/警告），并提供后续操作按钮（返回首页/重试/查看详情）。

Complication 冲突

没有统一组件时=各业务页自拼结果页，视觉不统一、无四态图标、无标准操作按钮布局、与 Empty 空状态混淆。

Question 问题

需要一个结果反馈组件，支持 type 四态（success/error/warning/info）+title+description+actions 操作按钮列表，双端视觉一致。

Answer 方案

ResultPage——整页/区域结果反馈，type 四态图标+title+description+actions 按钮列表（纯展示+回调，不内置业务逻辑）。

2. 组件边界与划界

组件职责与 ResultPage 划界
Empty #48空状态占位（无数据）Empty=无数据空状态，ResultPage=操作结果反馈（成功/失败）
Dialog #46居中确认对话Dialog=弹层确认，ResultPage=整页/区域结果占位
Notify #52顶部短时浮层通知Notify=短时自动消失，ResultPage=持续占位
Loading #50加载中指示器Loading=加载过程，ResultPage=加载完成结果
Toast #59轻提示（未实现）Toast=短时轻提示，ResultPage=整页结果

3. API 契约

Props

参数类型默认值说明
typeResultTypesuccess结果类型：success/error/warning/info
titleString必传结果标题（如"提交成功"/"支付失败"）
descriptionString?null结果描述文案（标题下方副文本）
actionsList<ResultAction>[]操作按钮列表（按顺序水平排列，最多 3 个）
iconUIView? / @Composable?null自定义图标（null=按 type 显示默认图标）

ResultType 枚举

值图标颜色场景
success对勾 ✓primary（绿）操作成功
error叉 ✕error（红）操作失败
warning感叹号 !warning（橙）操作警告
info字母 iinfo（蓝）信息提示

ResultAction 数据类

字段类型默认值说明
textString必传按钮文案
styleResultActionStyleprimary按钮样式：primary/ghost/text
onClick(() -> Unit)必传点击回调

ResultActionStyle 枚举

值说明
primary主按钮（主色填充+白字，第一个按钮默认）
ghost次按钮（白底+主色描边+主色字）
text文本按钮（无背景，纯文字链接）

Events

事件回调签名触发时机
actions[i].onClick() -> Unit点击对应操作按钮

6. 决策投票表

编号决策点选项选定理由
P1组件定位 A. 整页/区域结果反馈（四态图标+标题+描述+按钮）
B. 居中弹层确认
C. 短时浮层通知		 A 整页/区域结果反馈覆盖提交/支付/审批结果场景，与 Dialog 弹层确认/Notify 短时浮层划界
P2四态类型 A. success/error/warning/info 四态
B. 仅 success/error 两态
C. 自定义 type 字符串		 A 四态覆盖 95% 场景（成功/失败/警告/信息），自定义 type 过度设计
P3按钮承载 A. actions 列表数据驱动（text+style+onClick）
B. 固定主/次按钮 props
C. 纯 content 槽		 A 列表数据驱动最灵活，支持 0~3 按钮+三种 style，与 ActionSheet actions 模式一致
P4图标 A. type 默认图标+icon 自定义槽
B. 仅 type 默认图标
C. 仅 icon 自定义		 A 默认图标覆盖 80% 场景，自定义槽支持业务图标（如支付图标/品牌图标）
P5一期范围 A. 一期=type 四态+title+description+actions+icon 自定义+demo 四段
B. 二期=自定义布局/动画/嵌套内容		 A 一期覆盖 80% 场景（标准结果页），自定义布局/动画=二期

7. 平台差异表

差异点iOS（UIKit）Android（Compose）判据
图标绘制UIBezierPath 自绘对勾/叉/感叹号/iCanvas drawPath 自绘表内放行（双端同构自绘，不依赖系统图标库）
按钮UIButton + AppButton 样式AppButton Composable表内放行（复用 AppButton #1 组件）
布局UIStackView 垂直居中Column horizontalCenter表内放行（布局 API 差异）
图标底色UIColor(type).withAlphaComponent(0.1)Color(type).copyAlpha(0.1f)表内放行（颜色 API 差异）

8. 反目标（anti_goals）

不做原因
空状态占位用 Empty #48（无数据 vs 操作结果）
弹层确认对话用 Dialog #46
短时浮层通知用 Notify #52 或 Toast #59
自定义布局（嵌入任意内容）二期增量，一期四态图标+标题+描述+按钮覆盖 80%
进场动画跟随页面进场，不内置动画
自定义 type 字符串四态枚举覆盖 95%，自定义过度设计
