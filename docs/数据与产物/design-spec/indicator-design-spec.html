Indicator 指示器

组件 ID：ui.indicator ｜ 任务清单 #69 ｜ 导航区第二十件 ｜ TMO 组件库 v1.4.29

定位：页面位置指示器——圆点/数字形态标记当前页与总页数，用于轮播、引导页、分步表单等场景的位置感知。

1. 场景与边界（SCQA）

Situation 情景

App 中大量分页场景需要让用户感知当前位置：轮播图第几张、引导页第几步、分步表单第几页、图片预览第几张。

Complication 冲突

没有统一组件时=各业务页自绘圆点+横向堆叠+手写高亮逻辑，点间距不一、选中态色/形各异、竖向场景缺位。

Question 问题

需要一个指示器组件，支持圆点形态（默认）与数字形态，支持横向/竖向排布，支持自定义选中色/未选中色/大小/间距，支持长条选中态。

Answer 方案

Indicator——纯展示型内容组件，current/total 驱动高亮位置，direction 控制排布方向，showNumber 切数字形态，block 开长条选中态，color/activeColor/size/gap 自定义视觉。

2. 组件边界与划界

组件职责与 Indicator 划界
Carousel #59轮播容器Carousel=可滚动内容容器（自带可选指示器），Indicator=独立指示器原子组件（可被 Carousel 内嵌或独立使用）
Pagination #71分页翻页器Pagination=可点击翻页（上一页/下一页/页码按钮），Indicator=纯展示不可点（只标记位置不交互）

Steps 步骤条流程步骤Steps=带标题/图标的流程节点（强结构），Indicator=纯圆点/数字序列（轻量位置标记）

3. API 契约

Props

参数类型默认值说明
currentInt0当前页索引（从 0 开始），高亮第 current 个点
totalInt0总页数（渲染 total 个点）；total≤0 不渲染
directionDirectionhorizontal排布方向：horizontal 横向 / vertical 竖向
showNumberBooleanfalse数字形态：true 显示「current+1/total」胶囊，false 显示圆点序列
blockBooleanfalse选中态长条形态：true 选中点变长条（width=size*2.5 圆角矩形），false 选中点同形（仅色变）
sizeFloat6指示点直径/边长（dp），数字形态忽略
gapFloat8指示点间距（dp），数字形态忽略
colorColorgray15 (浅灰)未选中点颜色
activeColorColorprimary (蓝)选中点颜色

条件形态示例

6. 决策投票表

编号决策点选项选定理由
P1形态驱动 A. showNumber 布尔切换圆点/数字两形态
B. 显式 type 枚举 + 各自参数
C. 两个独立组件 DotIndicator/NumberIndicator		 A 布尔切换最简洁；圆点/数字覆盖全部场景；与 NutUI Indicator 一致；B 枚举淘汰=参数冗余/C 多组件淘汰=维护成本高
P2选中态变化 A. 仅色变（同形同大，色不同）
B. 长条形态（block 开关，选中点变长条）
C. 同时支持 A+B（block 开关）		 C block=false 默认色变（最简）；block=true 长条形态（视觉更醒目）；双模式覆盖轮播（色变）与引导页（长条）两类场景
P3排布方向 A. 仅横向
B. 横向+竖向（direction 参数）		 B 竖向场景存在（竖向轮播/分步表单侧边指示）；direction 一参数零成本扩展；与 NutUI 一致
P4一期范围 A. 一期=圆点/数字+横向/竖向+block长条+自定义色/大小/间距+demo四段
B. 二期=动画过渡/点击跳转/自定义渲染		 A 一期覆盖 95% 场景；动画/点击=二期增量

8. 反目标

不做原因
点击跳转Indicator 纯展示位置，跳转由容器（Carousel 等）承载；二期增量
动画过渡二期增量，一期静态切换已够用
自定义渲染（插槽）一期只做圆点/数字两形态，自定义渲染=二期
自动跟随容器Indicator 不自动绑定容器，current/total 由调用方驱动（解耦）
