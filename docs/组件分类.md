## 备注（与旧版分类的差异说明）

- 本次改用 **NutUI React 4.x** 官网分类，新增了独立的「**布局组件**」分类（Divider/Grid/Layout/SafeArea/Space/Sticky），与旧版 naming-pool（NutUI Vue）差异较大，故上次表格缺失布局类。
- 「已有 = 🔶」表示该组件已在组件库实现但仅单端完整（另一端缺失或为近似实现），具体缺哪端见备注列。
- 缺失组件统一标注「双端均未实现」，后续按分类优先级补齐。
- 底层能力（foundation）为 TMO 自有跨产品基建：Router/Storage/HTTPClient/MoneyFormat 4 个保留于本分类；Calendar/SystemBars/DesignTokens 3 个并入「特色组件」。
- 业务扩展（businessExtensions）与业务组件（GridPicker/Split/Statistic 等）**不列入本表**，由各 App 在业务代码库中继承开发。
