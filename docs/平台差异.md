# 双端平台差异白名单（platform-diff）

> 允许的系统级原生差异登记表。**白名单之外的视觉/行为差异一律禁止**。
> 配套：设计对齐与令牌复用规则见《产研部-唯一权威手册》第二章（docs 入口 `docs/README.md`）；验收门禁 A 检查项与验收标准正文见手册第二章（docs 侧 `验收标准.md` 壳已于 2026-09-04 收拢删除）。

## 白名单

| 项 | iOS | Android | 备注 |
|----|-----|---------|------|
| 手势 | UIGesture | GestureDetector | 系统行为 |
| hover | 无 | 有 | Android 支持 hover 态 |
| 键盘 | 系统键盘 | IME | 系统行为 |
| 控件默认样式 | UIKit | Material | 需覆盖对齐 |
| 按压反馈（Cell） | UILongPress/Highlight | Ripple 水波纹 | 平台原生差异；Cell 按下态统一覆盖为背景 `gray.4`，水波纹不扩散至 Cell 外（登记自 cell-design-spec.html 06 节） |
| 长按事件（Cell） | 支持 `onLongPress` 回调 | 不承诺（契约声明，Android 侧不暴露） | 能力差异（登记自 cell-design-spec.html 06 节 + api.json `ui.cell` events） |
| 图标参数类型（Cell） | `iconSymbol: String?`（SF Symbol 名） | `icon: Painter?`（资源映射层传入） | 平台资源体系差异（SF Symbols vs Vector Drawable），契约字段名 `icon` 双端一致 |
| 点击事件签名（Cell） | `onTap(_ item, _ index)` | `onClick: (() -> Unit)?`（数据+索引由调用方闭包绑定） | 平台惯例差异（Compose `() -> Unit`），事件名 `onClick` 双端一致 |
| 挂载方式（Overlay） | `UIApplication.keyWindow()` → `addSubview`（直接挂最前 UIWindow） | Compose `Dialog`（独立 window，usePlatformDefaultWidth=false + decorFitsSystemWindows=false） | P1 决策 A：两者均"脱离父 VC/Activity 生命周期"的顶层覆盖；视觉一致；影响 clickThrough 物理穿透实现差异（下条目登记） |
| dismissOnBackPress（Overlay） | @available(\*, unavailable)（iOS 无返回键概念；props 仍保留以对齐 API） | 绑定 `DialogProperties.dismissOnBackPress`；true=返回键触发 onClose，false=忽略 | 系统能力差异；契约 10 props 名一致，iOS 用 `@available(*, unavailable, message: "iOS 不支持返回键，dismissOnBackPress 无效果")` 编译期告警 |
| 圆角掩膜（Overlay 贴边零圆角） | `CACornerMask`（layer.maskedCorners = 贴边两直角移除掩码） | `RoundedCornerShape(topStart,topEnd,bottomStart,bottomEnd)`（四角差异化，贴边方向两直角=0dp） | 系统 API 差异；resolveShape(position, radius) / edgeMaskedCornersIfPinnedToEdge(position) 数学镜像，视觉结果一致 |
| contentOffset 参数展开（Overlay） | 单一对象 `contentOffset: CGPoint(x,y)`（UIKit 原生支持对象字面量） | 扁平化为两个 Int 参数：`contentOffsetX: Int` + `contentOffsetY: Int`（Compose 不支持命名对象字面量传参） | Compose 语言限制；语义等价（{x,y} → 两个 Int 合成 IntOffset(x,y)）；对外 api.json 契约仍保留 contentOffset?:{x,y} 对象语义（类型层对象+实现层 flatten 桥接） |

## 登记规则

1. 出现双端差异 → 先评估是否**系统级原生差异**：
   - 是 → 登记到本表（注明原因）。
   - 否 → 双端必须统一，禁止差异化。
2. 未登记即差异化 → 视为违规，验收门禁 A 打回。
3. 已有条目如需修改 → 走组件治理变更（治理规则正文在产研部唯一手册=入口壳 `docs/README.md`），不能私自改。
