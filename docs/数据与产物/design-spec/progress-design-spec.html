Progress 进度条

组件 ID：ui.progress ｜ 信息展示区组件 #73 ｜ TMO 组件库 v1.4.30

定位：用于展示操作的当前进度——一条带填充色的横向轨道，填充宽度按百分比（0-100）自适应，支持自定义颜色、高度、百分比文字显示与动态进度变化。

1. 场景与边界（SCQA）

Situation 情景

App 中常出现上传/下载/表单提交/资源加载等耗时操作，用户需要直观感知当前完成比例与剩余进度。

Complication 冲突

各业务页自绘背景条+前色块+手写百分比文字，颜色/高度/圆角不统一，动态更新时双端动画曲线漂移，禁用态/越界值处理缺失。

Question 问题

需要一个进度条组件，支持百分比驱动、自定义颜色与高度、百分比文字显示、动态进度更新，双端 1:1 视觉一致。

Answer 方案

Progress——数据驱动的横向进度条，percentage 控制填充宽度（0-100 clamp），color 自定义填充色、trackColor 轨道底色，height 控制条高，showText 开关百分比文字显示，动态更新 percentage 时填充宽度平滑过渡动画。

2. 组件边界与划界

组件职责与 Progress 划界
CircleProgress 环形进度 #73环形/圆形进度展示CircleProgress=环形描边进度（圆形）；Progress=横向线性进度条（矩形）
Loading 加载中 #60不确定时长的转圈动画Loading=无具体百分比的不确定等待；Progress=有明确百分比的确定进度
Skeleton 骨架屏 #63数据加载占位骨架Skeleton=整页/整块占位闪烁；Progress=单条进度数值展示
Steps 步骤条分步骤流程进度Steps=离散步骤节点进度；Progress=连续百分比线性进度

4. 决策投票表（ACE 模型：选项 / 评估后果 / 选最优）

编号决策点选项（Alternatives）评估后果（Consequences）选最优（Evaluate）理由
P1百分比取值范围 A. 0-100 clamp（越界自动钳制）
B. 不校验，使用方自负
C. 0-1 小数比例		 A. 越界安全，UI 不溢出，与 NutUI percentage 0-100 对齐
B. 负数/超 100 会导致填充溢出轨道、文字异常
C. 与 NutUI/业界惯例（0-100）不符，使用方易混淆		 A 0-100 clamp 是业界标准（NutUI/AntD 均用 0-100），自动钳制越界值保证 UI 安全；小数比例=二期可加 normalized 参数
P2进度变化动画 A. 默认带过渡动画（宽度 0.3s ease）
B. 一期无动画瞬切
C. 可配置 animated 参数开关		 A. 动态更新平滑自然，体验好，但双端动画曲线需对齐
B. 实现简单但动态更新生硬
C. 灵活，默认开启动画，需要瞬切时关闭		 C animated 参数默认 true 带过渡动画（0.3s ease），需要瞬切时设 false；与 Badge 一期静态先例不同——Progress 动态更新是核心场景，动画是刚需，双端用同曲线 0.3s 对齐
P3百分比文字位置 A. 右侧外部显示（条+文字横向排列）
B. 条内嵌入显示（文字叠在填充条上）
C. 无文字（纯条）		 A. 文字清晰不被条遮挡，布局简单，与 NutUI textIn=false 一致
B. 进度低时文字易溢出/被裁，实现复杂
C. 最简洁但缺数值反馈		 A 右侧外部显示=showText 开关控制，文字清晰不遮挡，与 NutUI 默认 textIn=false 对齐；条内嵌入=二期可加 textPosition 参数
P4一期范围 A. 一期=基础进度/自定义颜色+高度/百分比文字/动态进度+demo 四段
B. 二期=条纹样式(striped)/条纹动画(animated stripe)/渐变填充/条内文字		 A. 覆盖 95% 进度条场景，范围可控
B. 二期增量，不阻塞一期交付		 A 一期四段 demo 覆盖常见场景；条纹样式/条纹动画/渐变/条内文字=二期
