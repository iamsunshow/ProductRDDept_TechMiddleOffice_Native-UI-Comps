Address 地址 · 设计规格（数据录入组件 #1 · 任务清单 #21，subcategory=form · 门禁 A）

组件 ID：ui.address ｜ 定位：省市区地域选择视图（内嵌内容组件，不携带弹层）——宿主传入省市区三级 region 数据，组件内部按 省→市→区 逐级联动展示并完成选择，回传选中地址（各层 code + 中文文本 + 拼接地址串）；弹层/遮罩/确认按钮由宿主自理（库内通用 Popup 组件未实现，#54 待立项）。对标 NutUI React Address / Vant Area（均为"省市区区域数据 + 逐级联动 + onChange 回传"），收敛为库内自有设计语言（固定三级地域语义 + 数据驱动 + 顶部层级 tab 联动）。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-05，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 表单内省市区选择：收货地址/发票抬头地址/默认地址设置（数据层通常由接口下发 省→市→区 三级列表）；② 已选地址回显与重选：宿主已有地址（省市区 code/text）时，组件同步定位高亮各层，用户可逐级回退重选；③ 结果用于业务下单/地址簿落库，onChange 回传结构化结果供宿主存储
不适用（N/A）① 任意层级（非地域）树形数据选择 → Cascader（ui.cascader，#24）（通用级联，本组件=省市区固定三级语义）；② 日期类选择 → DatePicker（#26）/ CalendarCard（ui.calendar-card，#23）；③ 单列可滚动选择 → Picker（#33）；④ 弹层/遮罩容器 → 宿主自理（Popup #54 未实现；宿主用任意自定义弹层承载本视图）
五态适配默认态 ✅ 当前层级列表行默认次色文字；选中态 ✅ 顶部层级 tab + 列表已选项主色加粗；禁用态 ✅ 节点级 disabled 置灰 40% 不可点；完成态=到达末级节点（无 children）即回调 onChange 完成选择；加载/失败 N/A（区域数据异步加载为宿主职责，本组件=纯渲染已给数据）
与现有组件关系deps=[DesignTokens]；与 Cascader 划界：Address=地域专用（固定 省→市→区 三级语义，结果=结构化 AddressResult 含拼接文本，可直接落地址字段）；Cascader=任意层级通用树（品类/组织等，文本仅为所选路径展示）。弹层承载走宿主叠层先例（同 FixedNav/HoverButton 位置宿主锚定）；视图内列表=原生滚动视图（不依赖 VirtualList）

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
层级 tab 栏高 44pt/44dp，文字 Sm=14（激活主色 Semibold + 底部 2pt/2dp 主色指示线=当前层 tab 整宽，同 Tabs #20 指示线语义）；tab 数量=已选层级数+1（至少=根层）点击已选层 tab=回退该层重选；tab 文字单行省略（层名过长）；未知层级占位"请选择"文案待定=由宿主语言包定（demo 用"选择省/市/区"）
列表区行高 44pt/44dp（=导航列表行高惯例，同 Elevator/SideBar）；字号 Md=16（默认态 textSecondary、选中态 primary Semibold）行=区域名 + 存在子级时右侧">"指示符（次色）；叶子行不显示箭头；行整宽可点
容器/高度组件自身不固定高度：tab 栏固定 44，列表区高度由宿主/父容器约束（默认建议高 ≤360 滚动）弹层内高度=弹层内容区；内嵌卡片=宿主约束（demo 卡片示意）；列表可滚动=原生滚动视图
激活/默认色激活=AppColor.primary；默认=AppColor.textSecondary；tab 指示线=primary不做 activeColor 覆盖（地域选择为功能组件非品牌装饰场景；如业务确需可二期开放）
禁用态同默认布局 + 文字透明度 40% + 不可点disabled 区域节点点击不前进（数据异常防御，常规省市区数据无禁用，demo 演示备用）
选中结果回显宿主传入既有 AddressResult（codes/text）→ 组件逐层匹配高亮并定位列表半受控语义（见 P3）；codes 不匹配树内节点=忽略回显仅重置为根层

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件定位：ACE 三选

选项后果评估
A：纯地域选择视图（内嵌内容组件）——宿主传 省→市→区 三级嵌套 RegionOption[]，内部逐级联动 tab+列表，到叶子回调 onChange(AddressResult)；弹层/确认按钮/异步加载=宿主自理✅ 语义纯粹（=区域数据选择器），双端 1:1 简单；不依赖未实现的 Popup；宿主可装进自定义弹层/内嵌卡片两种形态；结果结构化（code+text+拼接串）直接落业务地址字段推荐 A：收敛可验收
B：内置弹层+遮罩+确认栏一体的"完整地址选择器"（含搜索/常用地址）遮罩/弹层动画/确认栏=Popup 类职责（#54 未实现）；搜索/常用/定位=业务态，双端差异大，一期验收失控淘汰：登记二期（Popup 立项后宿主弹层复用本视图）
C：基于通用 Cascader 直接改（不做固定三级语义，由 region 数据自然决定层数）实现可省，但"地址结果"语义（结构化省市区分量+文本拼接）无处安放；用户最终拿到的只是 path 文本，落库/回显要宿主二次拼装，与 Cascader 职责混淆淘汰：Address/Cascader 双组件语义互补并存（互不替代，见 §01 划界）

P2 · 数据模型：ACE 三选

选项后果评估
A：RegionOption(value, text, children?) 嵌套树传入 + 结果 AddressResult(codes[], names[], text)（text=各层 names 拼接，分隔符默认空格）✅ 与库内"数据驱动+value 稳定标识"惯例一致（同 TabBarItem/SideBarOption）；省市区层数由 children 深度自然表达（直辖市=两级）；宿主既可存 codes 又可直接存 text 展示推荐 A：数据驱动惯例
B：系统地区码内置（组件内置全国省市区静态库）数据更新/定制与包体双端维护重；行政区划随国家调整，内置=死数据淘汰：数据由宿主/接口下发（组件不持有地域库）
C：仅字符串数组（省/市/区三个可选下拉各给字符串列表）三层耦合硬编码（无法表达直辖市两级/缺失层）；无 value 无法稳定回显与落库淘汰：表达能力不足

P3 · 选中态控制：ACE 三选

选项后果评估
A：半受控结果——内部维护当前联动层级；宿主可传 result（AddressResult）外部驱动回显（同步高亮各层 tab+列表定位）；用户选到叶子=onChange(result)；层数自然（末级无 children 即完成）✅ 宿主"选择即得结构化结果"，也可带既有地址回显重选（编辑地址场景）；与库内半受控选中语义一致（同 SideBar/Elevator/Tabbar）推荐 A：灵活且行为确定
B：纯受控——每步（选省/市/区）都触发 onChange，由宿主回填当前层过程态回填对宿主过重（省未选完就要 state 回写）；"只关心最终地址"的常见用法被迫处理中间态可接受但过度
C：纯自管理仅终选通知无法预填回显既有地址（编辑场景缺失）；重置/外部跳层无门淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：三级联动视图——RegionOption 嵌套数据 + 顶部层级 tab（含回退）+ 当前层列表（选中主色高亮 + 叶子无箭头）+ 到叶子 onChange(AddressResult) + 外部 result 回显 + demo 四段（基础三级/两级直辖市/大列表滚动回退/受控驱动）✅ 覆盖"选地址"核心闭环（含编辑回显）；两级数据=children 缺失自动收拢（demo D2 可验）；31 省大数据=滚动性能（demo D3 可验）；半受控=外部驱动（demo D4 可验）推荐 A：验收路径清晰
B：一期即含 最近使用/历史地址/定位/搜索 业务增强定位/搜索=业务+平台能力（CoreLocation/地图 SDK），非 UI 组件职责；最近使用=宿主存储逻辑淘汰：登记二期（宿主可在弹层内自组）
C：一期即支持任意层级（不限三级）通用树 + 多选 + 联动异步懒加载子级懒加载子级=异步层级协议，双端差异大；多选=另一语义（与 Cascader/Address 单选定位冲突）淘汰：登记二期/交 Cascader 演进（异步懒加载留宿主预取）

05 · 平台差异表（表内放行，表外必须双端统一）

维度iOSAndroid放行原因
点击按压反馈UIButton touchDown 高亮/压暗瞬态clickable 系统 ripple（Material 默认点击反馈）系统级原生差异：按压反馈体系不同（表内放行，同全库先例）
tab 等分实现UIStackView distribution=.fillEquallyRow + Modifier.weight(1f)系统级布局机制不同、结果同=均分（表内放行）
列表滚动UIScrollView/UITableView 原生滚动LazyColumn/verticalScroll 原生滚动平台滚动容器实现不同、行为一致（表内放行）
文本省略截断UILabel 单行 truncateTailText overflow=Ellipsis（maxLines=1）两端系统文本省略行为一致指向（表内放行）
尺寸数值单位ptdpToken 同一数值不同单位（表内放行，同全库先例）
数据模型命名struct RegionOption / AddressResult / AddressViewdata class RegionOption / AddressResult / @Composable Address契约同构（表内放行，命名差异见门禁 B）

06 · API 草案（双端一致契约，门禁 B 据此登记 api.json）

端API
共用RegionOption：value: String（稳定标识，如区划 code）+ text: String（区域中文名）+ children: [RegionOption]?（子级；nil/空=叶子即末级）+ disabled: Boolean = false
AddressResult：codes: [String]（所选各级 value）+ names: [String]（各级中文）+ text: String（names 空格拼接，如"广东省 深圳市 南山区"）
iOSfinal class AddressView: UIView
init(options: [RegionOption], result: AddressResult? = nil, onChange: ((AddressResult) -> Void)? = nil)
result=nil → 根层起步；传 result → 按 codes 逐层定位高亮（未匹配则仅回根层）；var options / var result（didSet 重载联动）；到叶子 onChange；tab 高 44、列表高度由宿主约束、组件不含弹层
Androiddata class RegionOption(val value: String, val text: String, val children: List<RegionOption>? = null, val disabled: Boolean = false)、data class AddressResult(val codes: List<String>, val names: List<String>, val text: String)
@Composable fun Address(options: List<RegionOption>, result: AddressResult? = null, onChange: (AddressResult) -> Unit, modifier: Modifier = Modifier)
列表高度由 modifier 约束；内部 Column + 滚动 + 联动状态；点击行 ripple（表内放行）
