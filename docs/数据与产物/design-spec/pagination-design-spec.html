Pagination 分页

组件 ID：ui.pagination ｜ 导航区组件 #71 ｜ TMO 组件库 v1.4.30

定位：受控页码驱动的分页器——当数据总量较大需分页浏览时，提供上一页/下一页 + 页码按钮翻页，或简洁模式（x/y）翻页，页码超量时自动省略号折叠。

1. 场景与边界（SCQA）

Situation 情景

App 中订单列表、搜索结果、消息记录等长数据需分页浏览，用户需在多页之间快速翻页定位内容。

Complication 冲突

各业务页自绘页码按钮 + 上一页/下一页 + 省略号折叠逻辑，按钮选中态/禁用态/省略号窗口算法各异，移动端页码过密难以点击，双端表现漂移。

Question 问题

需要一个分页组件，支持页码按钮翻页、简洁模式（x/y 文本）、页码超量时省略号折叠、自定义可见按钮数，双端 1:1 视觉一致。

Answer 方案

Pagination——受控 currentValue 驱动的分页器，total + pageSize 计算总页数，itemSize 控制可见页码按钮数（超出自动省略号折叠），mode 切换 multi（按钮）/ simple（x/y），首尾页与当前页窗口固定渲染、中间间隔以省略号占位，onChange 回调翻页。

2. 组件边界与划界

组件职责与 Pagination 划界
Tabs #78页签横向切换Tabs=同屏页签切换不同面板（无翻页概念）；Pagination=数据分页翻页（同列表不同页数据）
InfiniteLoading #56滚动无限加载InfiniteLoading=下拉触底自动加载下一页（无显式页码）；Pagination=显式页码按钮翻页（用户主动跳页）
BackTop #6返回顶部BackTop=长页面回到顶部；Pagination=数据分页（页码切换，非滚动定位）
Stepper #48数字步进Stepper=小范围数值增减（无总页数概念）；Pagination=基于总页数的页码跳转

PaginationMode 枚举

值说明
multi按钮模式：上一页/下一页 + 页码按钮（含省略号）
simple简洁模式：上一页/下一页 + x/y 文本

省略号折叠算法

总页数 ≤ itemSize → 全量渲染 1..总页数；总页数 > itemSize → 当前页居中 window（itemSize 个按钮）+ 首尾固定 + 间隔省略号：

① window 居中：left = current - (itemSize-1)/2，right = left + itemSize - 1；边界 clamp（left<1 → left=1/right=itemSize；right>总页数 → right=总页数/left=总页数-itemSize+1）；

② 左侧：left>1 显首页，left>2 加省略号；右侧：right<总页数 显末页，right<总页数-1 加省略号。
