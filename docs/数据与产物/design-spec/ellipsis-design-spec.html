Ellipsis 文本省略

组件 ID：ui.ellipsis ｜ 任务清单 #67 ｜ 信息展示区 ｜ TMO 组件库 v1.4.27

定位：文本超出指定行数时自动截断显示省略号，支持点击展开/收起——用于商品描述、公告摘要、评论正文等长文本场景。

第一章 场景与边界（SCQA）

Situation 情景

App 中大量场景需要展示长文本：商品详情描述、活动公告、评论正文、消息摘要。这些文本长度不确定，若全部展开会破坏页面布局。

Complication 冲突

没有统一组件时=各业务页自行用 UILabel/Text 截断，行数硬编码、展开交互缺失、省略号位置不一致，且双端截断行为有平台差异。

Question 问题

需要一个文本省略组件，支持指定最大行数自动截断、点击展开/收起、半受控外部驱动展开态，双端行为一致。

Answer 方案

Ellipsis——纯展示型文本截断组件，输入 content+rows 自动截断尾部省略，expandText/collapseText 控制展开收起文案，expanded 半受控（nil=内部自持/非 nil=外部驱动），onExpandChange 回调。

第五章 四组 Demo 预览

D1 基础单行省略 + 点击展开/收起（rows=1）
这是一段很长的文本内容用于演示单行省略效果，当文本超出容器宽度时会自动截断显示省略号展开

排查点：单行文本超出宽度截断尾部省略号；点击「展开」显示全文+「收起」按钮；点击「收起」恢复截断。

D2 多行省略（rows=3 长文本截断 + 展开）
这是一段很长的多行文本内容用于演示多行省略效果。当文本超过指定行数（此处 rows=3）时，会在第三行末尾截断并显示省略号。用户可以点击展开按钮查看完整内容，再次点击则收起回到截断状态。多行省略在商品描述、活动公告等场景非常常用。展开

排查点：3 行后截断尾部省略号；展开后显示全文 + 收起按钮。

D3 自定义展开收起文案（expandText="查看全部" / collapseText="收起内容"）
自定义展开收起文案的演示文本，展开按钮文字改为「查看全部」，收起按钮文字改为「收起内容」，满足不同业务场景的文案需求。查看全部

排查点：展开按钮显示「查看全部」而非默认「展开」；收起按钮显示「收起内容」而非默认「收起」。

D4 受控外部驱动 expanded（外部按钮控制展开态）
受控模式：expanded 由外部 state 驱动，组件内部不自持。点击下方按钮切换展开/收起态，onExpandChange 回调通知外部。

排查点：外部按钮点击后文本展开/收起；onExpandChange 回调触发；组件不自持 state 完全由外部驱动。

第六章 平台差异预告

差异点iOS（UIKit）Android（Compose）判据
文本截断UILabel numberOfLines + lineBreakMode=.byTruncatingTailText maxLines + overflow=TextOverflow.Ellipsis表内放行（原生 API 差异，视觉一致）
展开态切换numberOfLines=0（展开）/ rows（收起）+ 重排 attributedTextmaxLines=Int.MAX_VALUE（展开）/ rows（收起）表内放行（API 差异，行为一致）
点击交互UITapGestureRecognizer(target:action:)Modifier.clickable表内放行（交互系统差异）
省略方向lineBreakMode=.byTruncatingTail（一期仅尾部）TextOverflow.Ellipsis（一期仅尾部）无差异（双端均原生支持尾部）

第七章 API 速览

Props

参数类型默认值说明
contentString""要显示的文本内容
rowsInt1最大显示行数，超出时截断显示省略号

半受控语义

expanded 值行为场景
nil内部自持 state，点击自动切换默认=零配置可点击展开/收起
非 nil受控模式，state 由外部驱动，内部不自持外部按钮/逻辑控制展开态
