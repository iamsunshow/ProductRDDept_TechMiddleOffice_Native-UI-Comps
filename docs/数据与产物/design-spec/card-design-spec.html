Card 摘要卡片

组件 ID：ui.card ｜ 任务清单 #85 ｜ 展示区（基础卡） ｜ TMO 组件库 v1.4.0

定位：通用摘要卡片容器——卡片壳 + 标题行（标题 + 右箭头）+ 副标题 + 数值行（主数值 + 右侧辅助文案），整卡可点击；用于资产总览、预算进度、月度结余等「一卡一指标」场景。

1. 场景与边界（SCQA）

Situation

资产页/发现页大量使用「标题 + 说明 + 大号数值 + 辅助对比」的卡片，形态高度一致（如「本月结余 ¥1,280.00 较上月 +12%」）。

Complication

各页各自拼装会出现圆角/边框/内边距/字号不一致，且数值行与辅助文案的基线对齐方式各异。

Question

需要一个数据驱动的通用摘要卡片：传入标题/副标题/数值/辅助即可渲染，双端视觉 1:1。

Answer

Card——iOS SummaryCardView（UIControl + apply(...)）；Android SummaryCardView（Composable，参数驱动）。

2. 组件边界与划界

组件职责与 Card 划界
Cell（列表项）列表行（图标+主副标题+右侧值）Cell 是行（等高、可成组、无大号数值），Card 是块（多行纵向、含大号数值区）
Price #72价格文本（字号/颜色/符号）Price=数值文本控件；Card 的 value 可传 MoneyFormatter.currency(...) 结果由 Price 渲染（组合关系，非替代）
Grid #8 / Layout #9排布排布由 Grid/Layout 负责，Card 只管自身视觉
业务专用卡（账单卡/资产卡）含业务交互的卡片业务卡可组合 Card + 自绘内容；Card 不含业务字段
