# TMO 组件库 · 组件完善进度跟踪（component-progress）

> 地位：**组件库完善任务清单与达成情况的唯一进度文档**，供所有 Agent（含 AI Agent）读取与更新。
> 数据源：`docs/组件分类.md`（分类 / 完整度基准）+ 本文件（执行进度）。
> 开发流程：每个组件按 `docs/验收流程/验收标准.md` 五阶段（设计 → API → 实现 → CR/CI → 发版 + 业务落地）推进，每过一道门禁更新本文件。
> 最近更新：2026-09-04

***

## 0. 给 Agent 的读取指引

1. 新任务开始前：先读本文件 + `docs/验收流程/README.md`（验收流程索引）+ `docs/开发规则.md`（规则）+ `docs/组件分类.md`（分类表）。
2. **选下一个组件**：从下方任务清单找阶段为 ⬜ 的组件（按表格顺序从上到下，且其 deps 依赖已完成——依赖优先）。业务用不到的组件：标注 **⏭【暂未使用】** 并登记原因，跳过全部门禁。
3. **开始开发**：把该组件状态从 ⬜ 改为 📐（设计中），按门禁 A（设计评审）→ 门禁 B（API 评审）→ 双端实现 → C1（自测对齐）→ C2（CR/CI）→ 发版 + 业务落地（门禁 D）推进。
4. **每过一道门禁**：更新本文件状态，并在「达成情况」追加一行（日期 / 组件 / 阶段 / 结论）。
5. **完成（✅）**：同步更新 `组件分类.md` 的完整度数据与 `README.md` 口径。
