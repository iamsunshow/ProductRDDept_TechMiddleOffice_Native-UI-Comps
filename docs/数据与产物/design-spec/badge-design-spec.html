Badge 徽标

组件 ID：ui.badge ｜ 任务清单 #45 ｜ 操作反馈区第二件 ｜ TMO 组件库 v1.4.0

定位：展示在图标/头像/容器右上角的数字或圆点提醒——用于未读数、新消息、状态标识。

1. 场景与边界（SCQA）

Situation 情景

App 中大量场景需要提示用户有新内容：消息未读数、待办数量、新功能入口、状态标签。

Complication 冲突

没有统一组件时=各业务页自绘红色圆点+绝对定位，位置偏移、大小不一、无数字截断逻辑。

Question 问题

需要一个徽标组件，支持三种形态：圆点 / 数字 / 自定义文本，支持绝对定位锚点到宿主右上角。

Answer 方案

Badge——纯展示型内容组件，根据 content 自动选形态（null=圆点 / 数字=数字徽标 / 文本=文本徽标），支持 color 主题色、count 上限 99+、offset 定位偏移。

2. 组件边界与划界

组件职责与 Badge 划界
Tag #15行内标签（分类标识）Tag=行内文本标签嵌入流式布局，Badge=锚点到宿主右上角的浮层徽标

3. API 契约

Props

参数类型默认值说明
countInt?null数字徽标：null=圆点形态；0=不显示；≥1=数字；≥maxCount=显示 maxCount+
textString?null自定义文本徽标（与 count 二选一，text 优先）
maxCountInt99数字上限，超过显示「99+」
colorColordanger (红)徽标背景色（danger/warn/success/primary 等）
dotBooleanfalse强制圆点形态（忽略 count/text）
offsetOffset?null锚点偏移（默认 top-4/right-4 即右上角外凸 4）

形态自动选择

条件形态示例
dot=true 或 count=null 且 text=null圆点 8×8🔴
count≥1 且 ≤maxCount数字圆角胶囊3 / 99
count>maxCount数字+号99+
text 非空文本胶囊新 / HOT
count=0 或 count=null 且 text=null 且 dot=false不渲染（空）

6. 决策投票表

编号决策点选项选定理由
P1形态驱动 A. 单一 content 参数自动推断形态
B. 显式 type 枚举 + 各自参数
C. 三个独立组件 DotBadge/CountBadge/TextBadge		 A 单一入口最简洁；count/text/dot 三参数覆盖所有形态；与 AppIcon 角标逻辑一致
P2锚点方式 A. 独立 Badge 组件+宿主自行绝对定位
B. Badge 作为宿主 wrapper（Box 包裹 content+badge）
C. Modifier/扩展点锚点		 B wrapper 模式=宿主直接嵌套 Badge{ 宿主内容 }，定位由组件内部控制，零使用方布局代码
P3count=0 行为 A. 不渲染（推荐）
B. 渲染灰色「0」
C. 渲染圆点		 A 0=无新内容=不应有徽标干扰；减少视觉噪音
P4一期范围 A. 一期=圆点/数字/文本三形态+maxCount+color+offset+wrapper锚点+demo四段
B. 二期=动画弹出/数字滚动/自定义形状		 A 一期覆盖 95% 场景；动画/滚动=二期增量

8. 反目标

不做原因
动画弹出/数字滚动二期增量，一期静态展示已够用
点击交互Badge 纯展示，点击由宿主承载
自定义形状（方形/三角）一期只做圆形胶囊，异形=二期
内置宿主图标Badge 只负责徽标本体，宿主内容由调用方提供
