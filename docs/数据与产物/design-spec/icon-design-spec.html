01用途与场景

图标是 UI 的最小矢量单元：tab、列表行、主操作加号、空态、宫格入口等全部收敛到这一个入口，收编「SF Symbol 名各页面自造 + 尺寸/着色随手写」的散乱用法。
  • 统一入口：任何页面需要图标时用 <AppIcon>，禁止各页面直接调用 UIImage(systemName:) / Material Icons 原语各写各的。
  • 字形来源（双端差异=允许项）：iOS 直接用系统 SF Symbols（零资源开销、系统级适配）；Android 用 SfApproxIcons 手绘矢量近似，同名枚举 AppIconName 双端共用。
  • 着色机制：整图单色 tint——iOS tintColor（配合 monochrome 强制单色轮廓），Android ColorFilter.tint，默认 textPrimary。
  • 被引用方：宫格 ui.grid、空态 ui.empty（EmptyStateView icon 参数）、Cell 等均复用本组件，语义色保持一致。
    • 边界（anti-goals）：① 不做品牌图标（wechat / weibo / qq 等），品牌图标属于登录方式特定场景，不纳入通用 Icon 组件；② 不做图标字体（iconfont），直接用系统 SF Symbols / 自建矢量，避免字体加载与缓存问题；③ 不做动效图标（Lottie / animated vector），动效需求由 ui.lottie 承载。

    04尺寸与视觉令牌

    图标为正方形等比：size 同时约束宽高（iOS width/height 双约束，Android Modifier.size），默认 24（pt / dp），宫格内常用 26（见 ui.grid）。
    视觉令牌值用途
    color.textPrimary#111827默认着色（icon 默认值）
    color.primary#16A34A主色强调（新建加号等主操作语义）
    color.error#DC2626警示语义（邮箱等需警示内容）
    color.textSecondary#6B7280次要内容图标
    设计要点：图标永远「语义着色」不随手写色，一屏内同一语义色保持一致；着色须与邻近文字色语义配套（警示→error、强调主操作→primary、普通内容→textPrimary / textSecondary）。

    契约正文以 docs/数据与产物/api.json（ui.icon，reviewed=true）为唯一事实源，此处为摘要。纯展示组件：无 events（无交互回调）。

    color? / tint?Color，默认 textPrimary着色：iOS color（tintColor）/ Android tint（ColorFilter.tint），契约文档化双写映射
