# API 接口规范（API Contract）

> 双端组件 Props/参数/状态/回调 **100% 对齐**。本文以 iOS 现有实现为基准，
> 逐步补齐 Android 对应实现，作为双端 API 契约的唯一权威清单。
>
> 约定：本文列出每个组件的**对外 API（构造参数、绑定方法、回调）**与**状态规范**。
> Android 侧必须提供同名/同语义的参数与回调；命名允许平台惯例外（Swift camelCase / Kotlin camelCase），
> 但**语义与数量必须一致**。
>
> 状态统一：**默认 / 禁用 / 加载 / 成功 / 失败**（组件支持哪些在各自章节标注）。

## 二、各组件 API 契约（双端）

### C1 年月选择器 `MonthPicker`

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `year` | Int | 是 | 初始选中年 |
| `month` | Int | 是 | 初始选中月 1...12 |

**回调**

| 回调 | 签名 | 说明 |
|------|------|------|
| `onConfirm` | `(year: Int, month: Int) -> Void` | 确认年月 |

**状态**：无（弹层类）

### C5 导航栏 `NavBar`

> 业务侧传入标题/左右按钮/返回行为。iOS 为 `NavBar`，Android 对应自定义 `TopBar`。

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | String | 是 | 标题 |
| `leftItem` | NavItem? | 否 | 左按钮（返回/取消） |
| `rightItem` | NavItem? | 否 | 右按钮（确定等） |

**回调**

| 回调 | 签名 | 说明 |
|------|------|------|
| `onLeftTap` | `() -> Void` | 左按钮点击 |
| `onRightTap` | `() -> Void` | 右按钮点击 |

**状态**：默认

## 四、契约执行铁律

- 新增/修改组件 API，**先改本文，再改双端代码**。
- 两端参数数量与语义必须一致；仅命名可随平台惯例。
- 回调语义一致（确认回调、点击回调、刷新回调等）。
- 业务强相关组件不进库、不入契约（见总览末尾说明）。
