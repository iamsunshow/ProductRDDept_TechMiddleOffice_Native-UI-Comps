Skeleton 骨架屏 · 设计规格（操作反馈区 #57 · 门禁 A）

组件 ID：ui.skeleton ｜ 定位：首屏/加载过渡期占位骨架——用灰色块模拟即将渲染的内容布局，shimmer 动画提示加载中。对标 NutUI Skeleton / Vant Skeleton / Ant Design Skeleton。用于列表项、卡片、文章详情等场景的加载占位，减少白屏焦虑感。
组件库版本 设计阶段锁定基线 = v1.4.14（2026-09-09，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 列表项加载占位（头像+标题+副标题骨架行）；② 卡片加载占位（图片+标题+描述骨架块）；③ 文章详情加载占位（标题+段落多行骨架）；④ 自定义骨架组合（SkeletonBlock 原子块自由组合）；⑤ 带 shimmer 动画提示加载中
不适用（N/A）① 底部加载更多状态条 → InfiniteLoading（ui.infinite-loading）；② 全屏遮罩加载 → Loading（ui.loading）；③ 下拉触发刷新 → PullToRefresh（ui.refresh）；④ 无数据空状态 → Empty（ui.empty）；⑤ 操作结果反馈 → ResultPage（ui.result-page）
五态适配加载态 ✅ loading=true 时显示骨架占位；完成态 ✅ loading=false 时显示真实内容（SkeletonRow 包裹器模式切换）；动画态 ✅ shimmer 从左到右渐变扫光动画；无禁用态（骨架屏总是被动展示）
与现有组件关系deps=[DesignTokens]（颜色/间距/圆角 token，零硬编码）。与 InfiniteLoading #49 划界：Skeleton=首屏占位骨架，InfiniteLoading=底部增量加载状态条；与 Loading #50 划界：Loading=全屏遮罩旋转指示器，Skeleton=内容布局骨架块；与 Empty #48 划界：Empty=无数据空状态引导，Skeleton=加载过渡期占位

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件形态：ACE 三选

选项后果评估
A：原子块 + 包裹器双模式——SkeletonBlock(width,height,radius) 原子块 + SkeletonRow(loading,avatar,title,subtitle) { content } 包裹器✅ 灵活组合（原子块自定义布局）+ 开箱即用（SkeletonRow 预设行布局）；loading 受控切换骨架/内容；与 NutUI/Vant Skeleton 双模式一致。推荐 A：原子块=最大灵活性，包裹器=最小使用成本
B：只做原子块 SkeletonBlock灵活但每次需自行组合，使用成本高。淘汰：缺少预设布局
C：只做预设行 SkeletonRow开箱即用但不灵活，无法自定义布局。淘汰：缺少自定义能力

P2 · Shimmer 动画方案：ACE 三选

选项后果评估
A：linear-gradient 横向扫光——background linear-gradient(90deg, base, active, base) + background-size 200% + animation shimmer 1.5s✅ 双端同构（iOS CAGradientLayer / Android Brush.linearGradient），视觉为从左到右渐变扫光，与 NutUI/Vant 一致。推荐 A：双端一致，视觉效果好
B：alpha 闪烁——background base + animation alpha 0.3→1→0.3实现简单，但视觉为整体明暗闪烁，不如扫光自然。淘汰：视觉效果差
C：无动画（静态灰色块）无动画提示，用户无法感知加载中。淘汰

P3 · iOS 实现路径：ACE 三选

选项后果评估
A：UIView + CAGradientLayer（shimmer 动画）+ 子视图布局✅ 原生 UIKit，CAGradientLayer 实现扫光动画自然；SkeletonBlock=UIView+gradientLayer；SkeletonRow=UIStackView 组合 avatar+text column。推荐 A：原生 UIKit，动画自然
B：UIStackView + UIView.animate alpha 闪烁实现简单但动画效果差（P2-B 方案）。淘汰
C：CAShapeLayer 自绘过度复杂，无优势。淘汰

P4 · Android 实现路径：ACE 三选

选项后果评估
A：Box + Brush.linearGradient（shimmer 动画）+ Compose 布局✅ Compose 原生，Brush.linearGradient + animateFloat 实现 shimmer；SkeletonBlock=Box+background brush；SkeletonRow=Row 组合 avatar+text column。推荐 A：Compose 原生，动画自然
B：Box + animateFloat alpha 闪烁实现简单但动画效果差。淘汰
C：Canvas 自绘过度复杂。淘汰

07 · anti_goals 反目标（二期不做）
