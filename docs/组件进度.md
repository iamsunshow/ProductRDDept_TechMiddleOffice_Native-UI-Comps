## 0. 给 Agent 的读取指引

1. 新任务开始前：先读本文件（1.1 节分类口径 + 第 3 节任务清单）+ `docs/数据与产物/api.json`（契约）+ 验收流程与规范唯一入口=《产研部-唯一权威手册》第二章（docs 原验收流程/ 已 2026-09-04 收拢删除）。
2. **选下一个组件**：从下方任务清单找阶段为 ⬜ 的组件（按表格顺序从上到下，且其 deps 依赖已完成——依赖优先）。业务用不到的组件：标注 **⏭【暂未使用】** 并登记原因，跳过全部门禁。
3. **开始开发**：把该组件状态从 ⬜ 改为 📐（设计中），按门禁 A（设计评审）→ 门禁 B（API 评审）→ 双端实现 → C1（自测对齐）→ C2（CR/CI）→ 发版 + 业务落地（门禁 D）推进。
4. **每过一道门禁**：更新本文件状态，并在「达成情况」追加一行（日期 / 组件 / 阶段 / 结论）。
5. **完成（✅）**：同步更新 api.json（reviewed=true）+ ui-version.json + CHANGELOG（三处一致=见唯一手册第三章第一条）与 `README.md` 口径。
