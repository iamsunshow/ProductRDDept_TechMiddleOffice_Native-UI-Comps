Tabs 选项卡 · 设计规格（导航组件 · 任务清单 #20 · 收编缺口补独立立项 · 门禁 A）

组件 ID：ui.tabs ｜ 定位：页面内容区的顶部页签切换条——内容区上方一行（或数行）页签，点击在页内内容块间切换，当前页签持久高亮（主色 + 底部指示线），回传 onChange(value)；页签下的内容面板由宿主接回调渲染自理；对标 NutUI React Tabs / Material TabRow（value 受控 + Tab title + onChange）收敛为库内自有设计语言（等分页签 + 主色激活 + 2 高主色指示线）。
组件库版本 设计阶段锁定基线 = v1.4.0（2026-09-04，未过 C2/D 不升版）

01 · 组件用途 & 不适用边界（SCQA）

维度说明
适用场景① 页内内容分类切换：同一页面顶部按分类/周期/维度切换下方内容块（账单类型 支出/收入/转账、图表周期 周/月/年、明细筛选等）；② 页签数量 2–6 等分（页面宽度足够）；③ 当前页签需持久高亮指示（主色文字 + 底部短指示线）与禁用个别页签；④ 由外部事件驱动页签跳转（如从详情返回切回某页签）
不适用（N/A）① 页面级一级底部导航（跨页）→ Tabbar（ui.tabbar，#19）；② 页面顶部标题/返回导航条 → NavBar（ui.nav-bar，#17）；③ 左侧目录轨 → SideBar（ui.side-bar，#18）；④ 等宽分段互斥选择器（无内容面板语义）→ Segmented（展示 #74）；⑤ 超过 6 个页签/横滑内容联动/自定义面板插槽 → 登记二期（anti_goals）
五态适配默认态 ✅ 未选中页签次色灰；激活态 ✅ 当前页签主色加粗 + 底部 2 高主色指示线（常驻持久）；禁用态 ✅ 单页签 disabled 置灰不可点；加载/成功/失败 N/A（内容面板业务态由宿主承载）
与现有组件关系deps=[DesignTokens]；收编现状=iOS TabsView/PeriodTabsView（SharedUI/Components，业务"周/月/年"及双 Tab 切换近似，固定 200 宽居中 32 高胶囊形态，更近 Segmented 语义）为收编近似，非独立 Tabs；Android 未实现独立 Tabs，本规格将近似收编升级为双端统一独立组件（同 Grid v2.0 / NavBar 收编升级先例）；激活视觉=主色文字加粗 + 底部指示线（区别于 SideBar 胶囊浮底，Tabs 内容切换语义用"下划线+文字主色"指示）；"内容面板"由宿主渲染（组件=纯页签条，不自带内容区与滑动手势）

02 · 尺寸/Token 规格（零硬编码）

要素Token说明
条高默认 44pt/44dp（宿主可覆盖）对齐 iOS UINavigationBar 44 / Material TabRow 48 / 库内导航同族行高惯例，取 44；无横向滚动一期（≤6 项等分），滚动式 Tabs=二期
页签宽等分（页签数均分条宽）2–6 项自适配；iOS=UIStackView fillEqually / Android=Row + weight(1f)（表内放行）
文字字号 Sm（14pt/14dp）；激活=主色 + Bold，默认=次色灰 Regular；单行省略长页签标题单行行尾省略（双端系统行为放行）；页签内无 icon 位（纯文字语义，icon 型页签=二期）
激活指示底部 2pt/2dp 高主色指示线，宽度=页签文字宽（或整项宽，见 §06 定稿）指示线横移=二期动画（一期仅静态当前项）
激活/默认色激活=AppColor.primary（可 activeColor 覆盖品牌色）；默认态=AppColor.textSecondary品牌自定义激活色场景宿主传值覆盖；非激活色固定次色不开放（克制，同 Tabbar/SideBar 先例）
禁用态同 default 布局 + 文字透明度 40% + 不可点disabled 项点击不触发 onChange（同全库禁用先例）
条底分隔hairline（iOS 1/scale pt vs Android 0.5dp 表内放行，同 Grid 先例）可选页签条与内容面板间细线分隔可宿主裁（组件底部默认无自带内容背景）

03 · 关键决策 PREP / ACE（人为决策 4 条，编号 P1–P4，AI 代评待用户总审）

P1 · 组件定位：ACE 三选

选项后果评估
A：纯顶部页签条（收编升级）——items 数据驱动等分（2–6 项、title/value/disabled）+ 激活主色加粗 + 底部指示线 + 点选回传 onChange；内容面板由宿主渲染切换✅ 语义=页内顶部内容切换（对齐 NutUI Tabs 的"页签条"本体）；单职责组件双端 1:1 清晰；与 Tabbar（底部跨页）/Segmented（无面板语义）/NavBar（标题条）全部划界；宿主可用 onChange 切内容块，亦可受控外部驱动推荐 A：收敛可验收
B：页签条 + 内置内容面板容器一体（多面板切换 + 滑动/保活）内容面板渲染/滑动/转场/懒加载双端差异大（UIViewController 容器 vs Compose pager），非 UI 组件职责，验收周期失控淘汰：内容面板宿主自理（登记二期候选）
C：直接收编 iOS UISegmentedControl / Android TabLayout 系统容器UISegmentedControl=等宽分段胶囊（Segmented #74 语义，非内容切换页签）；TabLayout 系统 tab 需 CoordinatorLayout 联动且定制到库内主色指示线成本高、跨端契约难统一淘汰：系统容器收编由 NavBar/Tabs 业务近似场景已覆盖，非组件本体

P2 · 数据模型：ACE 三选

选项后果评估
A：options 数据驱动——TabItem(title, value, disabled=false)，items 数组传入；onChange 回传被点 value✅ 与 FixedNav/SideBar/Tabbar 等"列表数据驱动 + value 标识"一致；value 稳定可映射内容块 id；disabled 可缺省；双端契约简单推荐 A：数据驱动惯例
B：children 声明式（iOS 子视图 / Android content slot 逐项内嵌）页签为固定样式等分项，无自定义插槽诉求；children 使等分/激活统一态维护复杂淘汰：二期自定义插槽再评估
C：仅标题字符串数组（无 value/disabled）无法禁用单项；value 用于稳定映射内容块 id（字符串标题不稳定，如改文案破坏映射）淘汰：表达能力不足

P3 · 选中态控制：ACE 三选

选项后果评估
A：半受控——默认首启用项激活自管理；宿主可传 selectedValue 外部驱动（同步高亮 + 指示线）；点击已激活项不重复回调；禁用项无动作✅ 宿主既能"点选即切内容"，也能受控驱动（外部事件/详情返回跳转 tab 同步高亮，demo D4 可验）；回调幂等便于计数验收；与 Tabbar/SideBar 选中语义一致推荐 A：灵活且行为确定
B：纯受控——value 必传，所有变更宿主回填页内简单切换普遍自管理即可，强制受控过重可接受但过度
C：纯自管理 + 仅通知点击无法由外部（如筛选重置回默认 tab）驱动页签激活，宿主需自己 hack淘汰

P4 · 一期范围裁剪：ACE 三选

选项后果评估
A：纯页签条——items 数据驱动（title/value/disabled）+ 等分（≤6 项）+ 半受控选中 + 主色激活 + 底部 2 指示线 + 禁用 + 单行省略 + 可选 activeColor + demo 四段（基础/禁用/长标题/受控驱动）✅ 覆盖页内内容切换核心闭环（分类切换 + 激活持久 + 内容面板宿主联动）；D4 验证外部 value 驱动语义；与 TabsView 收编近似（双 Tab/周月年胶囊）语义升级 1:1 展示推荐 A：验收路径清晰
B：一期即支持横向滚动（>6 项/超宽自适应滚动）/滑动切换内容/懒加载滚动式 Tabs 需 ScrollView/LazyRow + 指示线跟随 + 滑动手势双端差异大，一期验收失控；<6 项等分覆盖业务主要诉求淘汰：登记二期（滚动/滑动/懒加载）
C：一期内置图标页签（icon+文字）/红点 dot/面板动画/左侧胶囊icon 型页签映射与 dot 红点需双态复杂度；面板动画属宿主内容切换职责；左侧胶囊为 SideBar 语义淘汰：二期候选（icon/dot/动画）

05 · 平台差异表（表内放行，表外必须双端统一）

维度iOSAndroid放行原因
点击按压反馈UIButton touchDown 高亮/压暗瞬态clickable 系统 ripple（Material 默认点击反馈）系统级原生差异：按压反馈体系不同（表内放行，同 Grid/SideBar/Tabbar 先例）
等分实现UIStackView distribution=.fillEquallyRow + Modifier.weight(1f)系统级布局机制不同、结果同=均分（表内放行）
文字省略截断UILabel 单行 truncateTailText overflow=Ellipsis（maxLines=1）两端系统文本省略行为一致指向（表内放行，同全库先例）
指示线UIView 2pt 高主色（宿主宽度锚定当前项）Box 2dp 高主色 offset 到当前项实现机制不同、视觉同为当前项底 2 高主色线（表内放行）
尺寸数值单位ptdpToken 同一数值不同单位（表内放行，同全库先例）
数据模型命名struct TabItem / TabsView（替换旧收编 TabsView）data class TabItem / @Composable Tabs契约同构（表内放行，命名差异见门禁 B）

06 · API 草案（双端一致契约，门禁 B 据此登记 api.json）

端API
共用TabItem：title: String（单行省略）+ value: String（稳定标识，映射内容面板）+ disabled: Boolean = false
iOSfinal class TabsView: UIView（组件化替换旧收编 TabsView）
init(items: [TabItem], selectedValue: String? = nil, activeColor: UIColor? = nil, onChange: ((String) -> Void)? = nil)
默认 selectedValue=nil → 首启用项激活；var items / var selectedValue / var activeColor（didSet 刷新激活态+指示线）；条高默认 44，宿主可高度约束覆盖；内容面板由宿主渲染在下方
Androiddata class TabItem(title: String, value: String, disabled: Boolean = false)
@Composable fun Tabs(items: List<TabItem>, selectedValue: String? = null, activeColor: Color? = null, onChange: (String) -> Unit, modifier: Modifier = Modifier)
默认 selectedValue=null → 首启用项激活；内部 Row 等分（weight=1f）；行 clickable + ripple（表内放行）；指示线 2dp 主色 offset 当前项
