01用途与场景

中台「主操作按钮」的唯一入口：把散落各页、各自定义的按钮收敛为三种既定样式的统一组件，保证主次破坏三级操作在全 App 视觉一致。
  • 典型场景：一键登录（本机号码登录主按钮=样式基准）、注册、弹窗确认 / 取消、表单提交、退出登录等主操作与次操作。
  • 组合关系：页面级通栏使用（全宽 48 高）；行内 / 紧凑场景由外部约束宽度，高度不矮于 48。
  • 操作反馈：点击触发 onClick；提交型按钮用 loading 防止重复提交；不可达操作用 enabled=false 置灰。
    • 边界（anti-goals）：① 不做图标按钮（icon-only），图标按钮由 ui.icon 承载；② 不做悬浮动作按钮（FAB，属 Material 体系，不在中台基础范围）；③ 不做按钮组（ButtonGroup），分组由布局组件承担。

    02视觉规格（三样式）

    三样式语义 = 操作层级：每屏只应有一个 primary（主操作）、secondary 为次级操作、destructive 为破坏性操作。以下为真实渲染（色值 = design-token.json，与双端 AppTokens 一致）。
    primary=主色填充+白字
    secondary=白底+主色描边+主色字
    destructive=白底+红色描边+红字
    样式填充描边文字按下态反馈
    primary（默认） color.primary #16A34A 无 textInverse 白 背景切 color.primaryPressed #15803D
    secondary bgCard 白底 1px color.primary color.primary 主色字 弱反馈（文字透明度 0.6，iOS；Android 无独立按下档）
    destructive bgCard 白底 1px color.error #DC2626 color.error 红字 弱反馈（同 secondary）
    层级约定：primary 是操作层级锚点，一屏至多一个；次要/破坏性操作降为描边样式，避免满屏彩色按钮。破坏性 ≠ 「错误状态」，它只是一种操作样式（见 03 节状态说明）。

    03状态规格

    按钮是离散操作控件：五态中「成功 / 失败」不适用（由调用方 toast/反馈组件表达结果），实际状态空间 = 样式 × (enabled × loading)，按下为过程态。
    状态表现可点触发方式
    默认 按三样式既定视觉渲染 是 —
    按下（过程态） primary→深一档主色；secondary / destructive→弱透明度反馈 — 手指按下瞬间，抬起即回默认
    禁用 灰填充 buttonDisabled #9CA3AF + 白字，无描边 否 enabled=false / iOS setAppEnabled(false)
    加载 灰填充 buttonDisabled #9CA3AF + 白字 + 文案改「加载中...」 否 loading=true / iOS setLoading(true)（加载中不改回原文案直至结束）
    默认（primary）
    按下（primaryPressed）
    禁用（enabled=false）
    加载（loading=true）
    禁用 / 加载一致性：两者视觉完全一致（共用 buttonDisabled），差异只在文案（加载态显示「加载中...」）与外部语义；iOS 与 Android 顺序一致（先灰、后亮回原样式）。状态切换自愈：loading/enabled 恢复后回原样式渲染，无残留态。

    04尺寸与视觉令牌

    尺寸基准对齐「本机号码一键登录」按钮；通栏由页面约束全宽，组件默认内容高度 48。
    维度规格来源
    高度48（pt / dp）standardHeight=48 / 默认 48.dp，外部可覆盖
    宽度默认通栏全宽（fillMaxWidth / 外部约束）主操作按钮通栏惯例
    圆角lg = 14radius.lg（AppRadius.lg）
    字号 / 字重16 / Semibold 半粗font.sizeMd（AppFont.sizeMd）
    描边宽（描边样式）1pxsecondary / destructive
    视觉令牌值用途
    color.primary#16A34Aprimary 填充 / secondary 描边与字色
    color.primaryPressed#15803Dprimary 按下态
    color.buttonDisabled#9CA3AF禁用 / 加载灰填充
    color.bgCard#FFFFFFsecondary / destructive 白底
    color.error#DC2626destructive 描边与字色
    color.textInverse#FFFFFF填充型按钮文字色
    font.sizeMd16按钮文案字号
    radius.lg14按钮圆角

    05API 契约摘要

    契约正文以 docs/数据与产物/api.json（ui.button，reviewed=true）为唯一事实源，此处为摘要。双端 A7 命名比对一致，无平台差异登记。
    Props类型 / 默认说明
    textstring（必填）按钮文案
    onClick() => void（必填）点击回调（enabled=true 且 loading=false 时触发）
    style?primary / secondary / destructive，默认 primary视觉样式（见 02 节）
    fontSize?number，默认 16文案字号（pt / sp）
    height?number，默认 48按钮高度（pt / dp）
    enabled?boolean，默认 true可用性：false 置灰不可点
    loading?boolean，默认 false加载态：置灰 + 「加载中...」+ 不可点
    Events签名说明
    onClick() => void点击（enabled=true 且 loading=false 时触发）
    Demos（5 项，Demo 对照双端 1:1）：主操作 / 次要操作 / 破坏性操作 / 加载态 / 禁用态。iOS ButtonShowcase 与 Android ButtonDemo 以 4 组递增单因子排查呈现（① 基础仅 Primary → ② style 三样式 → ③ loading+disabled → ④ 三样式×三状态全组合）。
