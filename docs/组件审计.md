## 待办（由本表暴露）

1. **双端命名对齐**：对 ❌ 不一致组件统一命名（含 iOS/Android 类名、Swift/Kotlin 文件）。
2. **单端补全**：⚠️ 仅 iOS / 仅 Android 组件在另一端落地，保持命名与 API 一致。
3. **聚合文件拆分**：Android 的 `CommonComponents.kt` / `ProfileListGroup.kt` / `ProfileAvatarComponents.kt` 承载多组件，按组件独立文件。
4. **API 契约补全**：多个组件 `apis` / `props` / `events` 为空，需在 `docs/api.json` 补齐，作为双端 API 一致性基准。
